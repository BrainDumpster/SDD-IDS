## Anatomy
- Toggle track (background)
- Toggle thumb (sliding element)
- Container wrapper
- Focus ring for keyboard navigation
- Optional label text

## Layout & Measurements
- Standard width: 48px
- Standard height: 24px
- Thumb size: 20px × 20px
- Thumb offset: 2px from track edges
- Border radius: 12px (track), 10px (thumb)
- Focus ring: 2px offset from track
- Label spacing: 8px from toggle

## Typography
- Body 2: Roboto Regular 14px/20px (toggle labels)

## States (Dark Theme)
- Uses semantic tokens that automatically adapt to dark theme
- Surface tokens: `var(--color-background-surface-1)` (#111619)
- Text and border colors remain consistent via semantic variables
- Disabled state uses gray tokens for dark theme compatibility

## Interactions
- Click to toggle between on/off states
- Hover provides visual feedback with color changes
- Focus ring uses brand color for keyboard navigation
- Disabled state prevents interaction and uses gray colors
- Smooth sliding animation for thumb movement
- Keyboard navigation: Space to toggle

## Accessibility
- Focus ring: 2px brand color border
- Touch target: Minimum 44px × 24px for mobile accessibility
- Keyboard navigation: Tab to toggle, Space to toggle
- Screen reader support: Proper ARIA labels and state announcements
- High contrast: Meets WCAG AA standards with provided colors
- Semantic HTML: Use checkbox input with proper styling

## Variants
- **Default**: Standard toggle with brand colors
- **Small**: Compact size for tight spaces
- **Large**: Increased size for better accessibility
- **Disabled**: Non-interactive state
- **Labeled**: Toggle with descriptive text

## Behavior & Guidelines
- Use toggles for binary on/off settings
- Provide clear labels describing what the toggle controls
- Use consistent on/off positioning (left = off, right = on)
- Ensure smooth transitions between states
- Test with screen readers for proper state announcement
- Consider using switches for mobile-optimized interfaces

## Token Gaps / Notes
- All colors use semantic CSS custom properties for theme consistency
- Typography scales are defined via font tokens
- Focus states use brand colors for visual consistency
- Disabled states maintain accessibility with proper contrast
- Animation timing should follow design system guidelines
- Thumb positioning should be precise and centered
