## Layout & Measurements
- Panel width: `400px` fixed in current design.
- Panel height: full viewport/application height (`100%` of parent; designed as full-height drawer).
- Outer panel border: `1px`, light border token.
- Root content padding: `24px` top, `24px` left, `4px` right, `24px` bottom.
- Hero image: `104px` square visual region.
- Hero title width sample: `220px`, centered.
- Hero action button min width: `276px`.
- Section spacing:
  - Details stack gap: `24px`.
  - Properties section gap: `16px`.
  - Tags wrap uses `8px` spacing.
- Description:
  - Label `"Description:"` always present.
  - Body container uses light surface background, 1px border, 16px padding.

## Interactions
- Side panel behaves as a right-side drawer.
- Opening animation: panel draws in from right edge; closing reverses.
- When visible, application body area shrinks responsively (not overlay-only mode).
- Close action emits close event and hides drawer.
- Header action button emits primary action event.
- Tags align to IDS Tag default/non-alerting pattern: `24px` height, `12px` radius, `8px` horizontal padding, Body-2 text, accessible border, non-dismissible in this panel by default.
- Tags are informational by default; optional click behavior may be enabled by API.

## Composition & API (runtime)
Main inputs:
- `open: boolean`
- `title: string` (hero title)
- `imageSrc?: string` (optional custom image; fallback to `device-network-server`)
- `description: string` (required)
- `properties: { key: string; value: string; iconSlug?: string }[]`
- `tags: string[]`
- `actionLabel?: string` (default `"View and Manage"`)
- `closeAriaLabel?: string` (default `"Close side panel"`)
- `panelWidth?: number` (default `400`)

Outputs/events:
- `onOpenChange?(open: boolean): void`
- `onClose?(): void`
- `onActionClick?(): void`
- `onTagClick?(tag: string): void` (optional interactive mode)

## Codegen Contract (Framework-Agnostic Blueprint)
Deterministic structure:
- `DapSidePanelRoot`
  - `DapSidePanelHeader`
    - `DapSidePanelCloseAction`
  - `DapSidePanelHero`
    - `DapSidePanelHeroImage`
    - `DapSidePanelHeroTitle`
    - `DapSidePanelHeroAction`
  - `DapSidePanelPropertiesSection`
    - required `DapSidePanelDescriptionLabel`
    - required `DapSidePanelDescriptionBody`
    - repeated property rows
  - `DapSidePanelTagsSection`
    - repeated tag pills

Variant/options matrix:
- drawer state: `closed | opening | open | closing`
- mode: `push-layout` (default for DAP app shell) | `overlay-layout` (optional fallback)
- scroll support: `content-scroll | page-scroll`

Per-slot style contract:
- Close icon must resolve to slug `ctrl-close-16` with `var(--color-icon-neutral)`.
- Description block is mandatory and must retain bordered light-surface style.
- Tag chips follow IDS `Tag` spec default style: `24px` height, `12px` radius, `8px` horizontal padding, min width `32px`, background `var(--color-background-component)`, 1px accessible border, body-2 text, no dismiss affordance.

Behavior contract:
- Draw-in/out transitions are smooth and deterministic.
- Push-layout recalculates main content width during transition.
- Panel remains full-height and independently scrollable when content exceeds height.

Accessibility contract:
- Root should expose landmark/region label (e.g., `aria-label="Details side panel"`).
- Close button has explicit aria-label and keyboard activation.
- Focus remains reachable for all interactive controls in panel.

Asset resolution + bundling:
- Required icon slugs:
  - close: `ctrl-close-16`
  - healthy status sample: `status-ok-circ-solid-16`
  - sample property icon: `virtual-machine`
- Sample hero image slug: `device-network-server` (or consumer `imageSrc`).
- Canonical close icon asset path reference: `/assets/icons/ctrl-close-16.svg`.
- Canonical hero image asset path reference: `/assets/icons/device-network-server.svg`.

Fallback/error rules:
- Missing `description` -> render empty-state placeholder text but keep description container.
- Missing `tags` -> render empty tags section with heading only.
- Unknown `iconSlug` -> render no icon but keep text/value row.

Validation checklist:
- [ ] Panel is fixed 400px width by default and full-height.
- [ ] Drawer animation works for open/close.
- [ ] App body width shrinks/expands in push-layout mode.
- [ ] Description label + body are always rendered.
- [ ] Close icon is `ctrl-close-16` and neutral icon tokenized.
- [ ] Action/close events emit correctly.
