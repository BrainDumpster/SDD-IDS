## Layout & Measurements
- Masthead bar size: `1096px x 56px` in showcase frame; runtime width remains container-driven.
- Action area height: `54px`, vertically centered within 56px masthead.
- Left product info block:
  - left padding: `24px`
  - inter-item gap: `12px`
  - primary and secondary labels use 18px text with 32px line-height.
- Vertical divider between product labels:
  - sample length: `28px`
  - hairline stroke style from Figma divider asset.
- Action buttons:
  - settings/help/app launcher buttons: horizontal padding `16px`, vertical `19px` (16px icon centered).
  - user initials wrapper: horizontal padding `8px`, vertical `11px` (32px initials chip).
- Help dropdown:
  - surface width: `138px`
  - row padding: `10px 16px 10px 24px`
  - rows: Help, What's New, Get Started, About.
- App launcher dropdown:
  - surface width: `298px`
  - 2x2 grid tile block + lower options block (`Product Name 5/6/8` rows).
- Popovers anchor to the corresponding masthead action and open below the bar (`top offset = 56px` in frame).

## Interactions
- Help action toggles `MastheadDapHelpMenu` (open/close on click; closes on outside click / selection).
- App launcher action toggles `MastheadDapAppLauncherMenu` with standard launcher behavior.
- Help and app launcher are independently interactive; opening one does not disable the other.
- Launcher tiles and option rows trigger navigation callbacks when selected.
- Keyboard:
  - `Tab` traverses actions and menu items.
  - `Enter` / `Space` activates focused action/menu item.
  - `Escape` closes the currently open popup menu.

## Codegen Contract (Framework-Agnostic Blueprint)
Deterministic structure:
- `MastheadDapRoot`
  - `MastheadDapProductInfo`
    - `MastheadDapPrimaryProductLabel`
    - `MastheadDapProductDivider`
    - `MastheadDapSecondaryProductLabel`
  - `MastheadDapActions`
    - `MastheadDapSettingsAction`
    - `MastheadDapHelpAction`
      - optional `MastheadDapHelpMenu`
    - `MastheadDapAppLauncherAction`
      - optional `MastheadDapAppLauncherMenu`
    - `MastheadDapUserInitials`

Variant/option matrix:
- masthead menu state: `base | help-open | app-launcher-open`
- action state: `default | hover | press/select | focus`
- theme mode: `light | dark` (semantic token driven)

Per-slot style contract:
- Masthead root must use masthead-brand token family and white icon/text tokens.
- Help menu and launcher surfaces must use component background + accessible border + drop shadow.
- Help menu rows follow dropdown option spacing and interaction contract (`default | hover | press | focus-visible`) using the same token model as IDS dropdown rows.

Behavior contract:
- Help and launcher trigger states are independently controllable.
- Trigger buttons expose open state via `aria-expanded`.
- Popup menus close on blur/outside click/Escape.

Accessibility contract:
- Root uses `header`; actions use semantic `button`.
- Popup menus expose list semantics (`role="menu"` or listbox-equivalent pattern).
- Focus indicators are visible on masthead actions and menu items.

Asset/bundling contract:
- Masthead icons map to stable slugs:
  - settings: `setting-gear-16`
  - help: `help-circ-16`
  - app launcher: `grid-square-9-16`
- App launcher product icon fallback slug: `shield-encrypt-alt`.

Fallback/error rules:
- Missing `helpItems` falls back to default 4-item list.
- Missing launcher lists render empty launcher popup safely (no crash).
- Unknown icon slug uses shared icon fallback behavior.

Validation checklist:
- [ ] All masthead action states are tokenized and deterministic.
- [ ] Help dropdown and app launcher can open/close interactively.
- [ ] Help and launcher callbacks are emitted on selection.
- [ ] `help-circ-16` and `grid-square-9-16` are used for their actions.
- [ ] Accessibility attributes/keyboard close behavior are present.
- [ ] No missing variable references against `components/ids-theme.css`.
