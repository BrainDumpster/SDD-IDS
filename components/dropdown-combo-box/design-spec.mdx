# Dropdown / Combo Box Design Spec

## Metadata
- Component: Dropdown / Combo Box
- Category: Formelements
- Figma: https://www.figma.com/design/VZJ48bbVYrIynw8DdSukWw/-Exploration-only--IDS-with-variables?node-id=11067-54551&m=dev
- Node ID: 11067-54551

## Anatomy
- Dropdown trigger (button with selected value)
- Dropdown arrow icon
- Dropdown list container
- List items (options)
- Focus ring for keyboard navigation
- Optional search/filter input
- Optional checkboxes for multiselect

## Layout & Measurements
- Standard height: 40px
- Horizontal padding: 12px
- Vertical padding: 8px
- Border radius: 4px (trigger), 4px (dropdown)
- Focus ring: 2px offset from trigger
- List item height: 32px
- List padding: 4px
- Minimum width: 200px (match trigger width)
- Maximum height: 240px (with scroll)

## Typography
- Header 3: Roboto Regular 32px/40px (large dropdowns)
- Header 5: Roboto Regular 24px/32px (medium dropdowns)
- Body 1 - Medium: Roboto Medium 16px/24px (selected value)
- Body 2: Roboto Regular 14px/20px (options)
- Body 2 - Medium: Roboto Medium 14px/20px (highlighted options)
- Lo Res Body 2: Comic Sans MS 14px/20px (low resolution mode)

## States (Dark Theme)
- Uses semantic tokens that automatically adapt to dark theme
- Text and border colors remain consistent via semantic variables
- Disabled state uses gray tokens for dark theme compatibility
- Open state uses brand colors for clear indication

## Interactions
- Click to open/close dropdown list
- Hover provides visual feedback with border changes
- Focus ring uses brand color for keyboard navigation
- Arrow keys navigate options when open
- Enter/Space to open, Escape to close
- Click outside to close dropdown
- Disabled state prevents interaction

## Accessibility
- Focus ring: 2px brand color border
- Keyboard navigation: Tab to dropdown, Enter/Space to open, Arrows to navigate, Enter to select
- Screen reader support: Proper ARIA attributes (combobox, listbox, option)
- High contrast: Meets WCAG AA standards with provided colors
- Semantic HTML: Use select element or custom combobox with proper roles
- Focus management: Trap focus within dropdown when open

## Variants
- **Default**: Single select dropdown
- **Multiselect**: With checkboxes for multiple selections
- **Searchable**: With search/filter input
- **Disabled**: Non-interactive state
- **Error**: With validation styling
- **Sizes**: Small (32px), Medium (40px), Large (48px)

## Behavior & Guidelines
- Use dropdowns for selecting from a list of options
- Provide clear placeholder text for unselected state
- Implement proper keyboard navigation
- Show selected value clearly in trigger
- Use scroll for long option lists
- Test with screen readers for proper announcement
- Consider search functionality for many options

## Token Gaps / Notes
- All colors use semantic CSS custom properties for theme consistency
- Typography scales are defined via font tokens with proper hierarchy
- Focus states use brand colors for visual consistency
- Disabled states maintain accessibility with proper contrast
- Lo Res mode uses Comic Sans MS for low-resolution displays
- Dropdown positioning should be handled carefully
