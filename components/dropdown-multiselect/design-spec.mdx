## States (Dark Theme)
- Uses semantic tokens that automatically adapt to dark theme
- Text and border colors remain consistent via semantic variables
- Dropdown container maintains visibility in dark theme
- Options adapt to dark theme

## Interactions
- Click input field to open dropdown
- Click options to select/deselect items
- Click checkboxes to select/deselect items
- Click Select All to select all visible options
- Click Clear All to deselect all options
- Hover provides visual feedback on interactive elements
- Focus ring uses brand color for keyboard navigation
- Keyboard navigation: Arrow keys, Enter, Space, Tab, Escape
- Search to filter options (optional)

## Accessibility
- Focus ring: 2px brand color border
- Keyboard navigation: Arrow keys, Enter, Space, Tab, Escape
- Screen reader support: Proper ARIA attributes for multiselect
- High contrast: Meets WCAG AA standards with provided colors
- Semantic HTML: Use select element with multiple attribute
- Focus management: Logical tab order through options
- Selection announcements: Screen reader announces selections

## Variants
- **Default**: Standard multiselect dropdown
- **With Search**: Dropdown with search functionality
- **With Groups**: Options organized in groups
- **Compact**: Reduced size for space-constrained interfaces
- **With Tags**: Selected items shown as tags
- **Virtual**: Virtual scrolling for large option lists
- **With Select All**: With select/clear all functionality
- **With Validation**: With validation error states

## Behavior & Guidelines
- Use multiselect dropdown for selecting multiple options
- Provide clear visual indication of selected items
- Use consistent styling across dropdown variants
- Test with screen readers for proper option announcement
- Consider keyboard navigation for accessibility
- Use responsive design for different screen sizes
- Provide visual feedback for all interactions
- Consider performance for large option lists

## Token Gaps / Notes
- All colors use semantic CSS custom properties for theme consistency
- Typography scales are defined via font tokens with proper hierarchy
- Focus states use brand colors for visual consistency
- Selected states use brand colors for clear indication
- Dark theme adaptation through semantic tokens
- Multiselect dropdown should be responsive and accessible
