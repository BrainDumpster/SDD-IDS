## Anatomy
- Toast container with background
- Toast icon (status indicator)
- Toast title (optional)
- Toast message/content
- Close button (×)
- Focus ring for keyboard navigation
- Optional action button
- Slide-in animation

## Layout & Measurements
- Standard height: Auto (based on content)
- Horizontal padding: 16px
- Vertical padding: 12px
- Border radius: 4px
- Focus ring: 2px offset from toast
- Icon size: 20px × 20px
- Close button: 16px × 16px
- Minimum width: 300px
- Maximum width: 500px
- Spacing between elements: 8px

## Typography
- Display 1/Default: Roboto Light 72px/88px (hero toast titles)
- Body 2: Roboto Regular 14px/20px (toast messages)
- Body 2 - Underline: Roboto Regular 14px/20px (link text)

## States (Dark Theme)
- Uses semantic tokens that automatically adapt to dark theme
- Static colors provide consistent appearance
- Toast colors maintain visibility in dark theme
- Dark backgrounds ensure readability

## Interactions
- Click close button to dismiss toast
- Click toast to focus/activate (optional)
- Hover provides visual feedback on close button
- Focus ring uses brand color for keyboard navigation
- Auto-dismiss after timeout (default behavior)
- Slide-in/out animations
- Keyboard navigation: Tab to toast, Enter to action, Escape to dismiss

## Accessibility
- Focus ring: 2px brand color border
- Keyboard navigation: Tab to toast, Enter for actions, Escape to dismiss
- Screen reader support: Proper ARIA attributes and toast announcements
- High contrast: Meets WCAG AA standards with provided colors
- Semantic HTML: Use proper toast/role attributes
- Focus management: Auto-focus on new toasts
- Dismiss announcements: Screen reader announces when toast is dismissed

## Variants
- **Default**: Standard dark toast
- **Info**: Blue informational toast
- **Success**: Green success toast
- **Warning**: Yellow warning toast
- **Error**: Orange error toast
- **Critical**: Red critical toast
- **With Title**: Toast with heading
- **With Action**: Toast with action button
- **Persistent**: Toast that requires user action
- **Stacked**: Multiple toasts stacked vertically

## Behavior & Guidelines
- Use toasts for non-critical notifications
- Position at top-right or bottom-right of screen
- Auto-dismiss after appropriate timeout (3-5 seconds)
- Provide clear, concise messages
- Include dismiss functionality for user control
- Test with screen readers for proper announcement
- Consider mobile touch interactions
- Use consistent styling across toast types
- Limit number of concurrent toasts

## Token Gaps / Notes
- All colors use semantic CSS custom properties for theme consistency
- Typography scales are defined via font tokens with proper hierarchy
- Focus states use brand colors for visual consistency
- Toast variants use appropriate color psychology
- Dark backgrounds ensure text readability
- Dark theme adaptation through semantic tokens
