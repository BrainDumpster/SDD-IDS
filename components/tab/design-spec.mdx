# Tab Design Spec

## Metadata
- Component: Tab
- Category: Navigation
- Figma: https://www.figma.com/design/VZJ48bbVYrIynw8DdSukWw/-Exploration-only--IDS-with-variables?node-id=11067-54530&m=dev
- Node ID: 11067-54530

## Anatomy
- Tab label (text and optional icon)
- Tab container with border
- Active indicator (bottom border)
- Focus ring for keyboard navigation
- Tab panel content area
- Tab list container

## Layout & Measurements
- Standard height: 40px
- Horizontal padding: 16px
- Vertical padding: 8px
- Border radius: 4px (top corners only)
- Active indicator: 2px bottom border
- Focus ring: 2px offset from tab
- Minimum width: 80px
- Tab spacing: 0px (adjacent tabs)

## Typography
- Body 1: Roboto Regular 16px/24px (tab labels)
- Body 2: Roboto Regular 14px/20px (secondary text)
- Lo Res Body 1: Comic Sans MS 16px/24px (low resolution mode)

## States (Dark Theme)
- Uses semantic tokens that automatically adapt to dark theme
- Surface tokens: `var(--color-background-surface-1)` (#111619), `var(--color-background-surface-2)` (#ffffff)
- Text and border colors remain consistent via semantic variables
- Active indicator uses brand colors for visibility

## Interactions
- Click to activate tab and show corresponding panel
- Hover provides visual feedback with background changes
- Focus ring uses brand color for keyboard navigation
- Active tab shows bottom border indicator
- Keyboard navigation: Arrow keys between tabs, Enter to activate
- Smooth transitions for state changes

## Accessibility
- Focus ring: 2px brand color border
- Keyboard navigation: Tab to tab list, Arrow keys to navigate, Enter/Space to activate
- Screen reader support: Proper ARIA attributes (tablist, tab, tabpanel)
- High contrast: Meets WCAG AA standards with provided colors
- Semantic HTML: Use tablist, tab, tabpanel roles
- Focus management: Proper focus handling between tabs and panels

## Variants
- **Default**: Standard horizontal tabs
- **Vertical**: Stacked vertical orientation
- **Contained**: Tabs with background styling
- **Underline**: Minimal styling with bottom indicator only
- **Icons**: Tabs with icons only or icon + text
- **Disabled**: Non-interactive tabs

## Behavior & Guidelines
- Use tabs to organize related content in the same view
- Ensure tab labels are concise and descriptive
- Provide clear visual indication of active tab
- Maintain consistent tab order and structure
- Test with screen readers for proper announcement
- Consider overflow handling for many tabs
- Use proper focus management for keyboard users

## Token Gaps / Notes
- All colors use semantic CSS custom properties for theme consistency
- Typography scales are defined via font tokens with proper hierarchy
- Focus states use brand colors for visual consistency
- Active states use brand colors for clear indication
- Lo Res mode uses Comic Sans MS for low-resolution displays
- Tab panels should be properly associated with tabs
