# Radio Button Design Spec

## Metadata
- Component: Radio Button
- Category: Formelements
- Figma: https://www.figma.com/design/VZJ48bbVYrIynw8DdSukWw/-Exploration-only--IDS-with-variables?node-id=11067-54579&m=dev

## Anatomy
- Radio input element (native or custom)
- Selected indicator (dot/circle)
- Label text container
- Focus ring for keyboard navigation
- Container wrapper with proper spacing

## Layout & Measurements
- Standard radio size: 16px × 16px
- Label spacing: 8px from radio button
- Touch target: Minimum 44px × 44px for accessibility
- Border radius: 50% (circular for radio buttons)
- Focus ring: 2px offset from radio button
- Selected dot: 6px diameter (centered)

## Typography
- Body 1 - Medium: Roboto Medium 16px/24px (radio labels)
- Body 2: Roboto Regular 14px/20px (secondary text)
- Lo Res Body 2: Comic Sans MS 14px/20px (low resolution mode)

## States (Dark Theme)
- Uses semantic tokens that automatically adapt to dark theme
- Surface tokens: `var(--color-background-surface-1)` (#111619)
- Text and border colors remain consistent via semantic variables
- Disabled state uses gray tokens for dark theme compatibility

## Interactions
- Click selects radio button (deselects others in group)
- Hover provides visual feedback with border/background changes
- Focus ring uses brand color for keyboard navigation
- Disabled state prevents interaction and uses gray colors
- Only one radio can be selected in a group
- Smooth transitions for state changes

## Accessibility
- Focus ring: 2px brand color border
- Touch target: Minimum 44px for mobile accessibility
- Keyboard navigation: Tab to radio group, Arrow keys to navigate, Space to select
- Screen reader support: Proper ARIA labels and group attributes
- High contrast: Meets WCAG AA standards with provided colors
- Semantic HTML: Use native radio element with fieldset/legend for groups

## Variants
- **Default**: Standard radio button with brand colors
- **Error**: Critical state for validation errors
- **Warning**: Info state for warnings
- **Disabled**: Non-interactive state
- **Grouped**: Multiple radios with shared name attribute

## Behavior & Guidelines
- Use radio buttons for single selection scenarios
- Provide clear, concise labels for each option
- Group related radio buttons with fieldset/legend
- Ensure at least one option is selected by default when appropriate
- Use vertical stacking for better readability
- Test with screen readers for proper group announcement

## Token Gaps / Notes
- All colors use semantic CSS custom properties for theme consistency
- Typography scales are defined via font tokens with proper hierarchy
- Focus states use brand colors for visual consistency
- Disabled states maintain accessibility with proper contrast
- Error states use critical color tokens for validation feedback
- Lo Res mode uses Comic Sans MS for low-resolution displays
