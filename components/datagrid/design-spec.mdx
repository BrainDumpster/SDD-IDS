# Datagrid Design Spec

## Metadata
- Component: Datagrid
- Category: Table and Data Grids
- Figma: https://www.figma.com/design/VZJ48bbVYrIynw8DdSukWw/-Exploration-only--IDS-with-variables?node-id=37721-112481&m=dev
- Node ID: 37721-112481

## Anatomy
- Grid container with optional scroll
- Grid header with sortable columns
- Grid body with data rows
- Grid footer (optional)
- Row selection checkboxes
- Sort indicators
- Filter controls
- Column resizing handles
- Pagination controls
- Focus ring for keyboard navigation
- Loading states
- Empty state message
- Context menus

## Layout & Measurements
- Standard row height: 40px
- Header height: 48px
- Cell padding: 10px vertical, 12px horizontal
- Border width: 1px
- Selection padding: 12px
- Checkbox size: 16px × 16px
- Focus ring: 2px offset from cell
- Minimum width: 400px
- Maximum height: 600px (with scroll)
- Column resize handle: 4px width

## Typography
- Header 1: Roboto Regular 48px/58px (large grid headers)
- Header 1/Default: Roboto Light 48px/56px (light grid headers)
- Header 2: Roboto Regular 36px/44px (medium grid headers)
- Base Styles/Data Header: Roboto Medium 14px/20px (grid headers)
- Body 1: Roboto Regular 16px/24px (grid data)
- Body 2: Roboto Regular 14px/20px (secondary data)
- Body 2 - Medium: Roboto Medium 14px/20px (emphasized data)
- Body 3: Roboto Regular 12px/18px (small data)
- Base Styles/Default Text: Roboto Regular 14px/20px (default text)

## States (Dark Theme)
- Uses semantic tokens that automatically adapt to dark theme
- Surface tokens: `var(--color-background-surface-1)` (#f4f4f4)
- Text and border colors remain consistent via semantic variables
- Selected row uses brand colors for clear indication
- Hover states provide visual feedback

## Interactions
- Click header to sort column
- Click row to select/deselect
- Hover provides visual feedback on rows and headers
- Drag column borders to resize
- Right-click for context menu
- Keyboard navigation: Arrow keys to navigate, Space to select
- Checkbox selection for bulk operations
- Filter controls for data filtering
- Pagination controls for large datasets

## Accessibility
- Focus ring: 2px brand color border
- Keyboard navigation: Arrow keys, Enter, Space, Tab
- Screen reader support: Proper table semantics and announcements
- High contrast: Meets WCAG AA standards with provided colors
- Semantic HTML: Use table, thead, tbody, tr, th, td elements
- Sort indicators: Proper aria-sort attributes
- Row selection: Proper aria-selected attributes
- Filter announcements: Screen reader announces filter state

## Variants
- **Default**: Standard datagrid with sorting
- **Selectable**: With row selection checkboxes
- **Sortable**: With sortable columns
- **Resizable**: With resizable columns
- **Filterable**: With filter controls
- **Compact**: Reduced row height
- **Striped**: Alternating row colors
- **Bordered**: Full grid borders
- **Hoverable**: Row hover states
- **Virtual**: Virtual scrolling for large datasets

## Behavior & Guidelines
- Use datagrids for complex data display
- Provide clear column headers with sorting
- Implement proper filtering and searching
- Use responsive design for mobile devices
- Include pagination for large datasets
- Test with screen readers for proper data announcement
- Consider column freezing for wide tables
- Use consistent styling across grid variants
- Implement proper keyboard navigation

- Typography scales are defined via font tokens with proper hierarchy
- Focus states use brand colors for visual consistency
- Row selection uses brand colors for clear indication
- Dark theme adaptation through semantic tokens
- Grid layouts should be responsive and accessible
