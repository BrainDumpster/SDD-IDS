- Item spacing: 16px
- Border radius: 0 (full-width bar)
- Focus ring: 2px offset from element

- Button height: 24px
- Minimum width: 200px

## States (Dark Theme)
- Uses semantic tokens that automatically adapt to dark theme
- Text and border colors remain consistent via semantic variables
- Status bar container maintains visibility in dark theme
- Status indicators adapt to dark theme

## Interactions
- Click status indicators for more information
- Click action buttons to perform actions
- Hover provides visual feedback on interactive elements
- Focus ring uses brand color for keyboard navigation
- Keyboard navigation: Tab to navigate, Enter to activate
- Overflow menu for additional items (optional)
- Resize functionality (optional)

## Accessibility
- Focus ring: 2px brand color border
- Keyboard navigation: Tab, Enter
- Screen reader support: Proper ARIA attributes for status
- High contrast: Meets WCAG AA standards with provided colors
- Semantic HTML: Use status element with proper landmarks
- Focus management: Logical tab order through status items
- Status announcements: Screen reader announces status changes

## Variants
- **Default**: Standard status bar
- **With Progress**: Status bar with progress indicators
- **With Actions**: Status bar with action buttons
- **Compact**: Reduced height for space-constrained interfaces
- **Dark**: Dark themed status bar
- **With Overflow**: Status bar with overflow menu
- **Resizable**: Status bar that can be resized
- **With System Info**: Status bar with system information

## Behavior & Guidelines
- Use status bar for system status and information
- Provide clear visual indication of status states
- Use consistent styling across status variants
- Test with screen readers for proper status announcement
- Consider keyboard navigation for accessibility
- Use responsive design for different screen sizes
- Provide visual feedback for all interactions
- Consider overflow handling for many status items

## Token Gaps / Notes
- All colors use semantic CSS custom properties for theme consistency
- Typography scales are defined via font tokens with proper hierarchy
- Focus states use brand colors for visual consistency
- Status indicators use appropriate color psychology
- Dark theme adaptation through semantic tokens
- Status bar should be responsive and accessible
