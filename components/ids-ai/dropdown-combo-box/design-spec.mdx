## Anatomy
1. `ComboBoxRoot`
2. optional `Label` (`Label:*` + required `*` uses `var(--color-text-neutral-strong)`; label row vertical rhythm `var(--padding-padding-10)` when present per `12730:157002`)
3. `FieldContainer` (input trigger shell; `var(--corner-radius-radius-4)`)
4. `ValueSlot` (placeholder or selected text; flexes; ellipsis overflow for long values)
5. `IndicatorSlot` (caret `arrow-drop-tri-caret`, **`10×10`**; wrapper padding `var(--padding-padding-1)` × `var(--padding-component-padding-dropdown-caret)`)
6. optional `HelperText` (`Body 2`, `var(--color-text-neutral)`)
7. optional `ValidationError` (`status-critical-square-solid` **`16×16`** + `Body 2` `var(--color-text-critical)`)
8. optional `MenuPopup` (`var(--corner-radius-radius-4)`, border `var(--color-border-neutral-light)`, IDS shadow stack)
9. optional `SearchRow` in popup (outer padding `var(--padding-padding-8)`; inner **Search-Main** field `var(--corner-radius-radius-6)`, border `var(--color-border-accessible)`)
10. `OptionList` with option rows (`var(--padding-padding-10)` × `var(--padding-padding-16)`; min hit target **44px**)
11. **Multi-select only:** `SelectAllClearAllRow`, `ClearAllAction`, `ShowSelected` row (`12730:120316`), checkboxes **`16×16`**, optional `ShowSelectedToggle`, scrollbar when overflowing

## Layout & Measurements
- **Root column:** label (optional) → field column → helper/error; label–field horizontal gap `var(--spacing-space-16)`; field–helper gap `var(--spacing-space-4)` (`12730:157002`).
- **Field sizes:**
  - `Large`: **40px** row height; vertical padding `var(--padding-padding-10)`; horizontal `var(--padding-padding-16)`.
  - `Small`: **32px** row height; vertical `var(--padding-padding-6)`; horizontal `var(--padding-padding-16)`.
- **Value / caret:** horizontal gap between value cluster and caret **`var(--spacing-space-10)`**; caret glyph **`var(--sizing-size-10)`**.
- **Focus ring (closed or open trigger):** `1px` outline `var(--color-border-brand-base)`, **`outline-offset: 5px`** (Figma `inset-[-5px]` ring on `12730:157002`).
- **Runtime width:** sample **`300px`**; `max-width` **`700px`**; `min-width` **`186px`**; runtime **`width: 100%`** of host unless product overrides.
- **Menu popup:** width matches trigger; `min-height` sample **252px** where shown; list region scrollable; **Select-all / clear-all** row fixed above scroll list (`29393:143195` symbols).
- **Multi-select filled row:** inner value cluster gap **`var(--spacing-space-4)`** between count badge and truncated label text.
- **Selected-count badge (multi):** height **`var(--sizing-size-18)`**, pill **100px** radius, horizontal padding sample **~5.5px** (use `var(--padding-padding-4)` or nearest token); count type **`var(--font-size-body-3)`**; fill **`var(--color-background-controls-brand-base)`** + border **`var(--color-border-white)`**; **disabled** filled trigger uses badge fill **`var(--color-static-gray-500)`** with same white stroke (`12730:157002` disabled branch).

## Interactions
- Trigger: click / `Enter` / `Space` toggles popup; `Escape` closes and returns focus to trigger.
- List: `ArrowUp` / `ArrowDown` moves highlight; `Enter` commits in single-select; `Space` toggles in multi-select.
- Search: filters visible options; empty search state preserves layout per menu symbol (`Empty Search=True` variants on `29393:143195`).
- Multi: Select All / Clear All / Show Selected semantics unchanged from prior contract; **Clear All** uses disabled text token when nothing selected (`12730:157002`).

## Codegen Contract (Framework-Agnostic Blueprint)
### Deterministic slot schema
1. `ComboBoxRoot`
2. optional `Label`
3. `FieldContainer` → `ValueSlot` + `CaretSlot` (caret padding tokens)
4. optional `HelperText` or `ValidationError`
5. optional `Popup` → optional `SearchRow` → fixed `SelectAllClearAll` (multi) → scroll `ListRows` → optional `ShowSelected` row (multi) → optional footer action

### Supported matrix
- `mode`: `combobox-single | combobox-multi`
- `size`: `small | large`
- `content`: `empty | filled`
- `state`: `default | hover | selected | focus-visible | disabled | error`
- `search`: `enabled | disabled`

### Per-slot style contract
- Trigger: **`var(--corner-radius-radius-4)`**; paddings per size; hover border **`var(--color-border-strong)`**; focus **brand** ring **5px** offset; caret wrapper uses **component padding-dropdown-caret** token pair.
- Menu: **radius-4** shell, **neutral-light** border, shadow stack; search inner field **radius-6**.
- Option rows: **brand-lighter** hover + **inset 1px** **brand-base** top/bottom; checkbox **16×16** in multi list and select-all row.

### Behavior contract
- Single mode emits one selected id; multi mode emits ordered `string[]`.
- Filtering does not mutate source `options`.
- Disabled field blocks open and mutations.

### Accessibility contract
- Trigger: `role="combobox"`, `aria-expanded`, `aria-controls`.
- Listbox / `aria-selected` / `aria-checked` (multi) per prior contract.
- Error/helper: `aria-describedby` when active.

### Asset resolution + bundling contract
- Caret: `arrow-drop-tri-caret` (**10×10**).
- Search: `search-16` (node `44484:581`).
- Error: `status-critical-square-solid` (**16×16**).
- Checkbox / check / dash: `shape-check-checkbox`, `shape-dash-thick` per IDS-AI checkbox spec.

### Fallback/error rules
- Unknown `mode` → `combobox-single`
- Unknown `size` → `large`
- Empty `options` → non-crashing empty list
