## Codegen Contract (Framework-Agnostic Blueprint)
### Deterministic slot schema
`Root` → optional `Label` → `Field` (`Badge?` + `Summary` + `Caret`) → helper/error → `Popup` → `Search?` → `SelectAllClearAll` → `Options` → optional `ShowSelected` → optional `Action`

### Per-slot style contract
- **Badge** on field: **controls brand** fill + **white** border + **body-3** count; **disabled** fill **`var(--color-static-gray-500)`** — distinct from generic “info” badge palette.
- **Checkbox** in list and select-all: **16×16** outer, **`var(--corner-radius-radius-2)`**, tokens per IDS-AI checkbox spec.

### Validation checklist
- [ ] Field + badge match **`12730:157002`** (including disabled gray badge).
- [ ] Caret slot uses **`padding-dropdown-caret`** + **`padding-1`**; value–caret gap **`space-10`**.
- [ ] Focus ring **5px** offset.
- [ ] Menu + search + select-all row match **`29393:143195`** / **`12730:157002`** exports (**radius-6** search field).
- [ ] Select-all row bottom border **`var(--color-border-neutral-light)`**.
- [ ] Show Selected row matches **`12730:120316`**.
- [ ] Checkbox column **`16×16`** in menu list (`12730:157002`).
