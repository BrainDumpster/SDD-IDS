## Anatomy
- `TagRoot` — pill container; owns padding, border, background, and radius **`var(--corner-radius-radius-24)`**.
- `TagPrefixIcon?` — optional alerting glyph (read-only alerting tones).
- `TagLabel` — primary text (`Body 2`); pair with optional **`TagPrefix`** (“`Label:`” pattern) for editable/badge.
- **`TagBadge`** — numeric/status mini-chip (**`Tags with badge`** variant): **before** label row in Figma (`38910:57364`); tokens in **Layout & Measurements**.
- **`TagMenuIndicator?`** — trailing **`arrow-drop-tri-caret`** (**`10×10`**, `var(--color-icon-accessible)`) on **`Tags with badge`** only.
- `TagCloseButton?` — dismiss control; asset **`shape-x-thick`**, **`var(--sizing-size-10)`** (`11666:90408` / `44484:838`).
- `TagEditableField?` — inner focusable text surface for editable/dismissible.

## Interactions
- `read-only`: non-interactive label chip.
- `clickable`: toggles selection (`selected=true|false`).
- `editable/dismissible`: clicking the editable tag body behaves like an input activation surface and moves focus to the inner text field; close action removes tag.
- `badge`: supports optional leading info icon and badge count segment.
- Hover states apply where interaction is enabled (clickable and close button).
- Focus-visible is keyboard-driven and uses outer ring.
- Disabled suppresses click, close, and selection transitions.

## Composition & API (runtime)
- `type: "read-only" | "clickable" | "editable" | "badge"`
- `size: "small" | "large"` (defaults: read-only -> small, others -> large)
- `tone: "none" | "informational" | "success" | "minor" | "major" | "critical"`
- `selected?: boolean` (clickable only; default `false`)
- `disabled?: boolean` (default `false`)
- `error?: boolean` (read-only/editable/badge variants)
- `focusVisible?: boolean` (demo/testing only; runtime driven by keyboard)
- `focusOnText?: boolean` (editable only)
- `label: string`
- `badgeValue?: string | number` (badge only)
- `leadingIconSlug?: string | null`
- `closeIconSlug?: string` (default `shape-x-thick`)
- `onClick?: () => void` (clickable)
- `onDismiss?: () => void` (editable/dismissible)
- `onSelectionChange?: (selected: boolean) => void` (clickable)

## Codegen Contract (Framework-Agnostic Blueprint)
- Deterministic slot order (**branch by `type`**):
  - **`read-only` / `clickable` (unselected or selected) / alerting read-only:** `TagRoot` → `TagPrefixIcon?` → `TagLabel`
  - **`editable`:** `TagRoot` → (`TagEditableField` containing `TagPrefix?` + `TagLabel`) → `TagCloseButton`
  - **`badge` (`Tags with badge`):** `TagRoot` → `TagBadge` (count) → (`TagPrefix?` + `TagLabel`) → `TagMenuIndicator` (caret **`arrow-drop-tri-caret`**, decorative)
- Variant matrix (all supported axes):
  - `type`: read-only | clickable | editable | badge
  - `size`: small | large
  - `tone`: none | informational | success | minor | major | critical
  - `state`: default | hover | focus-visible | error | disabled
  - `selected`: true | false (clickable only)
  - `focusOnText`: true | false (editable only)
- Per-slot style contract:
  - `TagRoot` owns **`var(--corner-radius-radius-24)`**, border, surface, and per-type padding (**8/none** read-only small, **12/4** large / clickable / editable / badge).
  - `TagLabel` uses **`Body 2`**; prefix span uses **`Body 2 - Medium`** where Figma shows “`Label:`”.
  - `TagCloseButton` uses **`var(--sizing-size-10)`** asset footprint.
  - `TagBadge` (**Tags with badge**): **`var(--sizing-size-18)`** tall chip, **`var(--color-background-alerting-info-1)`**, **`var(--color-border-white)`** stroke, count in **`var(--font-size-body-3)`** / **`var(--color-text-white)`**.
  - `TagMenuIndicator`: **`10×10`**, `var(--color-icon-accessible)`.
- Behavior contract:
  - clickable toggles selected state and emits `onSelectionChange`.
  - editable tag body click focuses `TagEditableField` (input-like behavior) before text editing.
  - dismissible emits `onDismiss` and is removable by host list logic.
  - disabled state blocks all emitted events.
  - focus-visible ring appears for keyboard focus with **`4px`** outline gap (Figma **`42065:39233`**).
- Accessibility contract:
  - interactive variants use `button` semantics (or role/button + keyboard parity).
  - selected clickable tags expose `aria-pressed`.
  - dismiss controls expose `aria-label` with tag text context.
  - disabled uses `disabled`/`aria-disabled` consistently.
- Asset resolution + bundling:
  - close icon defaults to `assets/icons/shape-x-thick.svg`.
  - menu indicator uses `assets/icons/arrow-drop-tri-caret.svg` (or equivalent `Icon` primitive).
  - badge-leading icon (if any) resolves from `assets/icons/<slug>.svg`.
  - alerting glyphs map to IDS alert icon assets (e.g., status critical/warn).
- Fallback/error rules:
  - unknown `type` -> `read-only`
  - unknown `size` -> `small` for read-only else `large`
  - unknown `tone` -> `none`
  - if `badgeValue` provided while `type !== "badge"`, ignore `badgeValue`
  - if `selected=true` while `type !== "clickable"`, ignore `selected`
- Validation checklist (pass/fail):
  - [ ] all type variants render valid **branch** slot order (badge row = badge → label → caret).
  - [ ] pill radius uses **`var(--corner-radius-radius-24)`** (not ad-hoc `24px` literals in tokenized targets).
  - [ ] clickable **unselected** uses **component** surface + **brand** border + **neutral** label (Figma `38910:57379`).
  - [ ] **Tags with badge** count chip matches **info-1** fill + **white** border + **body-3** count type.
  - [ ] read-only **`emphasis_light`** alerting tones use **`border-alerting-*-white`** / **`minor-transparent`** per **`38910:51200`** (not fill-matched borders).
  - [ ] disabled blocks click/dismiss/selection events; focus-visible ring uses **`4px`** offset.
  - [ ] clickable **unselected** hover uses **`controls-brand-lighter`**; **selected** hover uses **`controls-brand-strong`** (`42065:39233`).
  - [ ] **editable** disabled pill uses **`gray-lighter`**; **badge** disabled count chip uses **`static-gray-500`** (`42065:39265` / `42065:39247`).
  - [ ] editable focus-on-text path shows field border token.
