- **Hover border (field):** **`var(--color-border-strong)`** (not brand fill on default resting field).
- **Option row:** `var(--padding-padding-10)` vertical, `var(--padding-padding-16)` horizontal; **min height 44px** target.

## Codegen Contract (Framework-Agnostic Blueprint)
### Deterministic slot schema
1. `DropdownSingleSelectRoot` → optional `Label` → `FieldContainer` (`ValueSlot` + `CaretSlot`) → optional helper/error → `MenuPopup` → optional `SearchRow` → `OptionList` → optional sections → optional `ActionRow`

### Supported matrix
- `size`: `small | large`
- `content`: `empty | filled`
- `field-state`: `default | hover | show-dropdown | focus-visible | disabled | error`
- `option-state`: `default | hover | selected | focus-visible | disabled`
- `radio-visibility`: `on | off`
- `search`: `enabled | disabled`
- `sections` / `action-row`: `none | enabled`

### Per-slot style contract
- Field + menu + options token-only; **hover** field border **`var(--color-border-strong)`**; **focus** ring **5px** offset **`var(--color-border-brand-base)`**.
- Option hover uses **`var(--color-background-brand-lighter)`** + **inset 1px** **`var(--color-border-brand-base)`** top/bottom (not `controls-brand-lighter`).

### Behavior contract
- Mutually exclusive selection; disabled options non-interactive; disabled field blocks open.

### Accessibility contract
- Combobox + listbox + `aria-describedby` for error/helper.

### Asset resolution + bundling contract
- `arrow-drop-tri-caret`, `status-critical-square-solid`, optional radio per **IDS-AI radio** spec.

### Fallback/error rules
- Unknown `size` → `large`; invalid `value` → placeholder.

### Validation checklist
- [ ] Size/state matrix aligns with **`12608:95982`** labels and **`12730:157002`** measurements.
- [ ] Option hover/selected rows match **`29392:48763`** + single-select menu symbols on **`29393:143195`**.
- [ ] Search control uses **`var(--corner-radius-radius-6)`** inner field.
- [ ] Focus ring **5px** offset documented behavior matches implementation.
- [ ] Light/dark use semantic variables only.
