## Anatomy
- `MastheadRoot` (`header` landmark)
  - `MastheadBackground` — full-bleed bar fill + bottom hairline (see Layout)
  - `MastheadProductRegion` (left)
    - optional `MastheadProductIcon` (sample **32×32** in Figma `10130:29493`)
    - `MastheadProductName` (text)
  - `MastheadActionsRegion` (right, **54px** tall rail vertically centered in the bar)
    - optional `MastheadIconsCluster` (search, alerts, jobs, settings, help, app launcher — **16×16** glyphs in Figma set)
    - optional `MastheadAppLauncherSlot`
    - `MastheadUserSlot` (initials chip **32×32** or photo / `user-single` variant per **`10130:29944`**)

## Layout & Measurements
- **Bar height:** **`var(--sizing-size-56)`** / **`var(--scale-56)`** (**56px** in Figma `Sizing/size-56` on **`10130:29493`** — not 64px).
- **Horizontal padding:** leading **`var(--padding-padding-16)`** on the product cluster; trailing **`var(--padding-padding-8)`** on the icon rail (Figma `Product Info` `pl-16` + `Icon Area` `pr-8`).
- **Bottom edge:** **`1px`** rule **`var(--border-width-border-default)`** **`var(--color-border-transparent-neutral)`** under the full bar (Figma `Background` layer on **`10130:29493`**).
- **Background fill:** **`var(--color-background-masthead-brand-base)`** across the masthead (Figma main export; do not substitute unrelated gradients for this component unless a separate Figma variant explicitly documents one).
- **Product cluster:** horizontal **`var(--spacing-space-8)`** gap between optional product icon and product name (Figma `gap-[8px]` on `Product Info`).
- **Product name typography:** **`var(--font-size-header-6)`** (**18px**) with **`var(--font-line-height-line-height-32)`** (**32px** line box) and weight **400** (Figma `Roboto` regular on **`10130:29493`**).
- **Actions rail:** height **54px**; each action hit-target uses vertical padding sample **19px** top/bottom with horizontal **`var(--padding-padding-16)`** for standard icons; **User** control uses **`var(--padding-padding-8)`** horizontal and **11px** vertical padding sample (Figma **`10130:29367`** / main **`10130:29493`** `User Settings` column).
- **Icon glyphs:** **16×16** asset frame (`Masthead-Web / *-16` set in Figma).
- **Badges (Jobs / Alerts):** pill height **`var(--sizing-size-18)`**; fill **`var(--color-icon-alerting-success-1)`** (jobs) or **`var(--color-icon-alerting-critical)`** (alerts); stroke **`var(--border-width-border-default)`** **`var(--color-icon-white)`**; count text **`var(--color-text-white)`** at **12px** / **1.758** line metric in export (use caption/body-small token family where available).
- **Avatar chip:** **32×32** circle; initials **Body 2** scale (**14px** / **20px**) in **`var(--color-text-white)`** per **`10130:29944`**.

## Interactions
- Action buttons are native **`button`** elements with optional **`aria-pressed="true"`** (or `:active`) mapping to **Press/Select** background **`var(--color-background-masthead-brand-stronger)`** per Figma.
- App launcher and help icons are **16px** targets; consumer wiring opens menus/popovers (see App Launcher spec).
- Keyboard: **Tab** moves through actions; **focus-visible** shows dashed white ring per state table.

## Composition & API (runtime)
Storybook **`Masthead`** / **`IdsMasthead`** surface:
- **Required:** `productName: ReactNode`, `avatarSlot: ReactNode`
- **Optional:** `logo?: ReactNode`, `iconsSlot?: ReactNode`, `appLauncherSlot?: ReactNode`, plus native **`header`** props.
- **`MastheadActionIconButton`:** `icon: ReactNode`, `aria-label` required for icon-only controls.
- **`MastheadAvatar`:** `initials?: string` **or** `imageSrc` + `imageAlt`.

## Codegen Contract (Framework-Agnostic Blueprint)
- **Slot order:** `MastheadRoot` → `MastheadProductRegion` (icon?, name) → `MastheadActionsRegion` (icons cluster?, app launcher?, user).
- **Variant matrix:** `productIcon` present vs absent; optional badges on Jobs/Alerts; user **Initials** vs **Icon** (`10130:29944`).
- **Style contract:** all masthead chrome uses semantic **`masthead`** / **`text-white`** / **`icon-white`** tokens above; icon assets use **`Masthead-Web / …-16`** naming in Figma — map to **`Icon`** `shapeName` slugs already used in Storybook (`help-circ-16`, `arrow-drop-tri-caret` for launcher, etc.) or inline SVG fallback.
- **Behavior:** left cluster never overlaps actions; actions stay **54px** tall inner rail; bar remains **`width: 100%`**, **`box-sizing: border-box`**.
- **Accessibility:** **`header`** landmark; each **`button`** has discernible name; decorative icons **`aria-hidden`** where paired with labels.
- **Fallbacks:** missing **`logo`** → product name only; missing **`imageSrc`** → initials text in chip.
