## Anatomy
- `PaginationRoot` (`nav` landmark)
- `ResultsPerPageGroup` (optional when `showPerPage`)
  - `ResultsLabel` (`Show:`)
  - `PerPageDropdown` (trigger + listbox menu, caret `arrow-drop-tri-caret`)
  - `ResultsSuffix` (`per page`)
- `PageNavigationGroup` when `totalPages > 1`:
  - If `showFirstLast`:
    - **First page (`currentPage === 1`):** `FirstPageButton` (`double-chev-left`, disabled) → **omit** `PrevPageButton` from the row (Figma `48815:220952` “1 of 16”; previous is not shown beside first).
    - **Other pages:** `FirstPageButton` → `PrevPageButton` (`chev-left`) → …
  - If `!showFirstLast`: `PrevPageButton` first (no first/last buttons).
  - **`PageInput`** (default): native **text field** for current page (`48815:220952` TextBox) — **not** a dropdown and **no** caret.
  - **`PageOffsetDropdown`** (optional only when `showPageOffset` is `true`): listbox-style page picker for product-specific layouts; **not** part of the default Figma page-number row.
  - `PageCountText`: `of {totalPages}` with exactly one space after `of`.
  - `NextPageButton` (`chev-right`) → optional `LastPageButton` (`double-chev-right`) when `showFirstLast`.
- `PageNavigationGroup` when `totalPages === 1`:
  - Only `PageCountText` as the literal **`1 page`** (no icons, no page field, per Figma `48815:220952` “1 page only”).

## Layout & Measurements
- Main row (`Pagination - Main`, `48815:220984`):
  - Height: `48px`
  - Horizontal padding: `24px` left, `32px` right (`var(--padding-padding-24)` / doubled right token as implemented: `calc(var(--padding-padding-16) * 2)` in Storybook CSS — treat as **32px** right sample).
  - Border: `1px solid var(--color-border-accessible)`
  - Background modes: `none` → `var(--color-background-component)`; `gray` → `var(--color-background-surface-1)`.
- Results-per-page group: Figma sample gap `~15.5px` between label cluster pieces; runtime uses `var(--spacing-space-16)` (nearest token).
- Page-navigation group gap: `var(--spacing-space-16)` (Figma `16px`).
- Page input (`48815:220952` / TextBox):
  - Width: **`52px`** (Storybook / product target; one Figma export samples `40px` — use **52px** for comfortable two-digit entry).
  - Height: `32px`
  - Inner padding: vertical sample `5px` / `6px`, horizontal `var(--padding-padding-16)` (editable numeric entry; no dropdown caret).
- Per-page / page-offset **dropdown** triggers only: inner horizontal `gap` between value and caret `var(--spacing-space-10)` (Figma `10px` on those containers).
- Page count text: `Body 2` (`14px` / `20px`); `of {totalPages}` uses `var(--color-text-neutral-strong)`.
- Per-page dropdown trigger: width `90px`, height `32px`, square corners (`border-radius: 0`).
- Menus (per-page + page-offset): width matches trigger, square corners, `1px` border `var(--color-border-accessible)`.
- Menu elevation: dual drop shadow per the Elevation bullet under Tokens (drop-shadow-4 stack, then drop-shadow-2 stack).

## Interactions
- First / previous / next / last call `onPageChange` with clamped page when not `disabled`.
- At first page: first + previous disabled; when `showFirstLast`, previous control is **not rendered** (Figma parity).
- At last page: next + last disabled.
- Page input: digits only; commit on `Enter` or blur; clamp to `[1, totalPages]`.
- Per-page menu: choosing an option calls `onPageSizeChange` and closes menu.
- Page-offset menu: choosing an option updates **current page** via `onPageChange` / internal state and closes menu.
- `dropdownState` / `pageOffsetDropdownState` may force `expanded-below` | `expanded-above` for Storybook/docs (overrides open state when not `collapsed`).

## Responsiveness
- `PaginationRoot` is container-driven (`width: 100%`, `box-sizing: border-box`); sample Figma width is not a runtime constraint.
- Host applications may hide `ResultsPerPageGroup` before page controls on narrow layouts; this repo Storybook implementation keeps a single flex row.

## Composition & API (runtime)
Matches `IdsPagination` / `IdsPaginationProps` in Storybook:
- **Required:** `currentPage`, `totalPages`
- **Optional:** `onPageChange`, `pageSize`, `pageSizeOptions`, `onPageSizeChange`, `showPerPage` (default `true`), `showFirstLast` (default `true`), `showPageOffset` (default `false`), `pageOffsetOptions`, `dropdownState`, `pageOffsetDropdownState`, `background` (`"none" | "gray"`), `disabled`, plus native `nav` attributes via `ComponentProps<"nav">`.

## Codegen Contract (Framework-Agnostic Blueprint)
- **Slot order:** `PaginationRoot` → optional `ResultsPerPageGroup` → `PageNavigationGroup`.
- **Variant matrix:** `background`: `none | gray`; `totalPages === 1` vs `> 1`; `showFirstLast`; `showPerPage`; `showPageOffset`; menu `collapsed | expanded-below | expanded-above`; row `default | hover | press | selected` inside menus.
- **Per-slot styles:** use semantic tokens in Layout/Tokens/States; square corners on triggers and menus (`border-radius: 0`); **`PageInput`** outer width **`52px`** × **`32px`** height.
- **Behavior:** normalize `totalPages` to at least `1`; clamp `currentPage`; empty `pageSizeOptions` → `[25, 50, 75, 100]`; transparent top/bottom borders on menu rows in default state to prevent layout shift.
- **Accessibility:** root `nav` with accessible name (default `"Pagination"`); `aria-expanded` on dropdown triggers; `role="listbox"` / `role="option"` / `aria-selected` on menu rows; disabled controls use native `disabled`.
- **Assets:** `Icon` with `shapeName` values: `arrow-drop-tri-caret`, `double-chev-left`, `chev-left`, `chev-right`, `double-chev-right`.
- **Fallbacks:** unknown `pageSize` not in options coerces to first option; invalid page input on blur resets display to current page.
