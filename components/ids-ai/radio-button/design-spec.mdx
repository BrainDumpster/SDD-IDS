## Anatomy
- **groupRoot** (optional): semantic grouping wrapper for radio collections.
- **root**: one radio row item (control + label).
- **input**: native `input[type="radio"]`.
- **controlOuter**: circular visual ring (16x16).
- **controlInnerDot**: selected indicator dot (centered).
- **label**: associated text.
- **assistiveText** (optional): helper/error copy.

## Layout & Measurements
- **Outer control:** **`16px × 16px`** (`8505:14225` + `get_variable_defs`).
- **Shape:** circle — **`border-radius: 50%`** (Figma variable **`Corner Radius/radius-20`** applies to the **focus** affordance ring geometry, not a square control).
- **Selected dot:** **`8px × 8px`** (`Sizing/size-8`), centered (**4px** inset from outer ring to dot center).
- **Label gap:** **`var(--spacing-space-8)`** between control and label.
- **Min hit area:** **`44px`** min-height on the full radio **row** (wrapper); control stays **16×16** (Storybook: `.wrapper { min-height: 44px; }`).
- **Focus-visible ring (Figma `8505:14225` export):** **`1px`** border **`var(--color-border-brand-base)`** on a **`22×22`** px ring centered around the **16×16** control (**≈3px** inset from ring outer edge to control outer edge). CSS parity: **`outline: var(--border-width-border-1) solid var(--color-border-brand-base)`** + **`outline-offset: 3px`** on the **16×16** `Radio.Root`.

## Interactions
- Click on a radio selects it and deselects sibling radios with the same `name`.
- Radio is single-select in group; one selected value at a time.
- Hover trigger area is the full radio row hit target (control + label), not only the 16x16 control:
  - Unselected hover: border shifts to `var(--color-border-strong)` while background remains `var(--color-background-component)`.
  - Selected hover: border/icon shift to hover tokens while fill stays `var(--color-background-component)`.
- Keyboard:
  - `Tab`: enters/leaves group,
  - `Arrow` keys: move selection among enabled radios in group,
  - `Space`: select focused radio.
- Disabled radios are skipped by selection changes and cannot be activated.

## Composition & API (runtime)

### Aggregate component (`RadioButton` — matches `storybook/src/components/RadioButton.tsx`)
| Prop | Required | Behavior |
|---|---|---|
| `name` | Yes | Shared group id for single-selection behavior. |
| `options` | Yes | Array of option objects (see below). |
| `value` | No | Controlled selected value (string matching one option `value`). |
| `defaultValue` | No | Initial selected value when uncontrolled. |
| `onChange(value)` | No | Fires with the new value when selection changes. |
| `disabled` | No | When true, disables the entire group (merged with per-option `disabled`). |
| `orientation` | No | `vertical` (default) or `horizontal` layout of option rows. |
| `id` | No | Optional id prefix for assistive text ids. |

### Option object (`options[]` items)
| Field | Required | Behavior |
|---|---|---|
| `value` | Yes | Unique value within the group. |
| `label` | Yes | Visible label for the option row. |
| `disabled` | No | Disables this option only. |
| `error` | No | Error border/label styling for this option. |
| `helperText` | No | Helper or error line under the option row. |
| `simulatedState` | No | **Docs / Storybook only**: `"hover"` or `"focus-visible"` to pin visuals for matrices; must not replace real `:hover` / `:focus-visible` in production defaults. |

### Low-level per-radio mapping (for codegen from options)
Each option maps to one radio row: `value`, `label`, `disabled`, `error`, `helperText`, and optional `simulatedState` as above. Controlled selection is expressed at the group level via `value` / `defaultValue`, not per-option `checked`.

## Codegen Contract (Framework-Agnostic Blueprint)
### Deterministic structure
- `groupRoot` (optional)
  - `radioItem[]`
    - `input`
    - `controlOuter`
      - optional `controlInnerDot`
    - `label`
    - optional `assistiveText`

### Supported matrix
- Selection: unselected | selected.
- Interaction: default | hover | focus-visible | disabled.
- Validation: default | error.
- Mode: controlled | uncontrolled.
- Group behavior: standalone | grouped single-select.

### Style contract
- Control stays circular and **16×16** across states.
- Dot appears only when selected; default dot fill **`var(--color-background-controls-brand-base)`**; selected **hover** dot uses **`var(--color-icon-brand-strong)`** per **`8505:14225`** export.
- Label spacing stays **`var(--spacing-space-8)`**; row **`min-height: 44px`** for hit target.
- Focus-visible ring: **`1px`** **`var(--color-border-brand-base)`** + **`outline-offset: 3px`** (Figma **`22×22`** ring around **16×16** control).
- Error (unselected): border **`var(--color-border-alerting-critical-base)`** (Storybook parity with checkbox invalid control).
- Optional `data-simulated-state` (or equivalent) on the control root may apply harness-only hover/focus visuals; strip or no-op in production unless used for documented fixtures.
- No hardcoded values for color/border/typography.

### Behavior + accessibility contract
- Native radio semantics preferred.
- Group semantics:
  - radios share `name`,
  - optionally wrapped in `fieldset` + `legend`.
- ARIA/semantic expectations:
  - input `type="radio"` handles role/checked state,
  - `aria-disabled` when disabled,
  - helper/error text associated with `aria-describedby` when present.

### Fallback/error rules
- If multiple radios are `checked=true` in controlled data, first checked wins; warn.
- If no radio selected in required group, generator should support explicit validation state.
- Missing `label` on any option is invalid for accessibility; generator must warn.
- `simulatedState` must not be emitted as the only focus/hover implementation for end users; it is for Storybook/state matrices only.

### Validation checklist
- [ ] Single-selection group behavior is deterministic.
- [ ] Full state matrix is token-mapped to **`8505:14225`** (including **error** unselected border).
- [ ] Focus ring matches Figma (**`22×22`** ring ≈ **`outline-offset: 3px`** on **16×16** control).
- [ ] **44px** row min-height on interactive wrapper.
- [ ] Focus-visible and keyboard navigation work for grouped radios.
- [ ] Disabled radios are non-interactive and correctly styled.
- [ ] Label/input association passes accessibility checks.
- [ ] Dark theme values resolve through semantic tokens only.
