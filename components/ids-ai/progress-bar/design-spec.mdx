## Anatomy
- `ProgressRoot` (column stack; width follows container)
- optional `MetaRow` (label + percentage; **Determinate/regular** with label only — indeterminate omits the percent value in Figma)
- `ProgressTrack` (neutral track + accessible stroke)
- `ProgressIndicator` (fill segment; determinate width from value; indeterminate animated segment)
- optional `HelperRow` (16×16 status icon + **Body 2** helper copy when product enables helper messaging)

Deterministic order:
1. `ProgressRoot`
2. optional `MetaRow`
3. `ProgressTrack` → `ProgressIndicator`
4. optional `HelperRow`

## Layout & Measurements
- **Width:** `width: 100%`; `box-sizing: border-box` on the root where applicable. Figma sample frames use fixed widths (e.g. `300px`) — runtime width is container-driven.
- **Track inner height (fillable area) by thickness** (Figma `Sizing/size-*` on `11099:57185` export):
  - **thin:** `var(--sizing-size-4)`
  - **medium:** `var(--sizing-size-8)`
  - **thick:** `var(--sizing-size-16)`
- **Track chrome:** outer border `var(--border-width-border-default)` solid `var(--color-border-accessible)`; corner radius `var(--corner-radius-radius-2)`; track fill `var(--color-background-gray-light)`.
- **Indicator:** fills track height; corner radius `var(--corner-radius-radius-2)`; `var(--border-width-border-default)` stroke on the bar using the same semantic token family as fill (see state tables).
- **Vertical rhythm (Determinate/regular + helper):**
  - **Meta row → track:** `var(--spacing-space-8)` (Figma inner column `gap` between label row and track).
  - **Track → helper row:** `var(--spacing-space-4)` (Figma outer column `gap` between the stacked block and standalone helper line).
- **Helper row:** row `gap` between icon and text: `var(--spacing-space-8)`; icon slot **16×16** (`status-ok-circ-solid`, `status-warn-tri-solid`, `status-critical-square-solid` semantics in Figma).
- **Typography:** label + percent + inline percent use **Body 2** — `var(--font-size-body-2)` / `var(--font-line-height-line-height-20)` / `var(--color-text-neutral-strong)` for label row; helper line body uses `var(--color-text-neutral)`.
- **Indeterminate segment:** Figma in-progress indeterminate bar uses approximately **60%** of track width (`inset-[0_19.95%]` on the brand segment in the MCP export); implement as **`width: 60%`** of the track with a continuous translate animation (timing product-tunable; Storybook uses ~`1.1s` ease-in-out loop).

## Interactions
- Default presentation is **non-interactive** (display-only). No hover/press surface on the track in Figma.
- When the host makes the control focusable (rare), use the product focus ring contract (`var(--color-border-brand-base)` outline) — not shown on the primary Progress Bar component set in the reviewed node.
- Determinate value changes animate indicator width (implementation uses a **300ms** ease transition unless product overrides).
- Indeterminate mode runs a continuous horizontal motion on the indicator segment until resolved to determinate or unmounted.

## Composition & API (runtime)
| Prop / slot | Required | Behavior |
|---|---|---|
| `type` | No | `"inline"` \| `"with-label"` \| `"indeterminate"` (default `"inline"`). Maps to Figma **Determinate/Inline**, **Determinate/regular**, **Indeterminate**. |
| `thickness` | No | `"thin"` \| `"medium"` \| `"thick"` (default `"medium"`). Maps to **Thin / Medium / Thick** track heights. |
| `state` | No | `"in-progress"` \| `"completed-success"` \| `"completed-warning"` \| `"failed-error"` (default `"in-progress"`). Maps to Figma status naming above. |
| `value` | No | `0`–`100` for determinate; ignored when `type === "indeterminate"`. |
| `label` | No | Visible when `type === "with-label"`; also feeds accessible name fallback. |
| `helperText` | No | Shown when `showHelperText` is true; **Body 2** neutral. |
| `showHelperText` | No | Default `false`. |

## Codegen Contract (Framework-Agnostic Blueprint)
### Deterministic structure
- `ProgressRoot`
  - optional `MetaRow` (`Label`, `ValueText`)
  - `ProgressTrack`
    - `ProgressIndicator`
  - optional `HelperRow` (`StatusIcon`, `HelperText`)

### Supported matrix
- `type` × `thickness` × `state` as declared in Composition; all combinations valid; indeterminate forces animated indicator and omits percent value in **with-label** meta row (label may still show).

### Style contract
- Track and indicator radii: **`var(--corner-radius-radius-2)`** only.
- Track fill **`var(--color-background-gray-light)`**; track stroke **`var(--color-border-accessible)`** at **`var(--border-width-border-default)`** — unchanged across success/warning/error (Figma keeps accessible stroke on the track shell; alerting strokes belong on the **indicator** only).
- Indicator always uses a **1px** semantic border matching its fill family (brand / success / minor / critical).
- Thickness maps strictly to **`var(--sizing-size-4)`**, **`var(--sizing-size-8)`**, **`var(--sizing-size-16)`** inner track heights.
- Meta / helper spacing: **`var(--spacing-space-8)`** under meta; **`var(--spacing-space-4)`** before helper row; helper icon gap **`var(--spacing-space-8)`**.

### Behavior + accessibility
- Expose **`role="progressbar"`** for determinate modes with **`aria-valuemin="0"`**, **`aria-valuemax="100"`**, **`aria-valuenow`** (integer clamped).
- Indeterminate: **`aria-busy="true"`** recommended; omit **`aria-valuenow`** or use platform-appropriate indeterminate pattern.
- Provide an accessible name (`aria-label` / visible label) whenever context is not obvious.

### Asset resolution
- Helper icons are **inline vector** stand-ins for Figma **`1-Solid / status-*`** assets; bundle as SVG or CSS shapes; tint with `var(--color-icon-alerting-success-1)`, `var(--color-icon-alerting-minor-1)`, and `var(--color-icon-alerting-critical)` (see Tokens).

### Fallback / error rules
- Unknown `type` → `"inline"`.
- Unknown `thickness` → `"medium"`.
- Unknown `state` → `"in-progress"`.
- `value` out of range → clamp to `[0, 100]`.
- Missing tokens at runtime → follow global theme fallback policy (no hex literals in generated component code).

### Validation checklist
- [ ] Track uses **`var(--color-background-gray-light)`** + **`var(--color-border-accessible)`** + **`var(--corner-radius-radius-2)`** in all states.
- [ ] In-progress indicator uses **`var(--color-background-brand-base)`** + **`var(--color-border-brand-base)`** (not `controls-brand-base` on the bar).
- [ ] Success indicator uses **`var(--color-background-alerting-success-1)`** + **`var(--color-border-alerting-success-base)`**.
- [ ] Warning / error indicators use minor / critical fill + matching border tokens from the state tables.
- [ ] Thickness uses **`var(--sizing-size-4|8|16)`** only.
- [ ] Meta→track **`var(--spacing-space-8)`**; track→helper **`var(--spacing-space-4)`**; helper row gap **`var(--spacing-space-8)`**.
- [ ] Indeterminate segment width ~**60%** of track with continuous motion.
- [ ] Light/dark use the same semantic variable names (no duplicate hex documentation in spec tables).
