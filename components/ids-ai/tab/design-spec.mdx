## Anatomy
- `TabRoot` (optional host chrome for **elevated** vs **transparent** surface)
- `TabList` (`role="tablist"`)
- `TabItem` (interactive tab control)
  - `TabLabelCluster` (icon + label + optional badge; single horizontal cluster)
  - optional trailing affordances (e.g. close control)
- optional `OverflowTrigger` + `OverflowMenu`
- optional `AddTabTrigger`
- `TabPanel` / `TabPanels` for active content

## Layout & Measurements
- **Root:** `width: 100%`, `box-sizing: border-box`; tab row is horizontal and non-wrapping by default.
- **Tab cell height:** **38px** total row height in Figma (`Tab-Main` / `Tab-Element` exports).
- **Tab cell horizontal padding:** `var(--padding-padding-24)` (Figma `Padding/padding-24`).
- **Tab cell vertical padding:** **9px** top and bottom in Figma (no dedicated semantic token in the current IDS-AI map — record as **fixed layout** from **`9838:25683`**; implementations may keep **`9px`** until a spacing token aligns).
- **Gap inside `TabLabelCluster`:** `var(--spacing-space-8)` between icon, label text, and badge (Figma inner `gap-[8px]`).
- **Gap between `TabLabelCluster` and trailing affordances** (e.g. close control): `var(--spacing-space-24)` (Figma outer row `Spacing/space-24` between major slots).
- **Typography:** **Body 2** — `var(--font-size-body-2)` / `var(--font-line-height-line-height-20)` / weight **400**.
- **Selected indicator:** thickness **`var(--border-width-border-thick)`** (**2px**); color **`var(--color-border-brand-dark)`** (Figma “Top Border” / “Bottom Border” on selected states — **not** `var(--color-text-brand-strong)`).
- **Placement:** **Primary** selected indicator is a **top** edge bar; **Secondary** selected indicator is a **bottom** edge bar (same thickness and token).
- **Baseline / row chrome:** continuous **`var(--border-width-border-default)`** (**1px**) rules using **`var(--color-border-accessible)`** for inactive baseline and vertical separators as defined in the Tab-Main frame (e.g. **`11482:99209`** “Tab group border” + per-cell bottom border in **`9838:25683`**).
- **Focus ring (Selected Focus / Unselected Focus):** **`var(--border-width-border-thick)`** stroke **`var(--color-border-brand-base)`**, corner **`var(--corner-radius-radius-4)`** (Figma `Border Width/border-thick` + `Color/Border/Brand-Base` + `Corner Radius/radius-4`). Figma uses slightly different `inset` per style/transparent combination; implementations should match **inset focus** inside the 38px row without clipping the **brand-dark** selected bar.
- **Primary left rail (Figma):** **Primary** tabs show an additional **`1px`** **`var(--color-border-accessible)`** vertical rail on the **leading** edge (full-height when selected; **`var(--sizing-size-24)`**-tall centered segment when unselected in the **`9838:25683`** export). **Secondary** composition omits that rail in the same export set. Reference Storybook CSS implements this on **`.tabPrimary::before`**; the **primary selected top `brand-dark` segment** uses an **inset `box-shadow`** so it does not compete with that pseudo-element. The **primary `More` trigger** (`.moreTriggerPrimary`) uses the same rail + top-segment pattern.
- **Transparent host (`transparent=true` in Figma):** tab **fill** is **transparent** for default/selected/unselected-focus/selected-focus cells; **hover** uses `var(--color-background-brand-lighter)`; **press** uses `var(--color-background-brand-light)`. **Non-transparent** host uses `var(--color-background-surface-2)` for those “solid” cells in the export. Storybook **`TransparentOnGray`** uses a host strip of **`var(--color-background-gray-light)`** so transparent cells read against a neutral page band (matches Figma “on grey” documentation rows).
- **Overflow / add-tab:** composition variants under **`9838:27827`**; row geometry stays **38px** with the same padding and token rules on triggers that read as peers in the tab list.

## Interactions
- Click activates one tab; keyboard: **ArrowLeft** / **ArrowRight**, **Home** / **End**, **Enter** / **Space** per the Composition API and WAI-ARIA tabs pattern.
- Overflow (`More`) and add-tab behaviors match the prior product contract (see Composition): hidden items collapse behind **More**; choosing a hidden tab updates the trigger label; choosing a visible tab resets the trigger to **`moreLabel`**.
- Tab switches do not auto-save data unless the product adds that behavior outside the component.

| Slot / prop | Required | Behavior |
|---|---|---|

| `moreLabel` | No | Overflow trigger fallback (**`"More"`**). |

## Codegen Contract (Framework-Agnostic Blueprint)
### Deterministic slot order
1. `TabRoot`
2. `TabList`
3. `TabItem` (×N) + optional `OverflowTrigger` + optional `AddTabTrigger`
4. `TabPanel` (active)

### Style contract (token-only)
- Tab row height **38px**; horizontal padding **`var(--padding-padding-24)`**; vertical padding **9px** (fixed from Figma until a token exists).
- **`TabLabelCluster`:** `gap: var(--spacing-space-8)`; icon **16×16** when present.
- **Gap** between label cluster and close (or other trailing controls): **`var(--spacing-space-24)`**.
- **Selected indicator:** **`var(--color-border-brand-dark)`** at **`var(--border-width-border-thick)`**; **secondary →** a true **`::before`** / **`::after`** bar along the **bottom** edge. **Primary → top** edge: prefer **inset `box-shadow`** (or equivalent) so the **leading rail** can occupy **`::before`** without stacking conflicts.
- **Focus-visible:** `outline: none` + inset ring (or equivalent) using **`var(--border-width-border-thick)`** **`var(--color-border-brand-base)`** and **`var(--corner-radius-radius-4)`** without obscuring the **brand-dark** selection bar.
- **Baseline:** **`var(--border-width-border-default)`** **`var(--color-border-accessible)`**.

### Behavior + accessibility
- One selected `tab`; `aria-selected`, `aria-controls`, `tabpanel` / `aria-labelledby`.
- Overflow trigger is a **button** with `aria-expanded` when open.

### Asset / badge contract
- Optional icons from product asset pipeline; badge uses **`var(--color-background-alerting-critical)`** + **`var(--color-border-white)`** + **`var(--color-text-white)`** for the count.

### Fallback / error rules
- Unknown `variant` → **`"secondary"`**.
- Unknown `surface` → **`"elevated"`**.
- Invalid `defaultActiveTabId` → first non-disabled item.

### Validation checklist
- [ ] **Primary** selection uses a **top** **`var(--color-border-brand-dark)`** bar; **Secondary** uses a **bottom** bar — both **`var(--border-width-border-thick)`**.
- [ ] **Primary** leading **`1px`** **`var(--color-border-accessible)`** rail on every primary tab and primary **More** trigger: **centered `var(--sizing-size-24)`** when unselected, **full cell height** when selected (Storybook: **`::before`** + top segment via **inset `box-shadow`**).
- [ ] Selected indicator color is **`var(--color-border-brand-dark)`**, not text color tokens.
- [ ] Focus ring uses **`var(--color-border-brand-base)`** + **`var(--border-width-border-thick)`** + **`var(--corner-radius-radius-4)`**.
- [ ] Padding uses **`var(--padding-padding-24)`**; inner label gap **`var(--spacing-space-8)`**; gap before close **`var(--spacing-space-24)`**.
- [ ] **Transparent** vs **elevated** host behavior matches the Figma **`transparent`** axis for idle fills.
- [ ] Light and dark tables stay structurally parallel and token-only.
