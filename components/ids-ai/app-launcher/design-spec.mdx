## Anatomy
- `AppLauncherRoot` (popover host)
- `AppLauncherTrigger` (`grid-square-9-16`; **`masthead`** vs **`default`** visual modes)
- `AppLauncherSurface` (menu panel)
  - optional `ProductRegion` — rows of **`ProductTile`** (`.AppLauncher-Element`), **148×125** cells
  - optional **column / row dividers** (dotted; **solid** vertical divider only for **2 products, no options** scenario per implementation parity with Figma sample)
  - optional `OptionsRegion` — list rows below products (or options-only)
  - optional `FooterAction`

## Layout & Measurements
- **Surface outer border (Figma `AppLauncher-Main` export):** `var(--border-width-border-default)` **`var(--color-border-neutral-light)`** — not the “accessible” token name in this frame’s binding (light theme hex matches legacy samples; dark resolves via theme).
- **Surface padding shell:** `var(--padding-padding-1)` on the outer launcher chrome where Figma applies `p-[1px]` (`13231:123761`).
- **Shadow (“Shadow 1”):** two drop layers in Figma order: **first** `var(--shadow-drop-shadow-2-{x,y,blur,spread,color})`, **then** `var(--shadow-drop-shadow-4-{x,y,blur,spread,color})` (see Tokens).
- **Product count → surface size (from `13231:123761` variant set + scenarios `42266:95085`):**
  - **1 product:** **150×127** compact surface.
  - **2 products:** **298×127**.
  - **3 or 4 products:** **298×254**.
  - **8 products:** **298×416** (includes options block height in composed scenario).
- **Product tile:** **148×125**; inner label stack **`var(--padding-padding-28)`** vertical padding sample, **`var(--spacing-space-12)`** between **32×32** icon slot and label when icon present.
- **Label:** **Body 2** — `var(--font-size-body-2)` / `var(--font-line-height-line-height-20)`; **max width 111px**; ellipsis.
- **No-icon tile (`13231:109521` “No Icon”):** vertical **`var(--padding-padding-52)`** on the label stack and **0** gap between missing icon and text (icon slot omitted).
- **Dividers:** vertical dotted separator geometry **93px** tall centered in the **125px** row; horizontal dotted rule **262px** wide centered between rows (implementation uses CSS dashed borders with **`var(--color-border-neutral-light)`** aligned to the same visual role as Figma divider components).
- **Product grid → options (`42266:95081` / `AppLauncher-Main`):** after the last horizontal row divider, **`var(--padding-padding-1)`** (frame `gap-px`) then **`var(--padding-padding-16)`** before the first option row (matches **`Dropdown-SingleSelect-Elements-Menu`** inner **`py-[16px]`** wrapper in Figma).
- **Options row (`12579:19717` / embedded rows in `13231:123761`):** padding **`var(--padding-padding-10)`** vertical, **`var(--padding-padding-16)`** leading, **`var(--padding-padding-24)`** trailing; inner row gap **`var(--spacing-space-8)`**; typography Body 2 **`var(--color-text-neutral)`** default.
- **Default trigger (non-masthead):** bordered control in Storybook uses **`var(--color-border-light)`** on the trigger chip (implementation); masthead trigger defers to **Masthead** action token set.

## Tokens
- **Surface / product:** `var(--color-background-surface-2)`, `var(--color-background-brand-lighter)`, `var(--color-background-brand-light)`, `var(--color-background-component)` (options block).
- **Borders:** `var(--color-border-neutral-light)` (launcher shell + structural dividers per Figma export), `var(--color-border-brand-neutral)` (option row hover/press inset emphasis), `var(--border-width-border-default)`.
- **Text / icon:** `var(--color-text-neutral-strong)`, `var(--color-text-neutral)`, `var(--color-text-brand-strong)`; `var(--color-icon-neutral-strong)`, `var(--color-icon-brand-strong)` (press/selected tile glyph).
- **Trigger (masthead):** `var(--color-background-masthead-brand-base)`, `var(--color-background-masthead-brand-strong)`, `var(--color-background-masthead-brand-stronger)`, `var(--color-text-white)` for `grid-square-9-16` when `triggerVariant === "masthead"`.
- **Elevation:** composite `box-shadow` in this order:
  1. `var(--shadow-drop-shadow-2-x)` `var(--shadow-drop-shadow-2-y)` `var(--shadow-drop-shadow-2-blur)` `var(--shadow-drop-shadow-2-spread)` `var(--shadow-drop-shadow-2-color)`

- **Radius (options menu reference in Figma):** `var(--corner-radius-radius-4)` on the detached menu component; launcher surface in matrix uses **0** corner radius on the outer panel.

## Interactions
- Trigger opens/closes popover; **`sideOffset`** controls vertical gap (px). With **`triggerVariant="masthead"`**, **`0`** still resolves to a **1px** offset so the surface clears the masthead bottom border; larger values are unchanged.
- Product tile activates link or `onSelect`; options call `onSelect`.
- Keyboard: **Tab** through trigger, tiles, options; **Escape** closes (Base UI `Popover` behavior).

## Composition & API (runtime)
`AppLauncher` / `AppLauncherProductTile` / `AppLauncherOptionsList` in Storybook:
- **`products` / `apps`:** `{ id?, name, icon?, href?, onSelect? }[]` — pass **`icon={null}`** to render **no-icon** tile (default shield only when **`icon` is `undefined`**).
- **`options`**, **`footerAction`**, **`columns`**, **`triggerVariant`**, **`sideOffset`**.

## Codegen Contract (Framework-Agnostic Blueprint)
- **Slot order:** Root → Trigger → Surface → `ProductRegion?` → `OptionsRegion?` → `FooterAction?`.
- **Matrix:** product counts **0 | 1 | 2 | 3 | 4 | 8**; **`triggerVariant`** `default | masthead`; **with / without** options; **2 products + no options** → solid inter-column divider.
- **Assets:** trigger **`grid-square-9-16`**; default product **`shield-encrypt-alt`** when `icon` omitted.
- **Validation:** surface border token, shadow order, tile dimensions, product→options **`padding-padding-1` + `padding-padding-16`** under top separator, option padding, **`icon === null`** no-icon path, light/dark semantic parity.
