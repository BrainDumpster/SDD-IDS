## Anatomy

- **trigger anchor**: UI element that owns tooltip visibility.
- **tooltip root**: container that holds content and arrow.
- **content panel**: rounded rectangle with tooltip text (and optional title/close).
- **title (optional)**: `Tooltip Title`.
- **body copy**: primary descriptive text.
- **dismiss button (optional)**: close icon shown for dismissible variant.
- **arrow (optional)**: directional pointer for placement alignment.

## Layout & Measurements

### Core sizes (from inspected instances)
- **No Title** (`Show Title=false`, arrow on): overall `240x115`; content `240x104`; arrow lane `240x12`.
- **With Title** (`Show Title=true`, non-dismissible): overall `240x139`; content `240x128`; arrow lane `240x12`.
- **Dismissible + Title** (`Show Dismissable=true`): overall `264x139`; content `264x128`; arrow lane `264x12`.
- **Right/Left arrow variants**: overall `251x128` (`12px` arrow lane + `240px` content).

### Content panel spacing
- Content frame padding: `12px 12px 12px 12px`.
- Content layout gap: `4px`.
- Tooltip container (title + body) layout gap: `4px`.
- Corner radius: `8px`.
- Border: `1px`.

### Typography
- Title: Roboto Medium `14/20`.
- Body: Roboto Regular `14/20`.

### Arrow geometry and placement matrix
- Arrow vector size:
  - Down/Up: `10x6`.
  - Left/Right: `6x10`.
- Arrow lane thickness:
  - Down/Up: `12px` height.
  - Left/Right: `12px` width.
- Alignment contract by axis:
  - `Start`: `16px` inset from start edge.
  - `Center`: centered on axis (implemented in Figma by reduced `8px` lane side padding).
  - `End`: `16px` inset from end edge.

Supported placement permutations:
- Down: Start, Center, End
- Up: Start, Center, End
- Right: Start, Center, End
- Left: Start, Center, End

### Storybook implementation calibration (validated against Figma `Up-Start`)
- Tooltip popup is rendered in portal with explicit side/alignment attributes.
- Arrow rendering uses SVG with:
  - fill triangle (`10x6` for up/down; `6x10` for left/right)
  - slanted-side stroke path only (no base stroke line) to avoid detached base edge.
- Arrow anchor offsets used in implementation:
  - `bottom`: `top: -6px`
  - `top`: `bottom: -5px`
  - `left`: `right: -5px`
  - `right`: `left: -5px`
- Alignment offsets used in implementation:
  - start: `16px`
  - center: `calc(50% - 5px)`
  - end: `calc(100% - 26px)`
- Popup border notch masking under arrow base (to merge arrow + border):
  - top/bottom notch width: `10px`
  - left/right notch height: `12px`

## Tokens

Use semantic tokens from `components/synapse-theme.css`; do not hardcode values in implementation.

- Surface and border:
  - `var(--color-background-surface-2)` (tooltip panel + arrow fill)
  - `var(--color-border-accessible)` (panel/arrow outline)
- Typography:
  - `var(--color-text-neutral-strong)` (title)
  - `var(--color-text-neutral)` (body copy)
- Shape/spacing:
  - `var(--corner-radius-radius-8)` (panel radius)
  - `var(--padding-padding-12)` (panel inset)
  - `var(--spacing-space-4)` (title/body spacing)
- Elevation:
  - Figma instance shadow resolves to `x:1 y:1 blur:2 rgba(37,37,37,0.25)`; keep tooltip elevation aligned with this visual depth contract.

## Interactions

- **No Title / With Title (non-dismissible)**:
  - Opens on hover/focus of trigger.
  - Closes when hover/focus leaves trigger region.
- **Dismissible**:
  - Does not auto-close on hover/focus leave.
  - Must close only via close action or `Escape`.
  - Emits close callback when dismissed.
- **Arrow behavior**:
  - Arrow orientation and alignment are controlled by placement props:
    - `arrowDirection`: `down | up | right | left`
    - `arrowAlign`: `start | center | end`
- **Accessibility**:
  - Tooltip container: `role="tooltip"`.
  - Trigger uses `aria-describedby` pointing to tooltip id.
  - Dismiss button has accessible label and keyboard activation.

## Composition & API (runtime)

- `title?: string` (omit for No Title).
- `content: string | ReactNode`.
- `dismissible?: boolean` (default `false`).
- `showArrow?: boolean` (default `true`).
- `arrowDirection?: "down" | "up" | "right" | "left"` (default `down`).
- `arrowAlign?: "start" | "center" | "end"` (default `center`).
- `open?: boolean` / `defaultOpen?: boolean`.
- `onOpenChange?: (open: boolean) => void`.
- `onDismiss?: () => void` (dismissible only).

## Codegen Contract (Framework-Agnostic Blueprint)

This section is normative for generation and validation.

### Deterministic structure
- `trigger`
- `portal`
  - `positioner`
    - `popup`
      - optional `title`
      - `body`
      - optional `dismissButton`
      - optional `arrow`

### Supported matrix
- Content mode: `no-title | with-title | dismissible`
- Arrow visibility: `showArrow=true|false`
- Placement: 12 permutations (`up|down|left|right` x `start|center|end`)

### Slot style contract
- Popup dimensions/padding/radius/border follow this spec.
- Arrow geometry and offsets follow calibration values in this spec.
- Border-notch masking under arrow base is required where applicable.
- Title/body typography and token mapping are deterministic.

### Behavior and accessibility contract
- Non-dismissible mode: opens on hover/focus, closes on leave/blur.
- Dismissible mode: close action or Escape required to dismiss.
- `role="tooltip"` on popup; trigger references tooltip id.
- Dismiss button has accessible name.

### Fallback/error rules
- Unknown side/align -> fallback `down` + `center`.
- If title is empty, title slot omitted.
- If `dismissible=false`, dismiss button omitted.

### Validation checklist
- [ ] 12 placement permutations render with correct arrow orientation/alignment.
- [ ] Arrow and popup border merge without seam artifacts.
- [ ] Dismissible and non-dismissible interaction behaviors pass.
- [ ] Token usage for light/dark is deterministic.
- [ ] ARIA contract passes.
