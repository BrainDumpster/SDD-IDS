# Progress Bar Design Spec

- Component: ProgressBar

## Anatomy
- Progress container (track)
- Progress fill bar
- Optional top label row (label + progress value)
- Optional helper text (below bar, left aligned)
- Focus ring for keyboard navigation
- Optional step indicators

## Composition & API (code generation)
Use this contract when generating framework components. Prefer semantic tokens and avoid hardcoded values.

| Prop | Type | Default | Behavior |
|---|---|---|---|
| `type` | `"with-label" \| "inline" \| "indeterminate"` | `"inline"` | **with-label**: label row above bar, label aligned left. **inline**: bar-only (or compact metadata usage if product requires). **indeterminate**: animated indicator with unknown completion duration. |
| `thickness` | `"thick" \| "medium" \| "thin"` | `"medium"` | Controls track/indicator height (see Layout mapping). |
| `state` | `"in-progress" \| "completed-success" \| "completed-warning" \| "failed-error"` | `"in-progress"` | Controls fill color/text semantics and completion affordances. |
| `showHelperText` | `boolean` | `false` | When `true`, render helper text under the progress bar, left aligned to bar start edge. |
| `value` | `number` (0-100) | `0` | Determinate progress value for non-indeterminate types. Clamp to `[0,100]`. |
| `label` | `string` | `undefined` | Primary label content used in `with-label` type. |
| `helperText` | `string` | `undefined` | Supportive text below bar; only visible when `showHelperText=true`. |

**Control rules**
- `type="with-label"`: show top metadata row; label on left; optional value/status on right if implementation provides it.
- Top-row label and percentage value color: `var(--color-text-neutral-strong)`.
- `type="inline"`: no dedicated top row by default.
- `type="indeterminate"`: ignore fixed completion percentage for UI rendering; use continuous animated indicator.
- `showHelperText=false`: helper text region omitted entirely (no reserved vertical space).
- `showHelperText=true`: helper text is rendered below track and aligned with the track left edge.

## Layout & Measurements
- `thickness` mapping:
  - **Thin**: 4px track height + `1px` border
  - **Medium**: 8px track height + `1px` border
  - **Thick**: 16px track height + `1px` border
- Container width: 100% of available space
- Border: `var(--border-width-border-1)` using progress border token (default `var(--color-border-accessible)`)
- Border radius: 4px (thin/medium), 6px (thick)
- Focus ring: 2px offset from container
- Minimum width: 200px
- Top label row spacing from bar: 8px (`with-label` type)
- Helper text spacing from bar: 8px when `showHelperText=true`
- Helper text status icon size: 16px × 16px
- Step indicator size: 12px × 12px

## Typography

## States (Dark Theme)
- Uses semantic tokens that automatically adapt to dark theme
- Text and border colors remain consistent via semantic variables
- Progress fill colors maintain visibility in dark theme
- Disabled state uses gray tokens for dark theme compatibility

## Interactions
- Progress bar is typically non-interactive (display only)
- Focus ring appears when progress bar is keyboard focusable
- Hover states not applicable (non-interactive)
- Progress value updates dynamically
- `type="indeterminate"` shows continuous animation
- `type="with-label"` shows top label row (left aligned label)
- `showHelperText=true` shows helper text under the bar (left aligned)
- Helper text color: `var(--color-text-neutral)`
- Helper text icon mapping:
  - `in-progress`: no icon
  - `completed-success`: `status-ok-circ-solid`
  - `completed-warning`: `status-warn-tri-solid`
  - `failed-error`: `status-critical-square-solid`
- Step indicators show current progress step

## Accessibility
- Focus ring: 2px brand color border
- Keyboard navigation: Tab to progress bar when focusable
- Screen reader support: Proper ARIA attributes for progress indication
- High contrast: Meets WCAG AA standards with provided colors
- Semantic HTML: Use progress element with proper attributes
- Progress announcements: Screen reader announces current progress
- Focus management: Clear focus indication when focusable

## Variants
- **Type / layout**:
  - **With Label**: Label positioned on top-left of the progress bar
  - **Inline**: Compact progress bar presentation
  - **Indeterminate**: Animated unknown-duration progress
- **Thickness**: Thin / Medium / Thick
- **State**:
  - **In Progress**
  - **Completed/Success**
  - **Completed with Exceptions/Warning**
  - **Failed/Error**
- **Helper text visibility**: `showHelperText=true/false`

## Behavior & Guidelines
- Use progress bars to show completion status
- For `with-label`, keep label left aligned above bar
- Use color variants to indicate status
- Use `indeterminate` type for unknown duration
- Use `showHelperText=true` only when support text adds actionable context
- Test with screen readers for proper progress announcement
- Use appropriate animation speeds for indeterminate state
- Ensure progress fills are clearly visible
- Consider responsive behavior for different screen sizes
