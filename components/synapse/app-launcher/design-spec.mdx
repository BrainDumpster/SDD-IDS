## Normative authority

- This spec is the **source of truth** for App Launcher **popover content** (grid of products, optional options list, dividers, spacing, tokens) and **runtime API** for codegen.
- **Masthead** owns **chrome** left of the trigger (logo, nav, etc.); this spec owns the **launcher surface** and **trigger icon contract** when embedded in masthead (**`grid-square-9-16`**, 16px — Figma `29515:170249`).

## Anatomy

1. **`launcherRoot`** (implementation): popover / floating root anchored to **masthead app launcher trigger** (not part of grid canvas in Figma examples; composed in app).
2. **`launcherSurface`** (`AppLauncher-Main`): bordered panel; holds product region, optional **region dividers**, optional **options menu** block.
3. **`productRegion`** (optional): one or more **rows** of **`productRow`**; each row is a horizontal group of **`productTile`** cells.
4. **`productTile`** (`AppLauncher-Element`): fixed **cell** width/height; contains **`iconSlot`** (32×32), **`label`** (product name). **Default icon asset** (when product does not supply one): **`assets/icons/shield-encrypt-alt.svg`** (Figma sample node `shield-encrypt-alt` / `14138:254093`).
5. **`verticalCellDivider`** (optional): **column border** between two adjacent tiles in the **same row** — **not** grid `gap`; Figma uses a zero-width track with a **1px dotted/dashed** line. Implement: `border-inline-start: var(--border-width-border-1) dashed var(--color-border-neutral-light)` on a zero-width flex item spanning the row (`min-height: 125px`).
6. **`rowDivider`** (optional): horizontal **dotted** rule between product grid rows (`Divider/Vertical/Dotted` rotated — visually horizontal dashed separation).
7. **`optionsRegion`** (optional): list of **`optionItem`** rows (align with Synapse **Dropdown** single-select menu — node ref `12579:19717` in file); optional **`optionsFooter`** with border-top and **tertiary-style action** (e.g. “Action” link).

## Layout & Measurements

- **`launcherSurface`**
  - Background: `var(--color-background-surface-2)`.
  - Border: `var(--border-width-border-1)` solid `var(--color-border-neutral-light)`.
  - Outer padding: `var(--padding-padding-1)` (Figma 1px inset chrome).
  - Corner radius: follow surface-2 / popover pattern — `var(--corner-radius-radius-4)` unless Figma library specifies otherwise.
  - Shadow (Figma sample): **`1px 1px 5px`** `rgba(0, 0, 0, 0.15)` — implement via closest semantic **elevation** tokens (e.g. `var(--shadow-drop-shadow-*)` composite) until a dedicated launcher token exists; validate visually against `49927:30551`.
  - **Width (sample):** `298px` for multi-cell layouts; single-product instance can be **content-driven** (min width ~**148px** + border/padding).
- **`productTile` cell:** width **`148px`**, height **`125px`**; inner **label** stack width **`147px`** (sample).
- **`productTile` interior (label stack):**
  - Vertical gap icon ↔ label: `var(--spacing-space-12)`.
  - Vertical padding (block axis): `var(--padding-padding-28)` on label column (Figma `py-28`).
  - **`iconSlot`:** **32×32** px bounding box; app icon asset scales inside (overflow clip per Figma).
  - **`label`:** `var(--font-size-body-2)`, `var(--font-line-height-line-height-20)`, `var(--color-text-neutral-strong)`; **center** text; **ellipsis** + **nowrap**; max width sample **111px** (runtime: constrain to cell minus padding).
- **Grid topology:**
  - **Two columns** for multiple products (Figma `2 Across` rows).
  - **Odd product count:** last row with a single tile is **center-aligned** within the two-column launcher width (Figma parity for 3-product examples).
  - **Separator spacing parity rule (normative):** use one shared inset token (`--separator-inset`, sample `var(--padding-padding-16)`) so:
    - vertical separator **top** gap = `--separator-inset`
    - vertical separator **bottom** gap = `--separator-inset`
    - vertical separator **center break** (between rows) = `--separator-inset`
    - horizontal row separator **left** and **right** inset = `--separator-inset`
  - Implement center break with a dedicated **`rowDivider` block** of height `--separator-inset`, drawing the dashed horizontal rule in the middle of that block.
- **`optionsRegion`:** `max-width` **500px**, `min-width` **185px** (Figma on embedded menu); full width of launcher when stacked below grid; separator from product region is **dashed** (`var(--border-width-border-1)` + `var(--color-border-neutral-light)`), inset left/right by the same `--separator-inset`.
  - From Figma node **`49927:271332`** (8 products + options): options list starts **immediately after** this dashed separator; no extra blank spacer block between separator and first option row.
- **`optionsFooter`:** top border **neutral-light**; vertical padding `var(--padding-padding-8)`; inner action uses `var(--font-size-body-2)` **`var(--color-text-brand-strong)`** (tertiary/link pattern).

## Interactions

- **Open:** user activates **app launcher trigger** in **Masthead** (16px grid icon); launcher positions **below** trigger, **inline end** aligned with trigger (popover / anchor positioning).
- **Close:** dismiss on **outside press**, **Escape**, optional **selection** of app (product navigates); implementers use non-modal popover or modal per product — **default** non-modal **popover** matching Figma (no full-screen scrim).
- **Keyboard:** `Tab` / `Shift+Tab` through focusable tiles and options; `Enter` / `Space` activate; arrow keys **optional** for grid (not required in baseline).
- **Product tile:** if `href` → navigation; if `onSelect` → callback; both optional but **one** should handle activation for a11y.

## Composition & API (runtime)

| Prop / slot | Required | Behavior |
|---|---|---|
| `open` | Yes (controlled) or internal popover state | Visibility of launcher surface. |
| `onOpenChange` | Recommended | `(open: boolean) => void`. |
| `trigger` | Yes | Typically Masthead-provided control; must expose accessible name (e.g. `aria-label="App launcher"`). |
| `products` | **Yes** | Ordered list: `{ id, name, icon?, href?, onSelect? }[]`. Renders **productTile** grid (2 columns). |
| `options` | No | `{ id, label, onSelect? }[]` — renders **optionsRegion** below divider when non-empty. |
| `footerAction` | No | `{ label, onClick }` — **optionsFooter** row (border-top). |
| `columns` | No (default `2`) | Grid column count; **`1`** only for single-product narrow layout if product team requires. |

## Codegen Contract (Framework-Agnostic Blueprint)

### Deterministic structure

```
launcherRoot (popover)
├── anchorReference (masthead trigger — external)
└── launcherSurface
    ├── productRegion (optional if products.length > 0)
    │   ├── productRow[] (each: 1–2 productTile)
    │   │   ├── productTile[]
    │   │   └── verticalCellDivider[] (between tiles)
    │   └── rowDivider[] (between rows, optional dotted)
    ├── optionsRegion (optional)
    │   ├── optionItem[]
    │   └── optionsFooter (optional)
    │       └── tertiaryAction
```

### Variant / option matrix

| `products.length` | `options.length` | Structure |
|---|---|---|
| 1 | 0 | Single **productTile** row (width ~148px panel sample). |
| 2–N | 0 | **2-column** rows; last row may have 1 tile. |
| 0 | >0 | **optionsOnly** — list panel (min/max width as Layout). |
| >0 | >0 | **mixed** — product grid, dashed inset separator, then **optionsRegion**. |

### Per-slot style contract

- All colors/spacing/radius from **Tokens**; no raw hex except documented Figma shadow sample pending token.
- **productTile:** 148×125 cell; icon 32; label body-2 strong centered ellipsis.
- **Dividers:** `var(--color-border-neutral-light)` — **vertical:** dashed `border-inline-start` between columns in a row; **horizontal between rows:** dashed `border-top` on **`rowDivider`** (Figma dotted divider). Horizontal divider is inset from left/right by launcher content padding (sample: `var(--padding-padding-16)`).

### Behavior contract

- Opening/closing tied to trigger; **restore focus** to trigger on close.
- **Single** `onOpenChange(false)` per dismiss gesture (no duplicate with tile click if tile also closes).

### Accessibility contract

- Trigger: `aria-expanded`, `aria-haspopup="dialog"` (or `true`/`menu` per pattern), `aria-controls` pointing at launcher id.
- Surface: `role="dialog"` **or** `role="menu"` — use **`dialog`** if focus trap; align with **Dropdown** when options-only.
- Tiles: **`article`** or **`button`** with accessible name = product name; icon decorative `aria-hidden` if redundant.

### Asset resolution + bundling

| Slug | File |
|---|---|
| `grid-square-9-16` | `assets/icons/grid-square-9-16.svg` |
| `shield-encrypt-alt` | `assets/icons/shield-encrypt-alt.svg` (default **`productTile`** icon) |
| Per-product icons | Consumer-supplied or map slug → `assets/icons/<slug>.svg` |

Bundle all icons; no reliance on expiring Figma MCP asset URLs in production.

### Fallback / error rules

- Empty `products` and empty `options` → **do not render** surface; log dev warning.
- Unknown icon slug → placeholder glyph or omit icon with text-only tile.
- `columns` not 1 or 2 → coerce to **2**.

### Validation checklist

- [ ] Masthead trigger uses **16×16** `grid-square-9-16` per Figma component description.
- [ ] Cell **148×125**, icon **32**, label **body-2** + **ellipsis**, gap **space-12**, padding **padding-28** on label stack.
- [ ] Surface tokens: **surface-2**, **border neutral-light**, shadow matches sample or approved token substitute.
- [ ] 2-column grid, odd count leaves empty trailing cell in row.
- [ ] **Column borders** only **between** cells in a row (divider after first column, not after row end).
- [ ] **Top, bottom, and center** vertical separator spaces are equal to horizontal separator **left/right** inset (shared `--separator-inset`, sample `padding-16`).
- [ ] **Row divider** (dashed) appears **between** product rows when `rows.length > 1`, inset from left/right by the same `--separator-inset`.
- [ ] Default tile icon uses **`shield-encrypt-alt`** when `icon` prop/slot omitted.
- [ ] Optional options list + footer matches Dropdown row spacing and border-top separation.
- [ ] Light/Dark tables structurally parallel; keyboard and ARIA pass.
