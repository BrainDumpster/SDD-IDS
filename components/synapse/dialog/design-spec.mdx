## Anatomy

The dialog is composed of these parts:

- **backdrop**
- **popup**
- **header**
  - **alertIcon (optional)**: Rendered alongside the title when `dialogType != "None"`.
    - `dialogType="Info"` -> informational icon
    - `dialogType="Warning"` -> warning icon
    - `dialogType="Major"` -> major icon
    - `dialogType="Danger"` -> critical/danger icon
    - `dialogType="Success"` -> success icon
  - **title**
  - **closeIcon**
- **body**
- **footer**
  - **tertiaryButton (optional)**
  - **primaryButton**

Notes:
- The alert icon is optional; non-alerting variant renders title without alert icon.
- There is **no border/divider** between header and body.

## Composition & API (code generation)
Use this contract when generating framework components (React, Angular, Lit, etc.).

### Inputs (Props)

| Prop | Type | Default | Behavior |
|---|---|---|---|
| `openDidalog` | `boolean` | `false` | Controlled visibility for the dialog. When `true`, the dialog popup is shown; when `false`, the popup is hidden. |
| `dialogTitle` | `string` | `""` | Title text rendered in the header (paired with optional alert icon). |
| `dialogType` | `"None" \| "Success" \| "Warning" \| "Major" \| "Danger" \| "Info"` | `"None"` | Controls the optional alert icon in the header. `None` renders no alert icon. |
| `dialogSize` | `"sm" \| "lg" \| "xl"` | `"lg"` | Controls dialog width preset in implementations. |
| `dialogClosable` | `boolean` | `true` | When `true`, shows the close icon and allows closing. When `false`, hides the close icon. |
| `primaryButtonName` | `string` | `""` | Primary button label in the footer. |
| `enableActionButton` | `boolean` | `true` | When `false`, the primary button is disabled and does not emit `onPrimaryButtonClick`. |
| `tertiaryButtonName` | `string` | `""` | Tertiary button label in the footer. If empty/omitted, tertiary button is not rendered. |
| `enableTertiaryButtton` | `boolean` | `true` | When `false` and the tertiary button is rendered, it is disabled and does not emit `onTertiaryButtonClick`. |

### Outputs (Events)

| Event | When it fires | Payload |
|---|---|---|
| `onClose` | Close icon click (only when `dialogClosable=true`) | none |
| `onPrimaryButtonClick` | Primary button click (only when `enableActionButton=true`) | none |
| `onTertiaryButtonClick` | Tertiary button click (only if tertiary is rendered and enabled) | none |

### Rendering rules
- Header alert icon:
  - `dialogType="None"`: do not render alert icon.
  - Other `dialogType` values: render the alert icon in the header before the title:
    - `Info` -> informational icon
    - `Warning` -> warning icon
    - `Major` -> major icon
    - `Danger` -> critical/danger icon
    - `Success` -> success icon
- Footer buttons:
  - Primary button is always part of the footer layout (disabled when `enableActionButton=false`).
  - Tertiary button is rendered only when `tertiaryButtonName` is non-empty.

## Layout & Measurements

Figma source analyzed: `43461:175960` (component set `ModalDialog-Main`) and variants:
`Type=Non-Alerting`, `Type=Informational`, `Type=Warning`, `Type=Major`, `Type=Critical`.

- **Dialog width**: 640px (all listed variants).
- **Dialog height**:
  - Non-alerting / Informational: 232px
  - Warning / Major / Critical: 244px
- **Corner radius**: 5px.
- **Dialog outer border**: 1px inside stroke (`var(--border-width-border-1)` + dialog border token).
- **Header container padding**: 24px top, 24px right, 8px bottom, 24px left (no border/divider between header and body).
- **Header icon-title spacing**: 16px (`alertIcon` to `title`).
- **Close icon size**: 16px visual glyph.
- **Body text/content row padding**: 8px top/bottom, 24px left/right.
- **Body content row padding**:
  - Base: 16px top, 24px left/right
  - Bottom: 24px in non-alerting/informational variants
- **Footer container padding**: 24px on all sides.
- **Button group spacing**:
  - Tertiary + Primary: 12px
  - Single Primary: no inter-button spacing needed
- **Footer structural spacing** (checkbox region to action group): 16px.
- **Header/body divider**: none.

## States (Dark Theme)

Same semantic structure as Light Theme. Values resolve through theme variables:
- Popup uses `var(--color-background-component)` dark value.
- Overlay uses `var(--color-background-overlay-1)` dark alpha.
- Title/body text and icons resolve via dark-mode semantic tokens.
- Header/body divider remains absent in dark theme as well.

## Interactions

- **Open**: dialog is shown when `openDidalog=true` (or via a trigger in demo implementations) and traps focus.
- **Close icon click**: closes dialog and emits `onClose`.
- **Escape key**: closes dialog.
- **Backdrop click** (if enabled by product): closes dialog.
- **Primary button click**: emits `onPrimaryButtonClick` (and may close dialog depending on product intent).
- **Tertiary button click** (when rendered): emits `onTertiaryButtonClick` (and may close dialog depending on product intent).

### Event contract (for code generation)

- `onClose()` fired on close icon click (only when `dialogClosable=true`).
- `onPrimaryButtonClick()` fired on primary button click (only when `enableActionButton=true`).
- `onTertiaryButtonClick()` fired on tertiary button click (only when tertiary is rendered and `enableTertiaryButtton=true`).

### Keyboard / focus

| Key | Action |
|---|---|
| Escape | Close dialog |
| Tab | Next focusable within dialog |
| Shift+Tab | Previous focusable within dialog |
| Enter/Space on close icon | Close dialog (`onClose()`) |
| Enter/Space on action buttons | Emit corresponding button event |
