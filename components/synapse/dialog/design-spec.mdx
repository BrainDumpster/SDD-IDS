## Normative authority

- **This document** is the **source of truth** for Synapse **Dialog** structure, props/events, visual tokens (per variant), interaction rules, assets, and **codegen/validation** for any target framework.
- **About pattern inner content** (product/version/logo/legal copy, spacing between those blocks) remains specified in **`components/synapse/about/design-spec.mdx`**. This Dialog spec defines the **modal shell** and **API** for `variant="about"` (backdrop, popup chrome, header dismiss, body region, footer primary close).
- **Reference implementation (illustrative, not a generator output):** `storybook/src/components/Dialog.tsx` + `Dialog.module.css`. When spec and code disagree, **update code to match this spec** (or amend this spec deliberately, then align code).

## Anatomy

### `variant="default"`

- **backdrop**
- **popup** (width from `dialogSize`; radius `var(--corner-radius-radius-8)`; single elevation shadow per implementation theme)
- **header**
  - **alertIcon (optional)**: when `dialogType != "None"`.
    - `dialogType="Info"` → informational icon
    - `dialogType="Warning"` → warning icon
    - `dialogType="Major"` → major icon
    - `dialogType="Danger"` → critical/danger icon
    - `dialogType="Success"` → success icon
  - **title** (`dialogTitle`) — header row, `header-5` treatment
  - **closeButton** (when `dialogClosable`): **closeIcon** glyph (see Assets)
- **description** (optional): when `description` string is provided
- **body** (optional): `children`
- **footer**
  - **tertiaryButton (optional)**: when `tertiaryButtonName` non-empty
  - **primaryButton**: `primaryButtonName` (standard `Button` primary; **does not** imply automatic dismiss unless product wires it)

Notes:
- Non-alerting `dialogType="None"` → no alert icon.
- **No border/divider** between header and body.

### `variant="about"`

- **backdrop** — same overlay token as default; **optional `backdrop-filter: blur(1px)`** for Figma parity (About overlay reference `49842:37475` / `49842:37477`).
- **popup** — outer shell: **`var(--corner-radius-radius-16)`**, border **`var(--border-width-border-1)`** solid **`var(--color-border-neutral-light)`**; width **`min(1152px, 100vw − gutters)`**; `max-height` content/viewport-driven (e.g. `90vh`); centered in viewport.
- **modalMain** (inner surface) — background **`var(--color-background-component)`**; **four-layer** drop shadow stack using `var(--shadow-drop-shadow-{2,4,8,16}-*)` tokens (same rgba stack intent as default dialog elevation).
- **header** — **leading spacer** (Figma ~78px cluster; tokenized implementation may use `var(--scale-80)` or equivalent); **trailing closeButton** (same **closeIcon** asset and 32×32 hit target as default).
- **body** — **title** = `dialogTitle` rendered as **product title** slot ( **`var(--font-size-header-1)`**, **`var(--color-icon-brand-base)`**, centered — details in About spec); then **`children`** (version, optional logo, optional legal — **About spec**).
- **footer** — top border **`var(--color-border-neutral-light)`**; **single primary** control labeled `primaryButtonName` (default `"Close"`) that **closes the dialog** (dismiss primitive + optional `onPrimaryButtonClick`).

Notes:
- **`tertiaryButton` is never rendered** for `variant="about"` (ignore `tertiaryButtonName`).
- **`description` is not used** for `variant="about"` (omit or no-op).
- **`dialogType`** should be **`None`** for About (no alert icon).

## Composition & API (runtime)
Use this contract when generating framework components (React, Angular, Lit, etc.).

### Inputs (Props)

| Prop | Type | Default | Behavior |
|---|---|---|---|
| `variant` | `"default" \| "about"` | `"default"` | Selects anatomy, chrome, and footer rules above. |
| `trigger` | `ReactNode` (or framework slot) | — | **Required** when `open` is **omitted** (uncontrolled open-from-trigger). **Omit** when `open` is **set** (controlled visibility from parent). |
| `open` | `boolean` | omitted | **Controlled mode:** when defined, dialog visibility follows this boolean; do **not** use `openDidalog` as the live toggle. |
| `onOpenChange` | `(open: boolean) => void` | — | Fires when dialog opens or closes (dismiss icon, Escape, programmatic close, **About** footer close, etc.). **Normative** for controlled integrations. |
| `openDidalog` | `boolean` | `false` | **Uncontrolled initial open** only (typo preserved for API parity with existing demos). Used when `open` is **undefined** (`defaultOpen` semantics). |
| `dialogTitle` | `string` | `""` | **`default`:** header title (`header-5`). **`about`:** product title in body (header-1 / brand — see About spec). |
| `dialogType` | `"None" \| "Success" \| "Warning" \| "Major" \| "Danger" \| "Info"` | `"None"` | **`default` only:** optional alert icon. **`about`:** use `None`. |
| `dialogSize` | `"sm" \| "lg" \| "xl"` | `"lg"` | **`default` only:** popup width preset. **`about`:** ignored (About shell width rules apply). |
| `dialogClosable` | `boolean` | `true` | Header close control; when `false`, hide header **closeButton**. |
| `description` | `string` | — | **`default` only:** optional `Description` region. **`about`:** unused. |
| `children` | slot | — | **`default`:** body content. **`about`:** slots after product title (version, logo, legal — **About spec**). |
| `primaryButtonName` | `string` | `""` | Footer primary label. **`about`:** default consumer label `"Close"`; control **must** close dialog. |
| `enableActionButton` | `boolean` | `true` | When `false`, primary footer control disabled (`about`: footer close disabled). |
| `tertiaryButtonName` | `string` | `""` | **`default`:** if non-empty, show tertiary. **`about`:** never rendered. |
| `enableTertiaryButtton` | `boolean` | `true` | Tertiary enabled state (**`default` only**). |

### Outputs (Events)

| Event | When it fires | Payload |
|---|---|---|
| `onOpenChange` | Open/close transition (all variants) | `open: boolean` |
| `onClose` | Header close button press (when `dialogClosable=true`) | none |
| `onPrimaryButtonClick` | Footer primary press (when enabled) | none |
| `onTertiaryButtonClick` | Footer tertiary press (when rendered and enabled) | none |

### Visibility rules (normative)

- If `open` is **undefined**: **uncontrolled** — require **`trigger`**; initial open from `openDidalog` (`defaultOpen`).
- If `open` is **defined**: **controlled** — **`trigger` optional**; parent drives `open` / `onOpenChange`.
- **Invalid:** neither `trigger` nor `open` — implementations **must** error or no-op per product policy (reference impl throws).

### Runtime dialog primitive (implementation-agnostic)

- **Modal:** `aria-modal` / focus trap while open (framework primitive).
- **`disablePointerDismissal`:** **`true`** for `variant="about"` (no backdrop click to dismiss unless product overrides). **`false`** for `variant="default"` unless product specifies otherwise.

### Rendering rules
- **`variant="default"`** — Header alert icon:
  - `dialogType="None"`: do not render alert icon.
  - Other values: alert icon before title (`Info`, `Warning`, `Major`, `Danger`, `Success` mapping per token table).
- **`variant="about"`** — No alert icon; title is **not** in header row (see Anatomy).
- Footer:
  - **`default`:** Primary always rendered; tertiary only if `tertiaryButtonName` non-empty.
  - **`about`:** Primary only; **must** map to dismiss/close behavior for the dialog root.

## Layout & Measurements

Figma source analyzed: `43461:175960` (component set `ModalDialog-Main`) and variants:
`Type=Non-Alerting`, `Type=Informational`, `Type=Warning`, `Type=Major`, `Type=Critical`.

- **Dialog width**: 640px (all listed variants).
- **Dialog height**:
  - Non-alerting / Informational: 232px
  - Warning / Major / Critical: 244px
- **Corner radius**: 5px.
- **Dialog outer border**: 1px inside stroke (`var(--border-width-border-1)` + dialog border token).
- **Header container padding**: 24px top, 24px right, 8px bottom, 24px left (no border/divider between header and body).
- **Header icon-title spacing**: 16px (`alertIcon` to `title`).
- **Close icon size**: 16px visual glyph.
- **Body text/content row padding**: 8px top/bottom, 24px left/right.
- **Body content row padding**:
  - Base: 16px top, 24px left/right
  - Bottom: 24px in non-alerting/informational variants
- **Footer container padding**: 24px on all sides.
- **Button group spacing**:
  - Tertiary + Primary: 12px
  - Single Primary: no inter-button spacing needed
- **Footer structural spacing** (checkbox region to action group): 16px.
- **Header/body divider**: none.

### `variant="about"` (shell — align with `components/synapse/about/design-spec.mdx`)

- **Popup width:** `max-width` / `min()` with **`1152px`** sample and **horizontal gutters** from `var(--padding-padding-24)` (or equivalent).
- **Popup radius:** `var(--corner-radius-radius-16)`.
- **Popup border:** `var(--border-width-border-1)` `var(--color-border-neutral-light)`.
- **Header padding:** top `var(--padding-padding-24)`, bottom `var(--padding-padding-16)`, horizontal `var(--padding-padding-24)`.
- **Body padding:** horizontal + bottom `var(--padding-padding-24)`; scroll **body** when `children` overflow; header/footer remain fixed in column layout.
- **Footer:** `border-top` `var(--border-width-border-1)` `var(--color-border-neutral-light)`; padding `var(--padding-padding-24)`; actions **end** aligned; gap `var(--spacing-space-16)`.
- **Leading header spacer:** `var(--scale-80)` (approximates Figma 78px cluster).

### Shadow (from Figma effects)

Dialog elevation uses a 4-layer drop-shadow stack:
- `x: 0, y: 16, blur: 16, color: rgba(37, 37, 37, 0.08)`
- `x: 0, y: 8, blur: 8, color: rgba(37, 37, 37, 0.08)`
- `x: 0, y: 4, blur: 4, color: rgba(37, 37, 37, 0.08)`
- `x: 0, y: 2, blur: 2, color: rgba(37, 37, 37, 0.08)`

**`variant="about"`:** apply the same four-layer stack to **`modalMain`** (inner surface), or equivalent semantic elevation preset.

Same semantic structure as Light Theme. Values resolve through theme variables:

## Interactions

- **Open (uncontrolled):** user activates **`trigger`**; optional initial open via `openDidalog` / `defaultOpen`.
- **Open (controlled):** parent sets `open={true}`; no trigger required.
- **Close:** header close, Escape (when not disabled by primitive), **`variant="about"`** footer primary — all must drive **`onOpenChange(false)`** (and header close also **`onClose`** where specified).
- **`variant="default"`:** backdrop pointer dismiss **may** be enabled by the dialog primitive or product policy.
- **`variant="about"`:** **`disablePointerDismissal=true`** — backdrop click **does not** close by default (About spec).
- **Primary button (`default`):** emits `onPrimaryButtonClick`; **closing** is product-defined (not required by this spec).
- **Primary button (`about`):** **must** close dialog; still may emit `onPrimaryButtonClick` before/after close per implementation.
- **Tertiary** (`default` only): emits `onTertiaryButtonClick`.

### Event contract (for code generation)

- `onOpenChange(open)` on every open/close transition.
- `onClose()` on header close press (when `dialogClosable=true`).
- `onPrimaryButtonClick()` when footer primary is enabled and activated.
- `onTertiaryButtonClick()` when tertiary rendered, enabled, and activated.

### Keyboard / focus

| Key | Action |
|---|---|
| Escape | Close dialog |
| Tab | Next focusable within dialog |
| Shift+Tab | Previous focusable within dialog |
| Enter/Space on close icon | Close dialog (`onClose()`) |
| Enter/Space on action buttons | Emit corresponding button event |

| popup root | `role="dialog"`, `aria-modal="true"`, `aria-labelledby`, `aria-describedby` |
| close icon button | `aria-label="Close"` |

## Codegen Contract (Framework-Agnostic Blueprint)

This section is normative for generation and validation.

### Deterministic structure

**`variant="default"`**

- `root` (modal dialog primitive)
- `trigger` (optional if controlled)
- `backdrop`
- `popup`
  - `header`
    - optional `alertIcon`
    - `title`
    - optional `closeButton` → contains **closeIcon** (`shape-x` asset)
  - optional `description`
  - optional `body` → `children`
  - `footer`
    - optional `tertiaryButton`
    - `primaryButton`

**`variant="about"`**

- `root` (modal; `disablePointerDismissal` true)
- `trigger` (optional if controlled)
- `backdrop` (optional blur per Layout)
- `popup` (radius-16, border-neutral-light)
  - `modalMain` (surface + 4-layer shadow)
    - `header` → `headerSpacer` + optional `closeButton` (**shape-x**)
    - `body` → `title` (product) + `children`
    - `footer` → `primaryClose` (dismiss primitive + label `primaryButtonName`)

### Supported matrix

- `variant`: `default | about`
- `dialogType` (default only): `None | Success | Warning | Major | Danger | Info` (framework casing may differ; map deterministically)
- `dialogSize` (default only): `sm | lg | xl`
- `dialogClosable`: `true | false`
- Visibility: `uncontrolled` (`trigger` + optional `openDidalog`) | `controlled` (`open` + `onOpenChange`, `trigger` optional)
- Footer (`default`): primary only | primary + tertiary
- Footer (`about`): primary close only

### Slot style contract

- **`default`:** Header/body separator: none.
- **Widths/radius/shadow/padding** per **Layout & Measurements** for each variant.
- **closeButton:** 32×32 hit target; **closeIcon** 16×16 display; **shape-x** asset; focus-visible per states table.
- **Alert icon** token map → `dialogType` (`default` only).

### Asset resolution + bundling contract

- **Mandatory:** `assets/icons/shape-x.svg` → stable slug `shape-x`; include in app bundle or public URL map; no runtime network fetch unless product explicitly allows.

### Behavior and accessibility contract

- Focus trap while open; **`aria-modal="true"`** (or equivalent).
- **`onOpenChange`** on all open/close paths.
- **`variant="about"`:** backdrop click does **not** dismiss unless product overrides primitive.
- **`about`** footer primary **closes** dialog.
- `role="dialog"`, `aria-labelledby`, `aria-describedby` (or framework defaults) required.

### Fallback/error rules

- Unknown `dialogType` → `none`.
- Unknown `variant` → `default` or error (document choice).
- Missing tertiary label → omit tertiary (`default`).
- `dialogClosable=false` → omit header close.
- Missing `trigger` and missing `open` → error (reference contract).

### Validation checklist

- [ ] `variant="default"` and `variant="about"` both render correct anatomy.
- [ ] `shape-x` close icon bundled and sized 16×16 with correct a11y split (button vs img).
- [ ] Controlled (`open` / `onOpenChange`) and uncontrolled (`trigger` / `openDidalog`) behaviors match.
- [ ] `about`: no tertiary, no description, no backdrop dismiss, footer closes dialog.
- [ ] `default`: alert types, sizes, header/body no-divider rule.
- [ ] Event contract: `onOpenChange`, `onClose`, `onPrimaryButtonClick`, `onTertiaryButtonClick` deterministic.
- [ ] Focus trap + keyboard + ARIA pass.
