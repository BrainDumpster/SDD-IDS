## Anatomy
1. **`patternRoot`** (optional outer wrapper when embedding in page mock): hosts **page**, **scrim**, **dialog**.
2. **`scrim`**: full-viewport layer above page; blocks pointer events to content below; optional subtle **backdrop blur** (Figma: `1px`).
3. **`dialog`**: centered **modal surface** (`About-Synapse`); clips overflow; outer border + large corner radius.
4. **`modalMain`**: column flex; **modal background**, **elevation shadow stack**; contains **header**, **body**, **footer**.
5. **`header`**: top bar — **leading spacer / reserved region** (Figma empty `78px` cluster), **trailing dismiss** control (icon-only **close**, `16×16`).
6. **`body`**: scrollable if needed; vertically centered **content column**:
   - **`productBlock`**: **`productTitle`** + **`versionLine`** (stacked, centered).
   - **`brandBlock`**: **`logo`** (horizontal Dell Technologies mark, fixed aspect sample in Figma).
   - **`legalCopy`**: one or more centered paragraphs (`Body 2`).
7. **`footer`**: top **divider**; horizontal row **`justify-end`**; **primary Close** button (synapse Button primary pattern).

## Interactions
- **Open:** pattern is mounted (or `open=true`); scrim + dialog visible; **focus trap** inside dialog on open; **initial focus** on dismiss or Close per product a11y policy (recommend first focusable = Close or dismiss).
- **Dismiss paths:** (1) **Dismiss** icon → `onClose` / `onOpenChange(false)`; (2) **Close** button → same; (3) optional: **Escape** key; (4) optional: **scrim click** (only if spec allows; Figma does not mandate — default **do not** close on scrim unless explicitly required).
- **Scroll:** body scrolls if legal copy exceeds viewport; header/footer remain visually fixed (sticky within dialog) **or** scroll as one column per implementation — Figma shows single column; prefer **header + footer fixed, body scroll** for long legal text.
- **Underlying page:** inert / `aria-hidden` while open (when dialog is modal).

## Composition & API (runtime)

| Prop / slot | Required | Behavior |
|---|---|---|
| `open` | Yes (controlled) | Whether About is visible. |
| `onOpenChange` / `onClose` | Yes | Fires when user closes via dismiss or Close (payload boolean or void). |
| `productTitle` | Yes | String (e.g. “Synapse”); renders as header-level display with Header 1 / brand color token. |
| `versionLabel` | Yes | String (e.g. semantic version); Body 2 / neutral-strong. |
| `legalContent` | Yes | `string` (markdown optional per product) **or** slot for rich text; centered Body 2. |
| `logo` | No | Default: bundled **horizontal Dell Technologies** asset; override slot for white-label. Canonical repo slug: `logo-delltech-horiz.svg` under `assets/icons/`. |
| `closeLabel` | No (default `"Close"`) | Footer primary button label. |
| `onCloseButtonClick` | No | Optional extra handler; must still call `onOpenChange(false)` when closing. |

## Codegen Contract (Framework-Agnostic Blueprint)

### Deterministic structure
```
patternRoot (optional)
├── scrim
└── dialog
    └── modalMain
        ├── header
        │   ├── headerStartSpacer (optional)
        │   └── dismissButton
        ├── body
        │   └── contentColumn
        │       ├── productBlock (productTitle, versionLabel)
        │       └── brandBlock (logo, legalCopy)
        └── footer
            └── closeButton (primary)
```

### Variant matrix
- **Density:** default only in source; future: compact legal / no logo (out of scope unless new Figma).
- **Theme:** light | dark via tokens.
- **White-label:** `logo` slot override; `productTitle` / `legalContent` strings required.

### Per-slot style contract
- All colors, radii, borders, typography from **Tokens** and **States** tables.
- Dismiss: **16×16** hit target minimum **44×44** if design system requires enlarged tap area (document touch target in implementation notes).

### Behavior contract
- Closing always unmounts or sets `open=false` exactly once per user gesture.
- No duplicate `onOpenChange` emissions from dismiss + Close unless separate analytics hooks provided.
- **Restore focus** to trigger element on close (dialog a11y).

### Accessibility contract
- **Role:** `dialog`; **`aria-modal="true"`**; **`aria-labelledby`** pointing at product title id; optional **`aria-describedby`** for legal region.
- **Keyboard:** `Tab` cycles focus within dialog; `Escape` closes if product enables it.
- **Dismiss control:** `aria-label="Close"` (or localized string).

### Asset + bundling contract
| Asset | Path |
|---|---|
| Close icon (dismiss) | `assets/icons/shape-x.svg` (or `shape-x-thick.svg` per design QA) |
| Dell Technologies horizontal list mark | `assets/icons/logo-delltech-horiz.svg` |

Bundle rule: ship icons with app; do not rely on Figma MCP asset URLs in production.

### Fallback/error rules
- Missing `productTitle`: generator error; refuse empty.
- Missing logo file: show **alt text** / `aria-label` for brand; optional placeholder glyph.
- Unknown markdown in `legalContent`: strip or safe-render per product sanitizer policy.
