## Anatomy

1. **`menuSurface`**: floating panel container.
2. **`optionsList`**: vertical stack of selectable rows.
3. **`optionRow`**: single action row (text-only or radio + text).
4. **`sectionHeaderRow`** (optional, repeatable): lightweight heading row with top border separator.
5. **`leadingControlSlot`** (optional): leading icon/radio slot (16x16 in Figma examples).
6. **`scrollRail`** (optional): visual scrollbar strip for long content examples.

## Layout & Measurements

- **`menuSurface`**
  - Width sample: `269px`.
  - Bounds: `min-width: 185px`, `max-width: 500px`.
  - Background: `var(--color-background-component)`.
  - Border: `var(--border-width-border-1)` solid `var(--color-border-neutral-light)`.
  - Radius: none in sampled nodes.
  - Shadow: two-layer drop shadow (`0 2px 2px` + `0 4px 4px`, low opacity).
- **`optionsList`**
  - Vertical stack with no gaps (`gap: 0`).
  - Rows consume full menu width.
- **`optionRow`**
  - Horizontal padding: `var(--padding-padding-16)`.
  - Vertical padding: `var(--padding-padding-10)`.
  - Internal gap (leading control to label): `var(--spacing-space-8)` for radio variants; `var(--spacing-space-16)` for text-only examples.
  - Label typography: body-2 regular (`14/20`).
- **`sectionHeaderRow`**
  - Horizontal padding: `var(--padding-padding-16)`.
  - Vertical padding: `var(--padding-padding-6)`.
  - Top divider: `var(--border-width-border-1)` solid `var(--color-border-neutral-light)`.
  - Header label color: `var(--color-text-neutral-strong)`.
- **`leadingControlSlot`**
  - Sample size: `16x16`.
  - For single-select sectioned lists, this is a RadioButton instance.
- **`scrollRail`** (when present in example)
  - Rail width: `8px`, thumb width: `6px`.
  - Rail background: `var(--color-background-gray-neutral-alt)`.
  - Thumb color: `var(--color-border-neutral-light)`.

## Interactions

- Rows are actionable menu options (single-select or plain action list variants).
- Section headers are non-actionable grouping labels.
- For selectable variants (`selectionMode="single"` and `selectionMode="multi"`), selecting a row updates selection state **without dismissing** the popup.
- Selectable variants dismiss only on outside click, `Escape`, or trigger toggle.
- Keyboard baseline:
  - `ArrowUp`/`ArrowDown` move active option.
  - `Enter`/`Space` activates current option.
  - `Escape` closes menu.
- For radio variants, selection semantics are single-select and delegated to radio group behavior.
- For checkbox variants, selection semantics are multi-select and delegated to checkbox behavior.
- Scrollbar is visible only when option content exceeds viewport height.

## Composition & API (runtime)

| Prop / slot | Required | Behavior |
|---|---|---|
| `open` | Yes (controlled or internal) | Menu visibility state. |
| `onOpenChange` | Recommended | Visibility change callback. |
| `items` | Yes | Option model list with label/value/disabled metadata. |
| `sections` | No | Grouped menu shape (`title` + `items[]`) for sectioned list variants. |
| `selectionMode` | No | `single` (default), `multi`, or `none`. |
| `selectedValue` | No | Currently selected option key for single-select mode. |
| `selectedValues` | No | Currently selected option keys for multi-select mode. |
| `onSelect` | No | Option activation callback. |
| `maxHeight` | No | Enables vertical scroll region when exceeded. |
| `trigger` | Yes | External trigger element/slot. |

Selection semantics:
- `single`: one selected key at a time; selecting another key replaces previous.
- `multi`: selected keys are toggled independently.
- `none`: plain action list behavior (no retained selection state required).

## Codegen Contract (Framework-Agnostic Blueprint)

### Deterministic structure

`menuRoot -> menuSurface -> (sectionHeaderRow? + optionRow+)* -> scrollRail?`

### Variant / option matrix

- `flat`: options only (`optionRow[]`).
- `sectioned`: repeated `sectionHeaderRow + optionRow[]`.
- `sectionedSingleSelect`: sectioned + `leadingControlSlot` (radio).
- `sectionedMultiSelect`: sectioned + `leadingControlSlot` (checkbox).
- `scrollable`: any variant with constrained height + `scrollRail`.

### Per-slot style contract

- `menuSurface`: tokenized border/fill/shadow and min/max width constraints.
- `optionRow`: deterministic 16/10 paddings and body-2 text.
- `sectionHeaderRow`: deterministic 16/6 paddings + top border.
- `leadingControlSlot`: 16x16 slot; delegate state rendering by selection mode:
  - `single` -> `components/synapse/radiobutton/design-spec.mdx`
  - `multi` -> `components/synapse/checkbox/design-spec.mdx`
- `leadingControlSlot` state parity requirements:
  - **Radio default**: ring `var(--color-border-accessible)`, fill `var(--color-background-component)`, dot `var(--color-background-controls-brand-base)` when selected.
  - **Radio hover/press**: ring `var(--color-border-strong)`.
  - **Radio disabled**: ring + dot use `var(--color-border-disabled)`.
  - **Checkbox selected**: fill `var(--color-background-controls-brand-base)`, border `var(--color-border-transparent-brand)`, check glyph `var(--color-icon-white)`.
  - **Checkbox selected hover/press**: fill `var(--color-background-controls-brand-strong)`.
  - **Checkbox disabled**: unselected fill `var(--color-background-gray-light)`, selected fill `var(--color-background-gray-base)`, border `var(--color-border-disabled)`, glyph `var(--color-icon-inverse)`.
- `scrollRail`: optional visual rail with 8/6 geometry.

### Behavior contract

- Open/close follows trigger + escape/outside-click menu semantics.
- Option activation emits callback with value payload.
- Selectable variants must not auto-dismiss popup on row activation.
- Section headers are non-focusable and non-selectable.

### Accessibility contract

- Use menu pattern semantics (`role="menu"` + `menuitem*`) or listbox semantics (`role="listbox"` + `option`) consistently per implementation mode.
- Ensure keyboard navigation and announced selection state.
- Disabled options must be programmatically non-actionable.

### Asset resolution + bundling contract

- DropdownMenu has no mandatory glyph asset; icons/radios are delegated.
- Apply root-spec icon-resolution baseline when an option includes iconography.

### Fallback / error rules

- Empty `items` and no `sections` -> render empty container or suppress popup (product choice must be documented).
- Invalid `selectedValue` -> no selection.
- Unknown row type -> fallback to plain text `optionRow`.
