## Anatomy

- **container**: rounded tag capsule.
- **text value**: `"Tag"` text.
- **optional prefix label**: `"Label:"` (for with-label variants).
- **optional close button**: close icon from `Tag-Element-Close`.
- **optional badge**: numeric pill (e.g. `1`) for badge variants.

## Layout & Measurements

### Core capsules
- Alerting tags (Info/Success/Minor/Major/Critical/None-small): `40x20`, **radius `24px`**, padding `0px 8px 0px 8px`, gap `8px`.
- Non-alerting large tag: `48x28`, radius `24px`, padding `4px 12px 4px 12px`, gap `2px` (between label and value when label shown).
- Clickable tag: `48x28`, radius `24`, padding `4 12`, gap `8`.
- Editable/Dismissible regular capsule: `66x28`, radius `24`, padding `4 12`, gap `8`.
- Tags with badge: `92x28`, radius `24`, padding `4 12`, gap `8`.

### Typography
- Main tag text: Roboto `14/20`, weight `400`.
- Badge number text: Roboto `12`, weight `400` (line height from instance ~= 21.09).

## Tokens

Use semantic tokens from `components/synapse-theme.css`; do not hardcode values in implementation.

- Neutral / non-alerting:
  - `var(--color-background-component)`
  - `var(--color-border-accessible)` / `var(--color-border-light)`
  - `var(--color-text-neutral)` / `var(--color-text-neutral-strong)`
- Selection/focus/interactive:
  - `var(--color-border-brand-base)`
  - `var(--color-background-brand-base)` (selected clickable fill)
  - `var(--color-text-white)` / `var(--color-icon-inverse)` for inverted selected text/icon
- Alerting types:
  - Info (filled): `var(--color-background-alerting-info-1)` background, `var(--color-border-alerting-info-white)` border, `var(--color-text-white)` text.
  - Success (filled): `var(--color-background-alerting-success-1)` background, `var(--color-border-alerting-success-white)` border, `var(--color-text-white)` text.
  - Minor (filled): `var(--color-background-alerting-minor)` background, `var(--color-border-alerting-minor-transparent)` border, `var(--color-text-tag-warning)` text.

  - Critical (filled): `var(--color-background-alerting-critical)` background, `var(--color-border-alerting-critical-white)` border, `var(--color-text-white)` text.

### Read-only tags
- Read-only mode in `Tags-main` is composed from the alerting + non-alerting sets.
- No click/selection treatment; visual meaning comes from type color only.

### Non Alerting Large tag (`38910:51195`)
- States: `Default | Focus | Error`.
- Optional prefix via `Show Label` boolean.
- Default: white background, neutral border, neutral text.
- Error: white background with critical border `var(--color-border-alerting-critical-base)` (non-alerting error tag).
- Focus: tag field uses focus treatment while preserving neutral palette.

### Clickable tags (`38910:51213`)
- Axes: `State=Default|Hover|Focus`, `Selected=True|False`.
- **Default, Selected=False**: white bg + brand border + neutral text.
- **Default, Selected=True**: brand fill + inverse border/text.
- **Focus** follows selected/non-selected palettes with focus-visible treatment.
- On click, clickable tags toggle state between `Selected=False` and `Selected=True`.

### Editable tags (`38910:51235`)
- Axes: `Type=Regular|Error|Disabled`, `Focus on Text=True|False`, `Show Label` boolean.
- Supports:
  - no label (`Show Label=false`)
  - with label (`Show Label=true`)
  - focus for no label and with label (via `Focus on Text=True` variants)
- Interaction contract: clicking an editable tag moves focus to the internal text region (not the outer capsule). Focus indicator is a `1px` brand border with `2px` radius around the text field.
- Capsule spacing contract: padding `4px 12px 4px 12px`; space between label/value group and close icon is `8px`.
- Error and disabled are explicit variant states.

### Closable tag
- Uses close icon set `Tag-Element-Close` (`Status=Default|Hover|Focus`).
- Close glyph is `10x10`; icon color changes with status tokens.
- Closable behavior appears in editable/dismissible flow and should emit remove action.

### Tags with badge (`38910:57339`)
- Axes: `State=Default|Error|Disabled`, `Focus=True|False`, `Show Label` boolean.
- Container spacing contract: padding `4px 12px 4px 12px` with `8px` gap between badge and label/value content.
- Badge remains inverse text on badge fill while tag body follows state border/background rules.

## States (Dark Theme)

Use the same structural/state matrix as light theme, resolving values through dark semantic tokens:
- Alerting light variants resolve to dark alerting-slate backgrounds with corresponding dark text/border aliases (for Minor/Major use alerting-slate backgrounds, not light-theme yellow fills).
- Strong alerting and selected clickable variants use `var(--color-icon-inverse)` for text/icon in dark mode.
- Disabled variants use dark disabled background/border/text tokens.
- Focus-visible states retain brand focus semantics in dark mode.

## Interactions

- **Read-only** tags are non-interactive status indicators.
- **Clickable** tags toggle selected/unselected; selected uses brand-filled treatment.
- **Editable** tags support text focus (`Focus on Text=True`) for both no-label and with-label modes.
- Clicking editable tag body should transfer focus to text region and emit `onTextFocus` when focused.
- **Closable** tags expose close affordance and removal event.
- **Badge tags** preserve badge readability across default/error/disabled + focus states.

### Accessibility
- Tag root must expose readable text (`aria-label` when composed content is not text-only).
- Close button must include an action label (e.g., `Remove <tag name>`).
- Selected clickable tags should expose selected state (`aria-pressed` or equivalent selection semantics).

## Composition & API (runtime)

- `type`: `info | success | minor | major | critical | non-alerting`
- `size`: `small | large` (large for non-alerting large tag variants)
- `readOnly`: `boolean`
- `clickable`: `boolean`
- `selected`: `boolean` (clickable tags)
- `defaultSelected`: `boolean` (uncontrolled clickable initial state)
- `editable`: `boolean`
- `focusOnText`: `boolean`
- `showLabel`: `boolean`
- `labelText`: `string` (e.g., `"Label:"`)
- `closable`: `boolean`
- `badgeCount`: `number | null`
- events:
  - `onClick` (clickable)
  - `onSelectedChange` (clickable toggle state change)
  - `onRemove` (closable)
  - `onTextFocus` / `onTextBlur` (editable focus variants)

## Codegen Contract (Framework-Agnostic Blueprint)

This section is normative for generation and validation.

### Deterministic structure
- `root`
  - optional `labelPrefix`
  - `valueText`
  - optional `badge`
  - optional `closeButton`

### Supported matrix
- Type: `info | success | minor | major | critical | non-alerting`
- Mode: `readOnly | clickable | editable | closable | badge`
- Size: `small | large`
- Booleans: `selected`, `showLabel`, `focusOnText`

### Slot style contract
- Capsule sizing/padding/gap by mode/size must match this spec.
- Clickable selected vs unselected palette is deterministic.
- Editable text-focus ring must be `1px` brand with `2px` radius.
- Closable icon sizing and state transitions follow `Tag-Element-Close`.

### Behavior and accessibility contract
- Clickable toggles selection and emits `onSelectedChange`.
- Editable focuses internal text region (not outer capsule).
- Closable emits remove action on close activation.
- Close button has accessible name.

### Fallback/error rules
- Unknown type -> fallback `non-alerting`.
- If `badgeCount` missing/null, badge slot omitted.
- If `closable=false`, close slot omitted.

### Validation checklist
- [ ] All alerting and non-alerting variants match token/state mapping.
- [ ] Clickable selection toggles deterministically.
- [ ] Editable focus-on-text behavior and ring match spec.
- [ ] Badge layout spacing remains valid in all states.
- [ ] Accessibility semantics pass.
