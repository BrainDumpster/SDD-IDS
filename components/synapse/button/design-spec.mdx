## Anatomy

The button component set is built from:
- **root** (`button` element)
- **label** (text)
- **icon** (optional leading icon)
- **icon-only glyph** (when `Icon Only=Yes`)
- **loading spinner** (implementation behavior)

Variant axes present in Figma (`47808:31665`):
- `Style`: `Primary | Secondary | Tertiary | Destructive`
- `State`: `Default | Hover | Press | Focus | Disabled`
- `Size`: `Large | Medium | Small`
- `Icon`: `No | Yes`
- `Icon Only`: `No | Yes`
- `Low Res`: `No` (single option in inspected set)

## Layout & Measurements

### Size and spacing
- Shared layout: horizontal auto-layout with `itemSpacing: 8px`.
- Border radius: `var(--corner-radius-radius-4)`.
- Border width: `var(--border-width-border-1)` for bordered variants.

| Size | Height | Vertical padding | Horizontal padding | Label typography |
|---|---:|---:|---:|---|
| Large | 40px | 10px top / bottom | 16px left / right | Roboto 14 / 20, weight 400 |
| Medium | 32px | 6px top / bottom | 16px left / right | Roboto 14 / 20, weight 400 |
| Small | 24px | 2px top / bottom | 16px left / right | Roboto 14 / 20, weight 400 |

### Icon layouts
- Icon + label (`Icon=Yes`, `Icon Only=No`, large):
  - Height `40px`, width sample `98px`
  - Icon size `16x16`
  - Internal gap `8px`
- Icon-only (`Icon Only=Yes`, large):
  - Height `40px`, width sample `48px`
  - Padding `12px 16px`
  - Icon size `16x16`

> Width values are content-driven samples from Figma instances and should remain intrinsic in implementation.

## Tokens

Use semantic tokens from `components/synapse-theme.css` and root spec. Do not hardcode colors in implementation code.

Core tokens used by button variants:
- `var(--color-background-controls-brand-base)` (primary default)
- `var(--color-border-transparent-brand)` (primary border)
- `var(--color-background-controls-brand-strong)` (primary hover)
- `var(--color-background-controls-brand-stronger)` (primary pressed; map to closest semantic token for `#004E88` where needed)
- `var(--color-border-brand-base)`
- `var(--color-text-brand-strong)` (secondary/tertiary label)
- `var(--color-background-gray-neutral-lighter)` (secondary background)
- `var(--color-text-white)`
- `var(--color-background-brand-lighter)` / `var(--color-background-brand-light)` (hover/press surfaces for secondary/tertiary)
- `var(--color-background-alerting-critical)` (destructive default)
- `var(--color-border-alerting-transparent-critical)` (destructive border)
- `var(--color-background-gray-light)` + `var(--color-text-disabled)` + `var(--color-border-disabled)` (disabled)
- **Focus:** keep each variant’s default/hover border treatment on the button surface, and add a **visible outer focus indicator**: `1px` solid `var(--color-border-brand-base)` drawn **3px outside** the button bounds (same ring color for Primary, Secondary, Tertiary, and Destructive in the published set).

Typography and geometry tokens:
- `var(--font-size-body-2)` + `var(--font-line-height-line-height-20)`
- `var(--corner-radius-radius-4)`
- `var(--spacing-space-8)`

## States (Dark Theme)

Same structural state matrix as light theme; values must resolve through dark semantic tokens:
- Primary/brand hues resolve to dark brand ramps (`--color-background-controls-brand-*` dark values).
- Secondary/tertiary border and text resolve to dark brand/text tokens.
- Disabled uses dark disabled tokens (`--color-text-disabled`, `--color-border-accessible`, gray backgrounds in dark mode).
- Focus follows the same variant border treatment on the surface; the outer focus ring uses `var(--color-border-brand-base)` (resolve to dark-theme brand border token).

## Interactions

- Click / Enter / Space activates button when enabled.
- `Disabled` state prevents activation and pointer interaction.
- `Focus` state keeps variant-specific **surface** border treatment and adds the **outer** 1px brand focus ring at 3px offset (`var(--color-border-brand-base)`, `var(--border-width-border-1)`). On a native `<button>`, implement this with **`:focus-visible`** (and suppress the user-agent focus ring with `outline: none` on the base control); Base UI `Button` does not emit `data-focus-visible` for this primitive.
- `Hover` and `Press` states use variant-specific color transitions.
- Icon-only buttons must expose accessible text via `aria-label`.
- Loading state (when implemented) should set `aria-busy="true"` and suppress duplicate clicks.
