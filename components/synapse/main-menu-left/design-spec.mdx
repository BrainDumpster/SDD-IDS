## Anatomy

Deterministic slot order:
1. `MainMenuLeftRoot`
2. `PrimarySection`
   - repeated `PrimaryItem`
     - `PrimaryItemContainer`
     - `PrimaryLeadingIcon`
     - `PrimaryLabel` (hidden in icon-only mode)
     - optional `PrimaryActionButton` (`shape-plus`)
     - optional `PrimaryChevron` (`chev-right-thick` / `chev-down-thick`)
     - optional `PrimaryFocusRing`
     - optional `PrimarySelectedInset`
3. optional `SecondarySection` (rendered only when primary item expands)
   - repeated `SecondaryItem`
     - `SecondaryLabel`
4. `BottomToggleArea`
   - `CollapseExpandToggleButton` (`double-chev-left` in expanded, `double-chev-right` in collapsed)

## Layout & Measurements

- Expanded container width: `250px`; collapsed container width: `64px`.
- Main nav height sample: `700px`; runtime height is container-driven.
- Primary row height: `40px`.
- Primary row horizontal padding: `24px`.
- Primary row gap: `16px` between icon and label/action area.
- Primary icon size: `16px`.
- Chevron size: `14px`.
- Focus ring geometry on row: `1px` border with `4px` radius around `40px` row.
- Selected inset indicator: `4px` left inset stripe.
- Secondary item row height: `32px`.
- Secondary item left indent: `58px`; right padding: `16px`.
- Secondary item text size: `14px / 20px`.
- Bottom toggle area sits at container bottom with divider border above.
- Bottom toggle area padding: horizontal `24px`, vertical `16px`; toggle icon aligns to bottom edge (`items-end` behavior).
- Root surface includes `linear-gradient(180deg, var(--color-background-gradient-left-nav-start) 0%, var(--color-background-gradient-left-nav-end) 100%)` over base surface.

Runtime layout rules:
- `Expanded` shows icon + label + optional secondary section.
- `Collapsed` shows icon-only item rows.
- Label text is visually hidden (not removed semantically) in collapsed mode.
- Secondary section is rendered only for `Secondary Menu=Expanded`.

## Interactions

- Selecting a primary item updates its state to `selected` (or `selected-focus` when keyboard-focused).
- Hover and press states apply to interactive rows only.
- `Secondary Menu=Expanded` on a primary item reveals secondary items below that row.
- In collapsed mode, only primary icons and bottom toggle control remain visible.
- Bottom toggle switches container state between expanded/collapsed.
- Focus-visible state uses explicit focus ring and must be keyboard-triggered.

  - `primaryIcon: string`
  - `secondaryItems?: { key: string; label: string }[]`

Accessibility runtime contract:
- Root uses navigation semantics (`nav` landmark + list structure).

- Current page/menu item is exposed via `aria-current` or `aria-selected`.
- Collapsed rows keep accessible labels via text or `aria-label`.

## Codegen Contract (Framework-Agnostic Blueprint)

Deterministic structure:
- `MainMenuLeftRoot`
  - repeated `PrimaryItem`
    - `PrimaryLeadingIcon`
    - optional `PrimaryLabel`
    - optional `PrimaryActionButton`
    - optional `PrimaryChevron`
    - optional `PrimaryFocusRing`
    - optional `PrimarySelectedInset`
    - optional `SecondarySection`
      - repeated `SecondaryItem`
  - `BottomToggleArea`
    - `CollapseExpandToggleButton`

Variant/option matrix:
- `containerState`: `expanded | collapsed`
- `primaryState`: `default | hover | press | selected | default-focus | selected-focus`
- `secondaryMenu`: `expanded | collapsed`
- `showPrimaryActionButton`: `true | false`

Per-slot style contract:
- Primary row height fixed at `40px`; secondary row fixed at `32px`.
- Expanded root width `250px`; collapsed root width `64px`.
- Selected inset width fixed at `4px`.
- Focus ring border width fixed at `1px`.
- Icon slots map to tokenized color states, no hardcoded hex.

Behavior contract:
- Exactly one selected primary item at a time (unless host allows none).
- Secondary expansion can be single-open or controlled by host; default single-open.
- In collapsed mode, secondary section is not rendered.
- Row interaction state precedence: `selected-focus` > `focus` > `press` > `hover` > `default`.

Accessibility contract:
- Keyboard: `Tab` focus traversal; `Enter/Space` activate row.
- Arrow-key roving is optional but must be consistent if implemented.
- Focus ring visible on keyboard focus for both selected and unselected rows.
- Collapsed toggle button has explicit label (`Expand navigation` / `Collapse navigation`).

Asset resolution + bundling contract:
- Primary icon names are consumer-provided and resolved through the project icon component.
- Chevron assets: `chev-right-thick` and `chev-down-thick`.
- Bottom toggle assets: `double-chev-left` and `double-chev-right`.
- Optional action icon asset: `shape-plus`.
- Apply global icon fallback rule from root spec (icon component first, then asset fallback).

Fallback/error rules:
- Unknown primary state -> fallback `default`.
- Missing icon name -> render placeholder icon slot and emit generator warning.
- Empty secondary list with `secondaryMenu=expanded` -> render no secondary rows.
- Invalid `selectedKey` -> no selected row; keep focus behavior intact.

Validation checklist:
- [ ] Expanded and collapsed container states match width/visibility rules.
- [ ] Primary row states map to correct bg/border/text/icon tokens.
- [ ] Secondary section renders only for expanded secondary state.
- [ ] Selected inset and focus ring can co-exist (`selected-focus`).
- [ ] Icon-only collapsed rows keep accessible labels.
- [ ] Bottom toggle semantics and icon state are correct.
- [ ] No hardcoded color literals in generated output.
