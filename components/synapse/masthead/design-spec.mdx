## Anatomy

1. **`mastheadRoot`**: top horizontal chrome bar.
2. **`brandGroup`**: optional **`logoSlot`** + required **`productName`** text.
3. **`actionsGroup`**: right-aligned controls; order is deterministic:
   - **`actionButtonContainer`** inside **`iconsSlot`** (optional), containing one or more **`actionIconButton`** children; commonly help icon first
   - **`appLauncherSlot`** (optional; usually trigger for App Launcher)
   - **`avatarSlot`** (required, last visual item; initials chip or user icon chip)
4. **`overlaySlot`** (optional): contextual floating menu/panel anchored to avatar or app launcher (example: profile menu, app launcher dropdown).

## Layout & Measurements

- **Masthead bar**
  - Height: `var(--scale-48)`.
  - Horizontal padding: `var(--padding-padding-16)`.
  - Layout: `display: flex`, `justify-content: space-between`, vertical center alignment.
  - Background: masthead gradient from `var(--color-background-gradient-masthead-start)` to `var(--color-background-gradient-masthead-end)`.
- **Brand group**
  - Horizontal gap between optional logo and product name: `var(--spacing-space-8)` to `var(--spacing-space-24)` depending on logo footprint.
  - Product name style: body-2 regular, white text token.
- **Actions group**
  - Right aligned, full masthead-height interactive rail.
  - Gap between controls: `0` (visual separation comes from per-control horizontal padding).
  - Icon action grouping: `actionButtonContainer` uses `inline-flex`, stretches to masthead height, and hosts one or more child actions.
  - Icon control geometry (normative): 16x16 glyph with `padding-inline: var(--padding-padding-16)`, `padding-block: 0`, and full-height background fill.
  - App launcher trigger follows the same geometry and must anchor its overlay to masthead bottom (`sideOffset: 0` equivalent behavior).
- **Avatar slot**
  - Chip sample size: `24x24`.
  - Shape: circle.
  - Border: 1px white/translucent stroke.
- **Overlays (example in frame)**
  - Profile/App menu width sample: 269px.
  - Border: `var(--border-width-border-1)` + neutral-light border token.
  - Shadow: two-layer dropdown shadow (2px/4px stack).

## Interactions

- Masthead remains fixed visual chrome while page content scrolls (app dependent).
- `iconsSlot` and `appLauncherSlot` controls are consumer-owned interactions; masthead only provides placement.
- `avatarSlot` is the final action and can open user menu/popover.
- Keyboard:
  - `Tab` order follows anatomy order: icons -> app launcher -> avatar.
  - `Enter` / `Space` activates the focused action.
  - `Esc` closes any open overlay/popover when supported by child control.

## Codegen Contract (Framework-Agnostic Blueprint)

### Deterministic structure

```
mastheadRoot
├── brandGroup
│   ├── logoSlot? 
│   └── productName
└── actionsGroup
    ├── iconsSlot?
    ├── appLauncherSlot?
    └── avatarSlot (required, last)
```

### Variant / option matrix

| logo | iconsSlot | appLauncherSlot | avatarSlot | Valid |
|---|---|---|---|---|
| no | no | no | initials/user icon | yes |
| no/yes | yes | no | initials/user icon | yes |
| no/yes | yes/no | yes | initials/user icon | yes |
| any | any | any | missing | **invalid** |

### Per-slot style contract

- `mastheadRoot`: gradient background + fixed 48px height + 16px horizontal padding.
- `productName`: body-2 regular white text.
- `iconsSlot`: `actionButtonContainer` with one or more `actionIconButton` children; each child is full masthead height with 16px horizontal padding on both sides and a centered 16px glyph.
- `appLauncherSlot`: launcher trigger follows the same full-height control geometry and opens overlay attached to masthead bottom edge.
- `avatarSlot`: circular affordance, 24px sample size, bordered.

### Behavior contract

- Order of right controls is fixed by slot contract.
- Action icons are grouped using `actionButtonContainer`; each icon is an independent interactive child.
- Masthead must not impose child-specific business logic (icons/app launcher/avatar actions remain external).
- Maintain keyboard reachability and visible focus for each actionable child.

### Accessibility contract

- `mastheadRoot` uses semantic `header` role (or native `<header>`).
- Actionable children in slots must provide accessible names (`aria-label`) and focus-visible styles.
- Product name remains readable at AA contrast against masthead background.

### Asset + bundling contract

| Asset slug | Path |
|---|---|
| `help-circ-16` | `assets/icons/help-circ-16.svg` |
| `grid-square-9-16` | `assets/icons/grid-square-9-16.svg` |
| `user-single-16` | `assets/icons/user-single-16.svg` |

Assets are optional per slot usage; bundle locally, do not use temporary Figma-hosted URLs in production.

### Fallback / error rules

- Missing `productName`: codegen error (required).
- Missing `avatarSlot`: codegen error (required last slot).
- Unknown icon assets: render fallback text/icon placeholder with accessible label.
