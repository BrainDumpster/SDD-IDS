## Anatomy
Deterministic slot order:
1. `root`
2. `formLabelSlot` (optional)
3. `control`
4. `track`
5. `thumb`
6. `stateTextSlot` (optional, "On" / "Off")

## Layout & Measurements
- Root layout: inline row, `align-items: center`, `gap: var(--spacing-space-8)`.
- Control visual size: `2rem x 1rem` (`32px x 16px`) for the track body; border is external (effective outer size = body + border).
- Thumb visual size: `1rem x 1rem` (`16px x 16px`).
- Focus outer geometry: `38px x 22px` with rounded capsule.
- Track radius: capsule.
- State text line-height: `16px`.
- Form-label text style: `Body 2`.
- On/off state text style: `Body 2`.

## Interactions
- Click/tap toggles checked state when enabled.
- Keyboard:
  - `Tab` focuses control.
  - `Space` toggles checked state.
- Focus-visible shows an outer ring capsule around control (`38x22` geometry).
- Hover styles apply only when enabled.
- Disabled blocks state changes and emits no change event.

## Composition & API (runtime)
Required runtime inputs:
- `checked?: boolean`
- `defaultChecked?: boolean`
- `onCheckedChange?: (checked: boolean) => void`
- `disabled?: boolean`
- `showLabel?: boolean` (default `true`)
- `label?: string` (default `"Label:"`)
- `required?: boolean` (default `true` in examples)
- `showOnOffOption?: boolean` (default `true`)
- `id?: string`
- `name?: string`
- `aria-label?: string`
- `aria-describedby?: string`
- `value?: string`

Runtime outputs:
- `onCheckedChange(checked: boolean)` emits exactly once per successful toggle.
- No change event is emitted when `disabled=true`.

Controlled/uncontrolled rule:
- If `checked` is provided, component is controlled and runtime must not mutate internal state without parent update.
- If `checked` is omitted, component may manage internal state initialized by `defaultChecked`.

## Codegen Contract (Framework-Agnostic Blueprint)
Deterministic rendering rules:
- Render a semantic switch primitive (`input[type="checkbox"]` or equivalent ARIA switch behavior).
- Preserve visual control geometry (`32x16`) and focus outer geometry (`38x22`).
- Keep state text slot optional and synchronized with checked state:
  - checked `true` -> `"On"`
  - checked `false` -> `"Off"`
- Keep form-label slot optional and independent from state text slot.
- Apply `box-sizing: content-box` for track body sizing, so declared `2rem x 1rem` excludes border thickness.

Variant/option matrix:
- `checked`: `false | true`
- `disabled`: `false | true`
- `showLabel`: `false | true`
- `showOnOffOption`: `false | true`

Per-slot style contract:
- `control/track`
  - body size: `2rem x 1rem` (content box)
  - border: `var(--border-width-border-1)` with state-driven border tokens
  - radius: capsule
- `thumb`
  - size: `1rem x 1rem`
  - border: `var(--border-width-border-1)` with `thumb.border` / `thumb.disabled.border`
  - translation on checked: `1rem`
- `focus.outer`
  - absolute capsule, `38x22`, `1px` brand border
  - rendered only for focus-visible interaction mode
- `formLabelSlot`
  - text token: `formLabel.text`
- `stateTextSlot`
  - text token: `stateText.default` or `stateText.disabled`

Accessibility contract:
- Preserve keyboard toggle with `Space`.
- Ensure accessible name through visible label or `aria-label`.
- Keep focus-visible indicator always perceivable.

Fallback/error rules:
- Missing optional label/state-text props fall back to hidden/disabled slot without layout break.
- Unknown variant options fall back to defaults.
- Missing `onCheckedChange` in controlled usage must be flagged by generator diagnostics.
- Missing accessible name (`showLabel=false` and no `aria-label`) must be flagged as validation error.

Validation checklist:
- [ ] Slot order matches anatomy.
- [ ] Light and dark state tables are structurally parallel.
- [ ] Focus-visible outer ring appears around control, not on text slots.
- [ ] Disabled mode blocks interaction and uses disabled token mappings.
- [ ] On/off state text remains synchronized with checked state when visible.
- [ ] Controlled/uncontrolled precedence is deterministic (`checked` wins over `defaultChecked`).
- [ ] Track body size excludes border (`content-box` sizing rule preserved).
