# Text Box Design Spec

## Metadata
- Component: Text Box
- Category: Formelements

## Anatomy
- Input field container
- Text input area
- Optional label
- Optional helper text
- Optional validation message
- Focus ring for keyboard navigation
- Optional clear button

## Layout & Measurements
- Standard height: 40px
- Horizontal padding: 12px
- Vertical padding: 8px
- Border radius: 4px (standard)
- Focus ring: 2px offset from container
- Label spacing: 4px from input
- Helper text spacing: 4px from input
- Minimum width: 200px (expandable)

## Typography
- Header 5: Roboto Regular 24px/32px (large text boxes)
- Header 6: Roboto Regular 18px/25px (medium text boxes)
- Body 1 - Medium: Roboto Medium 16px/24px (input text)
- Body 2: Roboto Regular 14px/20px (labels, helper text)

## States (Dark Theme)
- Uses semantic tokens that automatically adapt to dark theme
- Text and border colors remain consistent via semantic variables
- Disabled state uses gray tokens for dark theme compatibility
- Error state uses critical colors for validation feedback

## Interactions
- Click to focus input field
- Typing updates input value
- Hover provides visual feedback with border changes
- Focus ring uses brand color for keyboard navigation
- Disabled state prevents interaction and uses gray colors
- Error state shows critical border for validation
- Clear button appears when text is present

## Accessibility
- Focus ring: 2px brand color border
- Keyboard navigation: Tab to input, type to input, Enter to submit
- Screen reader support: Proper ARIA labels and descriptions
- High contrast: Meets WCAG AA standards with provided colors
- Semantic HTML: Use appropriate input types and attributes
- Error messages: Proper association with input field

## Variants
- **Default**: Standard text input
- **Multiline**: Textarea for longer content
- **Password**: Input with masked characters
- **Search**: With search icon and clear button
- **Error**: With validation styling
- **Disabled**: Non-interactive state
- **Sizes**: Small (32px), Medium (40px), Large (48px)

## Behavior & Guidelines
- Use text boxes for user input of text data
- Provide clear labels describing expected input
- Use appropriate input types (email, password, etc.)
- Show validation errors clearly and accessibly
- Implement proper focus management
- Test with screen readers for proper announcement
- Use placeholder text for additional guidance

## Token Gaps / Notes
- All colors use semantic CSS custom properties for theme consistency
- Typography scales are defined via font tokens with proper hierarchy
- Focus states use brand colors for visual consistency
- Disabled states maintain accessibility with proper contrast
- Error states use critical colors for validation feedback
- Input validation should be implemented with proper ARIA
