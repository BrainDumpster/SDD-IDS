# Tree Design Spec

- Category: Navigation

## Anatomy
- Tree container
- Tree nodes with expand/collapse functionality
- Node icons (folder/file icons)
- Node labels
- Expand/collapse arrows
- Selection indicators
- Focus ring for keyboard navigation
- Optional checkboxes for multi-select
- Drag and drop handles (optional)
## Layout & Measurements
- Node height: 32px
- Node indentation: 20px per level
- Horizontal padding: 8px
- Icon size: 16px × 16px
- Expand arrow size: 12px × 12px
- Checkbox size: 16px × 16px
- Border radius: 4px (selection)
- Focus ring: 2px offset from node
- Spacing between nodes: 0

## States (Dark Theme)
- Uses semantic tokens that automatically adapt to dark theme
- Surface tokens: `var(--color-background-surface-1)` (#111619)
- Text and border colors remain consistent via semantic variables
- Selected nodes use brand colors for clear indication
- Expand/collapse icons adapt to dark theme
## Interactions
- Click nodes to select/deselect
- Click expand arrows to expand/collapse branches
- Hover provides visual feedback with background changes
- Focus ring uses brand color for keyboard navigation
- Keyboard navigation: Arrow keys, Enter, Space, Tab
- Multi-select with checkboxes (optional)
- Drag and drop to reorganize tree (optional)
- Double-click to rename nodes (optional)
### Accessibility
- Focus ring: 2px brand color border
- Keyboard navigation: Arrow keys, Enter, Space, Tab
- Screen reader support: Proper ARIA attributes for tree structure
- High contrast: Meets WCAG AA standards with provided colors
- Semantic HTML: Use ul/li elements with proper tree roles
- Focus management: Logical tab order through tree nodes
- Expansion announcements: Screen reader announces expand/collapse

### Behavior & guidelines
- Use tree view for hierarchical data display
- Provide clear visual hierarchy with indentation
- Use consistent icons for node types
- Test with screen readers for proper tree structure announcement
- Consider keyboard navigation for accessibility
- Use responsive design for different screen sizes
- Provide visual feedback for all interactions
- Consider performance for large trees

- **Default**: Standard tree view
- **Multi-select**: Tree with checkboxes for selection
- **Draggable**: Tree with drag and drop functionality
- **Editable**: Tree with inline editing
- **Compact**: Reduced node height
- **Large**: Increased node height and icons
- **With Search**: Tree with search/filter functionality
- **Virtual**: Virtual scrolling for large trees
