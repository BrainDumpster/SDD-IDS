## Anatomy
- `DatagridRoot`
- `DatagridHeader`
  - `SelectAllColumn` (optional; checkbox column when multiselect is enabled)
  - repeated `DatagridColumnHeader`
    - `ColumnTitle` (user-defined, ellipsis when constrained)
    - `SortToggle` (optional)
    - `FilterToggle` (optional)
    - `ResizeHandle`
  - `SettingsColumn` (always last, always visible, fixed width `40px`, icon `settings-gear`)
- `DatagridBody`
  - repeated `DatagridRow`
  - repeated `DatagridCell`
  - `RowSelectionCell` (optional)
- `DatagridFooter`
  - `DatagridPaginationSlot` (IDS Pagination)
- Optional side attachment:
  - `DatagridDetailPanelSlot` (IDS Detail Panel datagrid variant)

## Layout & Measurements
- Header height: `48px` (`Grid height/Header` token evidence from MCP).
- Row height baseline: `40px` (`Grid height/Cell` token evidence from MCP).
- Column width rules:
  - minimum data column width: `90px` (includes optional sort/filter affordances when present).
  - settings column width: `40px` fixed.
  - select-all/row-selection column width follows checkbox-column pattern from IDS column definitions (`48px` sample family).
  - first header checkbox column (`SelectAllColumn`) layout contract:
    - `padding: var(--Selection-Header, 16px) 16px`
    - `display: flex`
    - `flex-direction: column`
    - `justify-content: center`
    - `align-items: center`
    - `gap: 16px`
    - `align-self: stretch`
    - checkbox primitive must follow `components/ids/checkbox/design-spec.mdx` (`controlBox` remains `16px x 16px` and checkbox state semantics are inherited from IDS checkbox spec)
- Horizontal scrolling:
  - scrollable region: data columns between leading pinned columns and trailing settings column.
  - non-scrollable pinned regions:
    - select-all column (when present)
    - settings column (always)
    - optional freeze range (`freezeUntilColumnKey`, inclusive)
- Column title overflow:
  - title must truncate with ellipsis when width constraints are reached.
- Resize constraints:
  - drag-resize handles are per-header separators.
  - column width cannot be reduced below min width (`90px`, or explicit per-column override if provided later).
- Row content overflow:
  - when width reaches min and text still overflows, body cell values use ellipsis (example behavior: `Rowval...`).
- View modes:
  - `table` view
  - `treeview` view (hierarchical indent/expand behavior for tree columns)

## Interactions
- Sort:
  - clicking sort toggle cycles between ascending and descending for the active column (single-column sort contract).
  - sort icon names are fixed: `col-sort-up-16`, `col-sort-down-16`.
- Filter:
  - clicking filter toggle opens column filter popup.
  - popup content is consumer-defined; base popup chrome follows IDS filter popup structure reference.
- Selection:
  - when `multiselect` is enabled, first header column includes select-all checkbox.
  - row checkboxes reflect and control row selection state.
  - select-all checkbox and row checkboxes reuse IDS Checkbox interaction/state/a11y rules from `components/ids/checkbox/design-spec.mdx`.
- Column resize:
  - drag header separator to resize column.
  - width clamp enforces min-width (`90px` or future explicit override).
- Column reorder:
  - drag-and-drop header columns to rearrange order.
- Freeze columns:
  - columns from start through `freezeUntilColumnKey` (inclusive) remain pinned and do not horizontally scroll.
- Row click:
  - clicking row emits row click event and may open attached detail panel.
- Footer:
  - pagination slot attaches IDS Pagination behavior/component.

## Composition & API (runtime)
- Required:
  - `columns: DatagridColumn[]`
  - `rows: DatagridRow[]`
  - `viewMode: "table" | "treeview"`
- Optional:
  - `multiselect?: boolean` (default `false`)
  - `showSettingsColumn?: boolean` (default `true`)
  - `settingsColumnAlwaysVisible?: boolean` (default `true`)
  - `freezeUntilColumnKey?: string | null`
  - `detailPanel?: { enabled: boolean; content?: Renderable }`
  - `pagination?: IDS Pagination props`
  - `columnMinWidth?: number` (default `90`)
  - `nonHideableColumnKeys?: string[]` (columns always visible in settings popup)
- Events:
  - `onSortChange?: (columnKey: string, direction: "asc" | "desc") => void`
  - `onFilterToggle?: (columnKey: string, open: boolean) => void`
  - `onFilterApply?: (columnKey: string, payload: unknown) => void`
  - `onColumnResize?: (columnKey: string, width: number) => void`
  - `onColumnOrderChange?: (orderedColumnKeys: string[]) => void`
  - `onColumnVisibilityChange?: (columnKey: string, visible: boolean) => void`
  - `onRowClick?: (rowKey: string) => void`
  - `onSelectionChange?: (selectedRowKeys: string[]) => void`

## Codegen Contract (Framework-Agnostic Blueprint)
- Deterministic slot schema:
  1. `DatagridRoot`
  2. `DatagridHeader`
  3. `DatagridBody`
  4. optional `DatagridDetailPanelSlot`
  5. `DatagridFooter`
- Variant matrix:
  - `viewMode`: `table | treeview`
  - `multiselect`: `on | off`
  - `detailsPanel`: `attached | none`
  - `filterPopup`: `closed | open`
  - `sortState`: `asc | desc`
  - `rowState`: `default | hover | selected`
- Per-slot style contract:
  - data columns honor min-width `90px`.
  - `SettingsColumn` width is fixed `40px` and pinned.
  - select-all column and settings column do not participate in horizontal scrolling.
  - `SelectAllColumn` header cell uses this deterministic layout:
    - `padding: var(--Selection-Header, 16px) 16px`
    - column flex container centered in both axes, `gap: 16px`, `align-self: stretch`
    - slot content uses IDS Checkbox component contract from `components/ids/checkbox/design-spec.mdx` (no custom checkbox styling override).
  - title/value overflow uses ellipsis in constrained widths.
  - filter icons use exact state/icon mapping:
    - default: `filter`
    - hover: `filter-solid` + `var(--color-icon-neutral)` (`14x14`)
    - selected: `filter-solid` + `var(--color-icon-brand-base)` (`14x14`)
    - press: `filter-solid` + `var(--color-icon-brand-stronger)` (`14x14`)
- Behavior contract:
  - sort toggles ascending/descending for active column.
  - resize clamps at min width and emits resize event.
  - reorder emits updated column order.
  - settings popup controls column visibility and enforces always-visible columns.
  - row click can trigger optional detail panel open flow.
- Accessibility contract:
  - use semantic table/treegrid roles as applicable to mode.
  - sortable headers expose `aria-sort`.
  - select-all and row checkboxes expose correct checked/mixed states.
  - checkbox semantics (`aria-checked`, mixed state, disabled rules, keyboard space toggle) are delegated to IDS Checkbox spec contract at `components/ids/checkbox/design-spec.mdx`.
  - filter and settings controls expose `aria-haspopup` + `aria-expanded` when popup is used.
- Asset/bundling:
  - sort icons: `col-sort-up-16`, `col-sort-down-16`
  - filter icons: `filter`, `filter-solid`
  - settings icon: `settings-gear` (`16x16`, neutral)
  - use project `Icon` component with shape names when available; inline SVG fallback only if no icon primitive exists.
- Fallback/error rules:
  - unknown view mode -> fallback to `table`.
  - invalid min width (`<=0`) -> fallback to `90`.
  - missing column key in freeze config -> ignore freeze boundary.
  - hidden column requested for non-hideable key -> ignore and keep visible.
- Validation checklist:
  - [ ] table + treeview modes are both represented.
  - [ ] first checkbox header column follows exact layout contract (`padding var(--Selection-Header, 16px) 16px`, centered flex column, gap `16px`, stretch alignment).
  - [ ] select-all and row checkboxes reuse IDS Checkbox spec contract without visual or behavior drift.
  - [ ] sort/filter icon mapping and state colors match contract.
  - [ ] column min-width (`90px`) and ellipsis behavior are enforced.
  - [ ] settings column remains fixed `40px` and non-scrollable.
  - [ ] select-all/settings pinned behavior is preserved during horizontal scrolling.
  - [ ] resize/reorder/filter/sort/selection events are emitted.
  - [ ] detail panel attaches and opens via row click when configured.
  - [ ] footer pagination integration uses IDS Pagination slot.
