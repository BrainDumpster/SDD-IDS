- Border radius: 4px
- Focus ring: 2px offset from alert
- Icon size: 16px × 16px

- Minimum width: 200px
- Spacing between elements: 8px

## Typography
- Body 1: Roboto Regular 16px/24px (alert messages)
- Body 2: Roboto Regular 14px/20px (secondary text)

## States (Dark Theme)
- Uses semantic tokens that automatically adapt to dark theme
- Static colors provide consistent appearance
- Alert colors maintain visibility in dark theme
- Light backgrounds ensure readability

## Interactions
- Click close button to dismiss alert
- Hover provides visual feedback on close button
- Focus ring uses brand color for keyboard navigation
- Auto-dismiss after timeout (optional)
- Action buttons for user responses
- Keyboard navigation: Tab to alert, Enter for action, Escape to dismiss

## Accessibility
- Focus ring: 2px brand color border
- Keyboard navigation: Tab to alert, Enter for actions, Escape to dismiss
- Screen reader support: Proper ARIA attributes and alert announcements
- High contrast: Meets WCAG AA standards with provided colors
- Semantic HTML: Use alert element with proper role
- Focus management: Auto-focus on new alerts
- Dismiss announcements: Screen reader announces when alert is dismissed

## Variants
- **Info**: Blue informational alert
- **Success**: Green success alert
- **Warning**: Yellow warning alert
- **Error**: Orange error alert
- **Critical**: Red critical alert
- **With Title**: Alert with heading
- **With Action**: Alert with action button
- **Persistent**: Alert that requires user action

## Behavior & Guidelines
- Use inline alerts for contextual messages
- Position alerts near relevant content
- Use appropriate color variants for severity levels
- Provide clear, concise messages
- Include dismiss functionality for non-critical alerts
- Test with screen readers for proper announcement
- Consider auto-dismiss for non-critical notifications
- Use consistent styling across alert types

## Token Gaps / Notes
- All colors use semantic CSS custom properties for theme consistency
- Typography scales are defined via font tokens with proper hierarchy
- Focus states use brand colors for visual consistency
- Alert variants use appropriate color psychology
- Light backgrounds ensure text readability
- Dark theme adaptation through semantic tokens
