- Focus ring: 2px offset from element

- Spacing between sections: 16px

## States (Dark Theme)
- Uses semantic tokens that automatically adapt to dark theme
- Text and border colors remain consistent via semantic variables
- Panel container maintains visibility in dark theme
- Status indicators maintain visibility

## Interactions
- Click close button to collapse/close panel
- Click action buttons to perform actions
- Hover provides visual feedback on interactive elements
- Focus ring uses brand color for keyboard navigation
- Keyboard navigation: Tab to navigate, Enter to activate
- Panel can be resized (optional)
- Panel can be docked/undocked (optional)

## Accessibility
- Focus ring: 2px brand color border
- Keyboard navigation: Tab, Enter, Escape
- Screen reader support: Proper ARIA attributes for panel content
- High contrast: Meets WCAG AA standards with provided colors
- Semantic HTML: Use aside element with proper landmarks
- Focus management: Logical tab order through panel elements
- Content announcements: Screen reader announces panel content

## Variants
- **Default**: Standard detail panel
- **Collapsible**: Panel that can be collapsed
- **Resizable**: Panel that can be resized
- **Docked**: Panel docked to side of screen
- **Floating**: Floating panel overlay
- **With Tabs**: Panel with tabbed sections
- **With Actions**: Panel with action buttons
- **With Status**: Panel with status indicators

## Behavior & Guidelines
- Use detail panel for displaying detailed information
- Provide clear section headers and labels
- Use consistent styling across panel sections
- Test with screen readers for proper content announcement
- Consider responsive behavior for different screen sizes
- Use keyboard navigation for accessibility
- Provide visual feedback for all interactions
- Consider panel positioning and z-index

- Typography scales are defined via font tokens with proper hierarchy
- Focus states use brand colors for visual consistency
- Status indicators use appropriate color psychology
- Dark theme adaptation through semantic tokens
