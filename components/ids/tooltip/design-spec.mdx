## Metadata
- Component: Tooltip

## Anatomy
- Tooltip container with arrow
- Tooltip text content
- Optional icon
- Focus ring for keyboard navigation
- Positioning relative to trigger element
- Optional close button

## Layout & Measurements
- Standard padding: 8px 12px
- Border radius: 4px
- Arrow size: 8px × 8px
- Arrow offset: 16px from edge
- Focus ring: 2px offset from tooltip
- Maximum width: 200px
- Minimum width: 40px
- Z-index: High (above other elements)

## Typography

- Body 2 - Medium: Roboto Medium 14px/20px (emphasized tooltips)
- Body 2 - Underline: Roboto Regular 14px/20px (link tooltips)

## States (Dark Theme)
- Uses semantic tokens that automatically adapt to dark theme
- Surface tokens: `var(--color-background-surface-1)` (#111619), `var(--color-background-surface-2)` (#ffffff)
- Text and border colors remain consistent via semantic variables
- Alert variants maintain visibility in dark theme

## Interactions
- Hover over trigger element to show tooltip
- Click to dismiss (optional)
- Focus to show tooltip (for keyboard users)
- Escape to dismiss (optional)
- Auto-hide after timeout (optional)
- Tooltip follows mouse movement (optional)

## Accessibility
- Focus ring: 2px brand color border
- Keyboard navigation: Tab to trigger, focus to show
- Screen reader support: Proper ARIA attributes and descriptions
- High contrast: Meets WCAG AA standards with provided colors
- Semantic HTML: Use proper tooltip attributes
- Focus management: Tooltip appears on focus
- Content announcements: Screen reader announces tooltip content

## Variants
- **Default**: Standard tooltip with neutral styling
- **Info**: Blue informational tooltip
- **Success**: Green success tooltip
- **Warning**: Yellow warning tooltip
- **Error**: Red error tooltip
- **Dark**: Dark themed tooltip
- **With Icon**: Tooltip with accompanying icon
- **Persistent**: Tooltip that stays visible until dismissed

## Behavior & Guidelines
- Use tooltips to provide additional context
- Keep tooltip text concise and helpful
- Position tooltips to avoid covering important content
- Use appropriate colors for different message types
- Test with screen readers for proper content announcement
- Consider mobile touch interactions
- Use consistent positioning across the application
- Avoid critical information in tooltips

## Token Gaps / Notes
- All colors use semantic CSS custom properties for theme consistency
- Typography scales are defined via font tokens with proper hierarchy
- Focus states use brand colors for visual consistency
- Alert variants use appropriate color psychology
- Dark theme adaptation through semantic tokens
- Tooltip positioning should be intelligent and adaptive
