## Interactions
- Click menu items to navigate to respective pages
- Click submenu items to expand/collapse sections
- Click collapse button to toggle menu width
- Hover provides visual feedback with background changes
- Focus ring uses brand color for keyboard navigation
- Keyboard navigation: Arrow keys, Enter, Escape
- Active item shows persistent selection state

## Accessibility
- Focus ring: 2px brand color border
- Keyboard navigation: Arrow keys, Enter, Tab, Escape
- Screen reader support: Proper ARIA attributes for navigation
- High contrast: Meets WCAG AA standards with provided colors
- Semantic HTML: Use nav element with proper landmarks
- Focus management: Logical tab order through menu items
- Current page indication: Proper aria-current="page" attribute
