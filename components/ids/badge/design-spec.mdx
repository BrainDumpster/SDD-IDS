## Anatomy
- Badge container with rounded corners
- Badge text/content
- Optional icon
- Focus ring for keyboard navigation
- Optional count indicator

## Layout & Measurements
- Standard height: 20px
- Horizontal padding: 6px
- Vertical padding: 2px
- Border radius: 10px (pill shape)
- Focus ring: 2px offset from badge
- Minimum width: 20px (for single character)
- Icon size: 12px × 12px

## Typography
- Body 3: Roboto Regular 12px/18px (badge text)

## States (Dark Theme)
- Uses semantic tokens that automatically adapt to dark theme
- Surface tokens: `UI Palettes/Slate/slate-900` (#111619)
- Text and border colors remain consistent via semantic variables
- Badge colors maintain visibility in dark theme

## Interactions
- Click badge to trigger associated action
- Hover provides visual feedback with opacity changes
- Focus ring uses brand color for keyboard navigation
- Badges can be used as indicators or interactive elements
- Count badges update dynamically based on data

## Accessibility
- Focus ring: 2px brand color border
- Keyboard navigation: Tab to badges, Enter/Space to activate
- Screen reader support: Proper ARIA labels and state announcements
- High contrast: Meets WCAG AA standards with provided colors
- Semantic HTML: Use span element with proper attributes
- Focus management: Clear focus indication for keyboard users

## Variants
- **Default**: Neutral gray styling
- **Brand**: Primary brand color
- **Success**: Green for positive status
- **Warning**: Yellow for caution
- **Error**: Red for negative status
- **Info**: Blue for informational
- **Neutral**: Light gray for secondary information
- **Count**: Numeric indicator with circle shape

## Behavior & Guidelines
- Use badges to show status, counts, or categories
- Keep badge text concise (1-4 characters recommended)
- Use color variants to convey meaning and status
- Position badges near related content
- Test color combinations for accessibility
- Use consistent sizing across the application
- Consider badge overflow for long content

## Token Gaps / Notes
- All colors use semantic CSS custom properties for theme consistency
- Typography scales are defined via font tokens with proper hierarchy
- Focus states use brand colors for visual consistency
- Alert colors follow standard design system conventions
- Badge sizing should be consistent with text content
- Dark theme adaptation through semantic tokens
