## States (Dark Theme)
- Uses semantic tokens that automatically adapt to dark theme
- Text colors remain consistent via semantic variables
- Background colors provide subtle hover feedback
- Dark theme: `UI Palettes/Slate/slate-900` (#111619)

## Interactions
- Click link to navigate to target URL
- Hover provides visual feedback with underline and background
- Focus ring uses brand color for keyboard navigation
- Active state shows during click interaction
- Visited state indicates previously accessed links
- Disabled state prevents interaction and uses gray colors

## Accessibility
- Focus ring: 2px brand color border
- Keyboard navigation: Tab to links, Enter to activate
- Screen reader support: Proper link text and descriptions
- High contrast: Meets WCAG AA standards with provided colors
- Semantic HTML: Use anchor element with proper href
- Focus management: Clear focus indication for keyboard users
- Link text: Descriptive and meaningful text content

## Variants
- **Default**: Standard text link
- **With Icon**: Link with accompanying icon
- **Inline**: Link within paragraph text
- **Standalone**: Link as standalone element
- **Button Style**: Link styled as button
- **Underlined**: Link with permanent underline
- **External**: Link with external indicator
- **Download**: Link with download indicator

## Behavior & Guidelines
- Use links for navigation between pages
- Provide descriptive link text that indicates destination
- Use consistent styling across the application
- Ensure adequate touch targets for mobile devices
- Test with screen readers for proper link announcement
- Consider open in new tab for external links
- Use proper hover and focus states for accessibility
- Avoid link text like "click here" - use descriptive text

## Token Gaps / Notes
- All colors use semantic CSS custom properties for theme consistency
- Typography scales are defined via font tokens with proper hierarchy
- Focus states use brand colors for visual consistency
- Link states provide clear visual feedback
- Dark theme adaptation through semantic tokens
- Link styling should be consistent with brand guidelines
