# Footer Design Spec

## Metadata
- Component: Footer
- Category: Navigation

## Anatomy
- Footer container with background
- Logo/brand section
- Navigation links (multiple columns)
- Legal/copyright section
- Social media links
- Contact information
- Back to top button (optional)
- Focus ring for keyboard navigation

## Layout & Measurements
- Standard height: 200px (varies with content)
- Section padding: 24px
- Column spacing: 32px
- Link spacing: 8px vertical
- Border radius: 0 (footer typically spans full width)
- Focus ring: 2px offset from interactive elements
- Minimum width: Full viewport width
- Responsive breakpoints for mobile

## Typography
- Display 1/Default: Roboto Light 72px/88px (hero footer branding)
- Header/Header 1: Roboto Regular 28px/64px (large section headers)
- Header 4: Roboto Regular 28px/34px (section headers)
- Header 6: Roboto Regular 18px/25px (sub-headers)
- Body 1: Roboto Regular 16px/24px (main content)
- Body 2: Roboto Regular 14px/20px (secondary content)
- Body 2 - Medium: Roboto Medium 14px/20px (emphasized links)

## States (Dark Theme)
- Uses semantic tokens that automatically adapt to dark theme
- Surface tokens: `var(--color-background-surface-1)` (#f4f4f4), `var(--color-background-surface-2)` (#ffffff)
- Text and border colors remain consistent via semantic variables
- Links maintain brand colors for consistency

## Interactions
- Click navigation links to navigate to respective pages
- Hover provides visual feedback with background and text changes
- Focus ring uses brand color for keyboard navigation
- Social media links open external sites
- Back to top button scrolls to page top
- Responsive behavior for mobile devices

## Accessibility
- Focus ring: 2px brand color border
- Keyboard navigation: Tab through all interactive elements
- Screen reader support: Proper ARIA landmarks and navigation structure
- High contrast: Meets WCAG AA standards with provided colors
- Semantic HTML: Use footer element with proper landmarks
- Link descriptions: Clear link text and descriptions
- Focus management: Logical tab order through footer elements

## Variants
- **Default**: Standard footer with multiple sections
- **Minimal**: Simple footer with copyright only
- **Brand**: Footer with prominent branding
- **Dark**: Dark themed footer
- **Sticky**: Footer that stays at bottom of viewport
- **Responsive**: Adaptive layout for different screen sizes

## Behavior & Guidelines
- Use footer for site-wide navigation and information
- Organize links logically by category
- Include legal information and copyright
- Maintain consistent styling with site theme
- Test responsive behavior on mobile devices
- Ensure all links are accessible and properly labeled
- Consider back to top functionality for long pages
- Use semantic HTML for proper structure

## Token Gaps / Notes
