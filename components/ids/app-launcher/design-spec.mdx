# App Launcher Design Spec

## Metadata
- Component: App Launcher
- Category: Navigation
- Figma: https://www.figma.com/design/VZJ48bbVYrIynw8DdSukWw/-Exploration-only--IDS-with-variables?node-id=11067-54490&m=dev

## Anatomy
- App launcher container
- App grid layout
- App icons with labels
- Search functionality
- Category filters
- Recently used apps
- Focus ring for keyboard navigation
- App descriptions (optional)

## Layout & Measurements
- Grid columns: 4-6 columns (responsive)
- App card size: 120px × 120px
- Icon size: 48px × 48px
- Label height: 40px
- Card spacing: 16px
- Grid padding: 24px
- Border radius: 8px (cards)
- Focus ring: 2px offset from card
- Search bar height: 40px
- Filter height: 32px

## Typography
- Display 1/Default: Roboto Light 72px/88px (large launcher titles)
- Body 2: Roboto Regular 14px/20px (app labels and descriptions)

## States (Dark Theme)
- Uses semantic tokens that automatically adapt to dark theme
- Surface tokens: `var(--color-background-surface-1)` (#111619), `var(--color-background-surface-2)` (#ffffff)
- Text and border colors remain consistent via semantic variables
- App cards maintain visibility in dark theme
- Search and filter components adapt to dark theme

## Interactions
- Click app cards to launch applications
- Hover provides visual feedback with background changes
- Focus ring uses brand color for keyboard navigation
- Search functionality to filter apps
- Category filters to organize apps
- Keyboard navigation: Arrow keys, Enter, Tab
- Recently used apps prioritized
- Drag and drop to organize apps (optional)

## Accessibility
- Focus ring: 2px brand color border
- Keyboard navigation: Arrow keys, Enter, Tab
- Screen reader support: Proper ARIA attributes for app grid
- High contrast: Meets WCAG AA standards with provided colors
- Semantic HTML: Use grid layout with proper landmarks
- Focus management: Logical tab order through apps
- App announcements: Screen reader announces app names

## Variants
- **Default**: Standard app grid launcher
- **List View**: Linear list of applications
- **Compact**: Reduced size app cards
- **With Search**: Launcher with integrated search
- **With Categories**: Organized by app categories
- **With Recents**: Recently used apps section
- **Dark**: Dark themed launcher
- **Customizable**: User can organize and customize

## Behavior & Guidelines
- Use app launcher for application selection
- Organize apps logically by category or usage
- Provide clear app icons and labels
- Use search for large app collections
- Test with screen readers for proper app announcement
- Consider responsive design for different screen sizes
- Use consistent styling across the launcher
- Provide visual feedback for all interactions

## Token Gaps / Notes
- All colors use semantic CSS custom properties for theme consistency
- Typography scales are defined via font tokens with proper hierarchy
- Focus states use brand colors for visual consistency
- Active states use brand colors for clear indication
- Dark theme adaptation through semantic tokens
- App launcher should be responsive and accessible
