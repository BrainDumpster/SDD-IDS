## Anatomy
- Tag container with rounded corners
- Tag text/content
- Optional dismiss button (×)
- Optional status indicator
- Focus ring for keyboard navigation

## Layout & Measurements
- Standard height: 24px
- Horizontal padding: 8px
- Text padding: 4px from edges
- Border radius: 12px (pill shape)
- Dismiss button: 16px × 16px
- Focus ring: 2px offset from container
- Minimum width: 32px (for single character)

## Typography
- Body 2: Roboto Regular 14px/20px (tag text)
- Body 2 - Medium: Roboto Medium 14px/20px (emphasized tags)
- Header 6 - Medium: Roboto Medium 18px/25px (large tags)
- Header 3: Roboto Regular 32px/40px (hero tags)
- Body 1: Roboto Regular 16px/24px (medium tags)

## States (Dark Theme)
- Uses semantic tokens that automatically adapt to dark theme
- Surface tokens: `var(--color-background-surface-1)` (#111619)
- Text and border colors remain consistent via semantic variables
- Disabled state uses gray tokens for dark theme compatibility

## Interactions
- Click to select/deselect tag
- Hover provides visual feedback with opacity changes
- Focus ring uses brand color for keyboard navigation
- Dismiss button removes tag when clicked
- Disabled state prevents interaction and uses gray colors
- Multi-select behavior for tag groups

## Accessibility
- Focus ring: 2px brand color border
- Touch target: Minimum 44px × 24px for mobile accessibility
- Keyboard navigation: Tab to tags, Enter/Space to select, Escape to dismiss
- Screen reader support: Proper ARIA labels and state announcements
- High contrast: Meets WCAG AA standards with provided colors
- Semantic HTML: Use button elements for interactive tags

## Variants
- **Default**: Neutral gray styling
- **Brand**: Primary brand color
- **Success**: Green for positive status
- **Warning**: Yellow for caution
- **Error**: Red for negative status
- **Info**: Blue for informational
- **Disabled**: Non-interactive state
- **Dismissible**: With remove button
- **Sizes**: Small (20px), Medium (24px), Large (32px)

## Behavior & Guidelines
- Use tags to categorize and filter content
- Provide clear, concise text within tags
- Use color variants to convey meaning and status
- Allow multiple tags to be selected when appropriate
- Provide dismiss functionality for removable tags
- Test color combinations for accessibility
- Use consistent spacing between tags

## Token Gaps / Notes
- All colors use semantic CSS custom properties for theme consistency
- Typography scales are defined via font tokens with proper hierarchy
- Focus states use brand colors for visual consistency
- Disabled states maintain accessibility with proper contrast
- Alert colors follow standard design system conventions
- Dismiss functionality should be easily discoverable
