# Dual List Box Design Spec

## Metadata
- Component: Dual List Box
- Category: Formelements
- Figma: https://www.figma.com/design/VZJ48bbVYrIynw8DdSukWw/-Exploration-only--IDS-with-variables?node-id=11067-54563&m=dev

## Anatomy
- Dual list container
- Available items list
- Selected items list
- Transfer buttons (Add, Remove, Add All, Remove All)
- List headers with counts
- Search/filter functionality (optional)
- Focus ring for keyboard navigation
- Item checkboxes for selection
- Sort functionality (optional)

## Layout & Measurements
- Container width: 600px (minimum)
- List width: 250px each
- List height: 300px
- Item height: 32px
- Button width: 40px
- Button spacing: 8px
- Horizontal padding: 16px
- Border radius: 4px
- Focus ring: 2px offset from element
- Icon size: 16px × 16px
- Spacing between lists: 40px

## States (Dark Theme)
- Uses semantic tokens that automatically adapt to dark theme
- Text and border colors remain consistent via semantic variables
- List boxes maintain visibility in dark theme
- Transfer buttons adapt to dark theme

## Interactions
- Click items to select/deselect in lists
- Click transfer buttons to move items between lists
- Double-click items to transfer (optional)
- Hover provides visual feedback on interactive elements
- Focus ring uses brand color for keyboard navigation
- Keyboard navigation: Arrow keys, Enter, Space, Tab
- Search/filter to find items quickly
- Select multiple items with Ctrl/Cmd+click

## Accessibility
- Focus ring: 2px brand color border
- Keyboard navigation: Arrow keys, Enter, Space, Tab
- Screen reader support: Proper ARIA attributes for lists
- High contrast: Meets WCAG AA standards with provided colors
- Semantic HTML: Use select elements with proper attributes
- Focus management: Logical tab order through lists
- Transfer announcements: Screen reader announces item transfers

## Variants
- **Default**: Standard dual list box
- **With Search**: Lists with search/filter functionality
- **With Sort**: Lists with sorting capabilities
- **Compact**: Reduced size for space-constrained interfaces
- **With Counts**: Lists showing item counts
- **With Checkboxes**: Items with checkboxes for selection
- **Virtual**: Virtual scrolling for large lists
- **Drag and Drop**: Drag items between lists

## Behavior & Guidelines
- Use dual list box for moving items between two collections
- Provide clear visual separation between lists
- Use transfer buttons with clear icons and labels
- Test with screen readers for proper list announcement
- Consider keyboard navigation for accessibility
- Use responsive design for different screen sizes
- Provide visual feedback for all interactions
- Consider performance for large datasets

## Token Gaps / Notes
- All colors use semantic CSS custom properties for theme consistency
- Typography scales are defined via font tokens with proper hierarchy
- Focus states use brand colors for visual consistency
- Selected states use brand colors for clear indication
- Dark theme adaptation through semantic tokens
- Dual list box should be responsive and accessible
