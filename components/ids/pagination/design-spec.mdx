- Component: Pagination

## Anatomy
- Pagination container
- Previous page button
- Page number buttons
- Current page indicator
- Next page button
- Optional page size selector
- Optional total items display
- Focus ring for keyboard navigation
- Optional jump to page input

## Layout & Measurements
- Standard height: 40px
- Button width: 40px (page numbers), 80px (prev/next)
- Button spacing: 4px
- Border radius: 4px (buttons)
- Focus ring: 2px offset from button
- Minimum width: 200px
- Page number padding: 8px 12px
- Icon size: 16px × 16px

## Typography
- Body 2: Roboto Regular 14px/20px (page numbers and labels)

## States (Dark Theme)
- Uses semantic tokens that automatically adapt to dark theme
- Surface tokens: `var(--color-background-surface-1)` (#f4f4f4), `var(--color-background-surface-2)` (#ffffff)
- Text and border colors remain consistent via semantic variables
- Current page uses brand colors for clear indication

## Interactions
- Click page numbers to navigate to specific pages
- Click Previous/Next to navigate sequentially
- Hover provides visual feedback with background changes
- Focus ring uses brand color for keyboard navigation
- Disabled buttons prevent navigation at boundaries
- Jump to page input for direct navigation (optional)
- Page size selector for items per page (optional)

## Accessibility
- Focus ring: 2px brand color border
- Keyboard navigation: Tab through controls, Enter to activate
- Screen reader support: Proper ARIA attributes for navigation
- High contrast: Meets WCAG AA standards with provided colors
- Semantic HTML: Use nav element with pagination role
- Current page indication: Proper aria-current="page" attribute
- Focus management: Logical tab order through pagination controls

## Variants
- **Default**: Standard pagination with page numbers
- **Simple**: Previous/Next only
- **Compact**: Reduced size for space-constrained interfaces
- **With Jump**: With jump to page input
- **With Size Selector**: With items per page selector
- **With Info**: Showing current page and total items
- **Ellipsis**: With ellipsis for many pages

## Behavior & Guidelines
- Use pagination for large datasets
- Show current page clearly
- Provide Previous/Next navigation
- Limit visible page numbers (typically 5-7)
- Include page information when helpful
- Test with screen readers for proper navigation announcement
- Consider responsive behavior for mobile devices
- Use consistent styling across the application
