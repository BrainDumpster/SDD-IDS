## Anatomy
Main component:
- `PaginationRoot` (`nav` landmark)

Deterministic child slots (left to right):
1. `PaginationPrev`
2. `PaginationPageList`
3. `PaginationPageButton` (repeated; concrete numeric pages)
4. `PaginationEllipsis` (optional non-interactive marker)
5. `PaginationNext`

Optional sub-slots:
- `PaginationSummary` (e.g. "Page 3 of 20")
- `PaginationPageSize` (items-per-page selector)
- `PaginationJumpToPage` (direct input/go control)

- Root layout is horizontal and container-driven; main row sample width is `779px` in library demos (runtime width remains parent-driven).
- **MCP-verified `Pagination - Main` row height is `48px`** (`py: 8px`, top/bottom border included).
- Main row horizontal padding: `24px` left and `32px` right.
- Main row border: `1px` (`var(--border-width-border-1)`) with `var(--color-border-accessible)`.
- Left "results per page" group gap is ~`15.5px` in source node; implementations may normalize to nearest spacing token while preserving visual rhythm.
- Right page-nav group uses `16px` inter-item spacing.
- Page textbox/input sample width is `40px`, control height `32px`, with `16px` horizontal inner padding.
- Per-page dropdown trigger sample width is `90px`, control height `32px`; menu items use `10px` vertical and `16px/24px` horizontal padding.
- Chevron and double-chevron icon slots are `16px`; dropdown caret slot is `10px`.
- Pagination supports `Background=Gray` and `Background=None` container contexts.
- Dropdown placement variants in the showcase: collapsed/default, expanded-below, expanded-above.

## Interactions
- `PaginationPageButton` click/activation selects that page.
- `PaginationPrev` decrements page index when `currentPage > 1`; disabled at first page.
- `PaginationNext` increments page index when `currentPage < totalPages`; disabled at last page.
- Ellipsis is presentational (non-focusable, non-interactive) unless an explicit "jump" pattern is enabled by API.
- Keyboard:
  - `Tab` traverses interactive controls.
  - `Enter`/`Space` activate focused control.
  - Optional roving model may support `ArrowLeft`/`ArrowRight` between page buttons when framework pattern requires it.
- Focus ring must remain visible and not be clipped by root overflow.

## Composition & API (runtime)
Main inputs:
- `currentPage: number` (required; 1-based)
- `totalPages: number` (required; `>= 1`)
- `onPageChange?: (page: number) => void`
- `showPrevNext?: boolean` (default `true`)
- `windowSize?: number` (default `7`; max visible numeric buttons including boundaries)
- `showEllipsis?: boolean` (default `true`)
- `showSummary?: boolean` (default `false`)
- `showPageSize?: boolean` (default `false`)
- `showJumpToPage?: boolean` (default `false`)
- `disabled?: boolean` (default `false`)

Optional inputs for extended slots:
- `pageSizeOptions?: number[]`
- `pageSize?: number`
- `onPageSizeChange?: (size: number) => void`
- `summaryFormatter?: (currentPage: number, totalPages: number) => string`

Outputs/events:
- `onPageChange(page)`
- `onPageSizeChange(size)` when page-size slot is enabled

## Codegen Contract (Framework-Agnostic Blueprint)
Deterministic structure:
- `PaginationRoot` (`nav`, `aria-label`)
  - optional `PaginationPrev`
  - `PaginationPageList`
    - repeated `PaginationPageButton`
    - optional `PaginationEllipsis` markers
  - optional `PaginationNext`
  - optional `PaginationSummary`
  - optional `PaginationPageSize`
  - optional `PaginationJumpToPage`

Variant/option matrix:
- Density: `standard | compact` (only when target system supports density switch)
- Navigation controls: `with-prev-next | numeric-only`
- Number compression: `full-list | windowed-with-ellipsis`
- Optional addons: `summary on/off`, `page-size on/off`, `jump-to-page on/off`
- Background context: `none | gray`
- Per-page dropdown: `hidden | collapsed | expanded-below | expanded-above`
- Item state: `default | hover | press | focus-visible | selected | disabled`

Per-slot style contract:
- Root uses neutral background context and tokenized gap.
- Page controls share shape, border width, and typography contracts.
- Selected page always uses brand control tokens with inverse text/icon.
- Disabled controls always use disabled text/icon/border tokens and block pointer/keyboard activation.

Behavior contract:
- Page range clamps to `[1, totalPages]`.
- When `currentPage` changes, recompute visible window deterministically:
  - Always include page `1` and `totalPages` when `totalPages > windowSize`.
  - Add leading/trailing ellipsis only when there is a skipped numeric span.
- `disabled=true` blocks all navigation and suppresses callbacks.
- Invalid inputs (`totalPages < 1`, `currentPage` out of range) must be normalized and reported via validation path.

Accessibility contract:
- Root uses `nav` with label (`aria-label="Pagination"` or consumer-provided equivalent).
- Current page button carries `aria-current="page"`.
- Disabled controls carry `disabled` and/or `aria-disabled="true"` based on element type.
- Ellipsis should be hidden from tab sequence (`tabindex="-1"` or non-focusable text).
- Focus order must remain logical and deterministic across variant modes.

Asset/bundling contract:
- Prev/next icons should resolve through the target icon primitive when available (stable logical names: `chevron-left`, `chevron-right` or project aliases).
- If no icon primitive exists, fallback icon rendering must still use semantic icon color tokens (`currentColor`).

Fallback/error rules:
- Unknown density -> fallback `standard`.
- `windowSize < 5` -> fallback `5` (maintain boundary + center logic).
- Missing `onPageChange` is allowed; control remains semantically interactive but no external state update occurs.
- Duplicate or invalid page-size options are normalized to unique positive integers.

Validation checklist:
- [ ] Required sections are complete and free of placeholders.
- [ ] Light/Dark state tables are structurally parallel.
- [ ] Selected, disabled, hover, and focus-visible states are tokenized.
- [ ] Windowed pagination produces deterministic ellipsis placement.
- [ ] Prev/next boundaries disable correctly at page edges.
- [ ] `aria-current="page"` is applied to exactly one visible page control.
- [ ] Keyboard activation works with Enter/Space on interactive controls.
- [ ] Optional summary/page-size/jump slots do not break base layout contract.
