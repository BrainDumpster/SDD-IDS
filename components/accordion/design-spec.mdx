## Interactions

- Component variants define panel interaction states directly in Figma: `Collapsed/Expanded` x `Default/Hover`.
- Click target and toggle behavior:
  - Clicking the panel header toggles the panel.
  - Clicking the chevron icon also toggles the same panel (same action as header click).
- Hover behavior:
  - Collapsed hover uses `var(--color-background-brand-lighter)` and stronger chevron color (`var(--color-border-strong)`).
  - Expanded hover uses `var(--color-background-brand-light)` while preserving active bar token (`var(--color-border-brand-base)`).
- Expand/collapse behavior:
  - Chevron points down when collapsed and up when expanded.
  - Expanded state reveals content container and active left indicator bar.
- Open-mode behavior:
  - Single-open mode (`one panel at a time`): opening a panel closes any other open panel; clicking the already-expanded panel toggles it closed.
  - Multi-open mode (`multiple panels allowed`): each panel toggles independently; multiple expanded panels can coexist.
  - Suggested API contract for implementation: `mode="single|multiple"` with controlled open-state input (for example `openIndexes`).
- Implementation note for generated/runtime component:
  - Keep panel interaction enabled by default (`data-state` should be empty/undefined in runtime usage).
  - Use explicit `data-state` values only for visual demo/testing snapshots (forced state rendering).
- Group behavior:
  - In grouped accordion, panels are contiguous with no spacing between rows (border-overlap pattern).
- Map focus rings to `var(--color-border-brand-base)` (brand focus mapping in this file).
