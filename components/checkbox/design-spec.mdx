# Checkbox Design Spec

## Metadata
- Component: Checkbox
- Category: Formelements

## Anatomy
- Checkbox input element (native or custom)
- Check/cross icon for selected state
- Label text container
- Focus ring for keyboard navigation
- Container wrapper with proper spacing

## Layout & Measurements
- Standard checkbox size: 16px × 16px
- Label spacing: 8px from checkbox
- Touch target: Minimum 44px × 44px for accessibility
- Border radius: 2px (standard for form controls)
- Focus ring: 2px offset from checkbox

## Typography
- Body 1 - Medium: Roboto Medium 16px/24px (checkbox labels)
- Body 2: Roboto Regular 14px/20px (secondary text)

## States (Dark Theme)
- Uses semantic tokens that automatically adapt to dark theme
- Surface tokens: `var(--color-background-surface-1)` (#111619)
- Text and border colors remain consistent via semantic variables
- Disabled state uses gray base token for dark theme compatibility

## Interactions
- Click toggles checked/unchecked state
- Hover provides visual feedback with border/background changes
- Focus ring uses brand color for keyboard navigation
- Disabled state prevents interaction and uses gray colors
- Smooth transitions for state changes

## Accessibility
- Focus ring: 2px brand color border
- Touch target: Minimum 44px for mobile accessibility
- Keyboard navigation: Tab to checkbox, Space to toggle
- Screen reader support: Proper ARIA labels and states
- High contrast: Meets WCAG AA standards with provided colors
- Semantic HTML: Use native checkbox element when possible

## Variants
- **Default**: Standard checkbox with brand colors
- **Error**: Critical state for validation errors
- **Warning**: Info state for warnings
- **Disabled**: Non-interactive state
- **Indeterminate**: Partially selected state (tri-state)

## Behavior & Guidelines
- Use checkboxes for multiple selection scenarios
- Provide clear, concise labels for each checkbox
- Group related checkboxes with fieldset/legend
- Use indeterminate state for "select all" functionality
- Ensure adequate spacing between checkbox options
- Test with screen readers for proper announcement

## Token Gaps / Notes
- All colors use semantic CSS custom properties for theme consistency
- Typography scales are defined via font tokens with proper hierarchy
- Focus states use brand colors for visual consistency
- Disabled states maintain accessibility with proper contrast
- Error states use critical color tokens for validation feedback
