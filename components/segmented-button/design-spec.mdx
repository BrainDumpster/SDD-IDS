## Metadata
- Component: Segmented Button
- Category: Formelements

## Anatomy
- Segmented button container
- Individual button segments
- Selected segment indicator
- Focus ring for keyboard navigation
- Optional icons for each segment
- Grouped border styling

## Layout & Measurements
- Standard height: 32px
- Segment width: Auto (based on content)
- Horizontal padding: 12px per segment
- Border radius: 4px (container), 0 (internal borders)
- Focus ring: 2px offset from segment
- Minimum segment width: 40px
- Icon size: 16px × 16px
- Spacing between segments: 0 (adjacent)

## Typography
- Header 5: Roboto Regular 24px/32px (large segmented buttons)
- Header 6: Roboto Regular 18px/25px (medium segmented buttons)
- Body 2: Roboto Regular 14px/20px (standard segmented buttons)

## States (Dark Theme)
- Uses semantic tokens that automatically adapt to dark theme
- Surface tokens: `var(--color-background-surface-1)` (#111619)
- Text and border colors remain consistent via semantic variables
- Selected segment uses brand colors for clear indication
- Hover states provide visual feedback

## Interactions
- Click segment to select option
- Hover provides visual feedback with background changes
- Focus ring uses brand color for keyboard navigation
- Only one segment can be selected at a time
- Keyboard navigation: Arrow keys to navigate, Enter to select
- Disabled segments prevent interaction and use gray colors
- Selected segment provides clear visual indication

## Accessibility
- Focus ring: 2px brand color border
- Keyboard navigation: Tab to segmented control, Arrow keys to navigate, Enter to select
- Screen reader support: Proper ARIA attributes for segmented control
- High contrast: Meets WCAG AA standards with provided colors
- Semantic HTML: Use radio group with proper role attributes
- Focus management: Logical tab order through segments
- Selection announcements: Screen reader announces selected option

## Variants
- **Default**: Standard horizontal segmented button
- **Vertical**: Stacked vertical orientation
- **With Icons**: Segments with icons only or icon + text
- **Disabled**: Non-interactive state
- **Small**: Reduced size for tight spaces
- **Large**: Increased size for prominence
- **Full Width**: Segments fill container width
- **Multi-Select**: Allow multiple selections (radio vs checkbox behavior)

## Behavior & Guidelines
- Use segmented buttons for mutually exclusive options
- Provide clear, concise labels for each segment
- Use consistent styling across the application
- Ensure adequate touch targets for mobile devices
- Test with screen readers for proper option announcement
- Consider responsive behavior for different screen sizes
- Use appropriate number of segments (3-7 recommended)
- Provide visual indication of selected state

## Token Gaps / Notes
- All colors use semantic CSS custom properties for theme consistency
- Typography scales are defined via font tokens with proper hierarchy
- Focus states use brand colors for visual consistency
- Selected states use brand colors for clear indication
- Disabled states maintain accessibility with proper contrast
- Dark theme adaptation through semantic tokens
