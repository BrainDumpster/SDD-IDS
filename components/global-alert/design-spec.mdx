# Global Alert Design Spec

## Metadata
- Component: Global Alert
- Category: Alerts and Notifications
- Figma: https://www.figma.com/design/VZJ48bbVYrIynw8DdSukWw/-Exploration-only--IDS-with-variables?node-id=11067-54641&m=dev

## Anatomy
- Alert container with full-width background
- Alert icon (status indicator)
- Alert title and message
- Close button (×)
- Focus ring for keyboard navigation
- Optional action buttons
- Dismiss animation

## Layout & Measurements
- Standard height: 48px
- Horizontal padding: 16px
- Vertical padding: 12px
- Border radius: 0 (full-width alert)
- Focus ring: 2px offset from alert
- Icon size: 24px × 24px
- Close button: 16px × 16px
- Minimum width: Full viewport width
- Spacing between elements: 12px

## Typography
- Header 5: Roboto Regular 24px/32px (alert titles)
- Base Styles/Default Text: Roboto Regular 14px/20px (alert messages)
- Body 2: Roboto Regular 14px/20px (secondary text)

## States (Dark Theme)
- Uses semantic tokens that automatically adapt to dark theme
- Surface tokens: `UI Palettes/Slate/slate-900` (#111619)
- Text and border colors remain consistent via semantic variables
- Alert colors maintain visibility in dark theme

## Interactions
- Click close button to dismiss alert
- Hover provides visual feedback with stronger colors
- Focus ring uses brand color for keyboard navigation
- Auto-dismiss after timeout (optional)
- Action buttons for user responses
- Keyboard navigation: Tab to alert, Enter to action, Escape to dismiss

## Accessibility
- Focus ring: 2px brand color border
- Keyboard navigation: Tab to alert, Enter for actions, Escape to dismiss
- Screen reader support: Proper ARIA attributes (alert, role, status)
- High contrast: Meets WCAG AA standards with provided colors
- Semantic HTML: Use alert element with proper role
- Focus management: Auto-focus on new alerts
- Dismiss announcements: Screen reader announces when alert is dismissed

## Variants
- **Info**: Blue informational alert
- **Warning**: Yellow caution alert
- **Error**: Orange error alert
- **Critical**: Red critical alert
- **Success**: Green success alert
- **Persistent**: Alert that requires user action
- **Auto-dismiss**: Alert that dismisses automatically
- **With Actions**: Alert with action buttons

## Behavior & Guidelines
- Use global alerts for important system messages
- Position alerts at top of page for visibility
- Use appropriate color variants for severity levels
- Provide clear, concise messages
- Include dismiss functionality for non-critical alerts
- Test with screen readers for proper announcement
- Consider auto-dismiss for non-critical notifications
- Use consistent styling across alert types

## Token Gaps / Notes
- All colors use semantic CSS custom properties for theme consistency
- Typography scales are defined via font tokens with proper hierarchy
- Focus states use brand colors for visual consistency
- Alert variants use appropriate color psychology
- Dark theme adaptation through semantic tokens
- Alert positioning should be consistent and accessible
