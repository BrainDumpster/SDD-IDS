# Changelog

## 0.1.0

- Initial publishable `@ids/core` package (renamed from in-repo `@ids/core`).
- Multi-entry ESM build with per-component `./<slug>` and `./<slug>/register` exports.
- Self-contained minified theme CSS (`ids-theme.css`) with light + dark token sets.
- Runtime theme switching via `applyIdsTheme` / `getIdsTheme`.
- Package-shipped icon assets under `assets/icons/`.
